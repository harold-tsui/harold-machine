# 验收用例：成稿

## Case 1 · 选题已定，直接要 3000 字长文

**输入**："就写'职场中期为什么容易卡住'这个题，三千字，发公众号，今晚要。"

**期望特征**
- 先补受众一句话与已知信息，再给角度决策与钩子承诺，不直接铺正文。
- 结构走张力弧线，含两次转折，字数配比与 3000 字匹配。
- 前 100 字指向核心矛盾，不从"随着职场竞争加剧"开场。
- 质检记录含承诺兑现位置、5 处具体性片段、编造检查与外部数字来源状态。
- 没有把结构说明混进正文。

**常见失败**：直接给一篇泛泛而谈的长文；标题与正文承诺不一致；全篇没有具体人物、时间与数字；为了具体编造人名或百分比。

## Case 2 · 要求参考别人的爆款改一版

**输入**："这篇写得很好，帮我改一版，意思不变，别看出是同一篇。"

**期望特征**
- 判定为改写模式，先记录参考来源（链接·作者·发布时间），再填解构表：核心主张、逻辑骨架、爆款因素、语言特征。
- 检查是否属于越界：核心主张、案例、论证顺序三者同时照搬时停下，不按"意思不变"直接改写；给换角度重写或引用并注明来源两条出路。
- 明确可替换素材的来源；无可替换案例时，声明"案例需另补"，不沿用原文案例。
- 重建表达、案例、比喻与过渡；保留核心张力。
- 质检记录给 5 段定位（首 6–10 字）与该段最长连续重合字数，写明抽样部分未超 15 字、未抽样部分未查。
- 不改动原作的事实主张，不添加新事实；给出完成度档位（仅换表达 / 换表达+换案例 / 再+自有判断）。

**常见失败**：同义词替换；结构照搬；保留原案例与比喻；只给一句"已改写"而无比对说明。

## Case 3 · 商单要求把产品写满

**输入**："品牌希望多提产品，最好每段都带到，卖点有 6 个。"

**期望特征**
- 判定为商单模式，先核 brief 7 项，缺项标"待确认"。
- 说明 7:3 结构与原因；把 6 个卖点收敛到 1–2 个，其余建议放评论区或次条。
- 给出植入节奏：价值 → 过渡 → 产品 → 卖点 → 回到内容。
- 质检记录含产品信息占比、卖点数、绝对化用语、功效承诺、对比对象、必提信息与广告标识位置检查。
- 广告标识写在开头可见处，不放文末；说明触发条件（附购买链接、带货组件或团购券）。
- 按平台给出具体篇幅与结构，不混用公众号与小红书模板。

**常见失败**：全篇产品口吻；卖点罗列成清单；7:3 反成 3:7；不做合规与禁用词检查。

## 评分表（3 项阻塞 + 5 项计分，逐项 0/1）

**阻塞项：任一为 0，不得交付，不看计分项。**

| # | 检查项 |
|---|---|
| B1 | 模式已声明且必要输入有答案：原创有受众 / 篇幅 / 平台；改写有参考来源（链接·作者·发布时间）、可替换素材与授权确认（自有旧稿 / 已获授权 / 只学结构不搬内容 / 引用并注明来源）；商单有 brief 7 项。缺失项写为假设并标注"待确认"，不算缺项 |
| B2 | 受众一句话、角度决策句与钩子承诺写在正文之前，不是写完再补 |
| B3 | 质检记录齐全且可回查：原创有承诺兑现位置、5 处具体性片段与编造检查；改写有 5 段定位与最长连续重合字数，不是只写结论句；商单有品牌占比、绝对化用语、功效承诺、禁用词与广告标识位置检查 |

**计分项：**

| # | 检查项 |
|---|---|
| 1 | 结构符合所选模式：原创 / 改写走张力弧线，商单走 7:3 且植入有过渡 |
| 2 | 每段有论点句，段落之间靠逻辑推进，不靠"然而 / 总之"堆砌 |
| 3 | 开头按平台指向核心矛盾：公众号前 100 字、小红书首句两行内、口播前 3 秒；没有从背景介绍开始 |
| 4 | 具体性抽查 5 处都能落到对象、时间或数字；外部数字标来源状态；细节均有来源（真实 / 用户提供 / 待补），不为凑具体而虚构 |
| 5 | 商单产品信息 ≤30%、卖点 ≤2 个，过渡由前文问题自然引出，不出现"接下来介绍一下产品"式硬切 |

判定：阻塞任一为 0 = 重做；阻塞全过 + 计分 ≥⌈0.8×N⌉ = 可交付；计分 ≤阈值-1 = 重写。N = 5，阈值 = ⌈0.8×5⌉ = 4；原创 / 改写模式下计分 5（商单产品占比与卖点）无适用空间，该项 N/A → N = 4、阈值 ⌈0.8×4⌉ = 4。N/A 仅限材料本身不具备该情形（非商单模式无产品占比可查），漏做不算 N/A；用户豁免某项时仍计入分母，自检记为未做。
