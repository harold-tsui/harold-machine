# Production Line · 成稿

> 一句话：先定模式与角度，再写；写完必须过质检。

## 核心定位

- 适用：选题已确认，进入正文阶段的写作与改写。
- 不适用：选题（用 `harold-production-topic`）、纯语言层去 AI 腔（用 `harold-production-polish`）、版式与配图（用 `harold-production-slides` / `harold-production-visual`）。
- 三种模式先声明再动笔，不混写：原创 / 改写 / 商单。

## 触发场景

- "把这个题写成一篇长文"
- "按这个结构写一篇公众号"
- "参考这篇，改写成我的"
- "帮我写一篇品牌商单"
- "这篇初稿帮我写完整"

## 工作流

### Step 0 声明模式与口径

| 模式 | 何时用 | 必要输入 |
|---|---|---|
| 原创 | 只有选题与素材 | 受众 / 篇幅 / 平台（缺一先问） |
| 改写 | 有参考内容，要换成自己的表达 | 参考来源（链接·作者·发布时间）/ 目标风格 / 可替换的自有素材 / 授权状态 |
| 商单 | 有品牌合作与 brief | 品牌 / 产品与卖点 / 受众 / 平台 / 字数 / 软硬广要求 / 必提信息与禁用词 |

缺关键输入只问一个，其余写假设并标"待确认"。改写缺自有素材时先声明"只能换结构，案例需另补"。
材料不是缺字段，而是撑不住角度或篇幅时，退回 `harold-production-topic` 换题，不硬写。

改写模式先确认授权状态，四选一：

| 授权状态 | 可以做什么 | 不能做什么 |
|---|---|---|
| 自有旧稿 | 全部重写 | —— |
| 已获授权 | 换表达、换案例、换结构，保留主张 | 不超出授权范围 |
| 只学结构不搬内容 | 借逻辑骨架与角度 | 不搬案例、比喻、原句 |
| 引用并注明来源 | 少量原话引用 + 注明作者与出处 | 不作大段改写后冒充原创 |

**越界判据（命中即停，不动笔）**：核心主张、案例、论证顺序三者同时照搬、只换表达，是洗稿而非改写。用户要求"意思不变、别看出是同一篇"即属此列。此时给两条出路：换角度重写（回 Step 2），或改为引用并注明来源。司法实践按「接触 + 实质性相似」判侵权，相似的是表达与结构，不是字面重合率。

### Step 1 受众一句话

`[具体人群]，正在经历[具体处境]，希望得到[具体收获]`。
同时写明读者已知什么，正文不解释已知概念。

### Step 2 角度

先列 3–5 种同类内容的常见写法，找它们的共同盲点，再选一个角度切入。四种来源：

- 反直觉：与常见建议相反，但能被事实支撑。
- 具体化：把抽象判断落到一个具体人、场景或数字。
- 时间位移：看三年前 / 三年后的变化。
- 跨领域嫁接：用另一个领域的机制解释本领域现象。

写一句角度决策：选这个角度，因为……；与同类内容的区别是……。
角度必须被现有材料撑住：写不出支撑它的证据或案例，就换角度，不靠形容词硬撑。
再写一句钩子承诺：开头向读者承诺什么判断，正文第几段兑现。承诺与兑现对不上的钩子不采用。
商单从五类角度中选一：问题—解决方案 / 生活方式融入 / 对比验证 / 专业权威 / 场景事件。卖点超过 2 个时只留最能支撑角度的 1–2 个，其余给降级去处（评论区、次条、下一篇）。

### Step 3 结构

原创与改写走张力弧线：开篇悬念 → 第一次转折 → 论证展开 → 第二次转折 → 结论 → 行动。
按篇幅换算段落配额，示例（示例，非真实数据）：5000 字 = 钩子 150–300 / 界定 400–600 / 论证 800–1000 × 2 / 转折 600–800 / 案例 600–800 / 结论 300–500。
短篇不套完整弧线：小红书保留「钩子 → 转折 → 结论」三段，口播保留「钩子 → 一个转折 → 行动」，不硬塞六段。

短篇按字数给配额，不按系数折算：小红书钩子 ≤60 字（首屏两行内）、正文 3–5 个短段、结论一段收口；口播按 220–260 字/分钟折算——60 秒 ≈ 220–260 字，120 秒 ≈ 450–520 字，180 秒 ≈ 660–780 字，超出即读不完。

商单走 7:3：70% 独立内容 + 30% 产品信息；植入节奏为「价值 → 过渡 → 产品 → 1–2 个卖点 → 回到内容」。按平台取对应模板（见 `references/commercial-copy.md`），公众号与小红书的结构不混用。

### Step 4 起草

每段四件套：论点句 → 证据或案例 → 分析 → 过渡。
短篇降级：小红书与口播每段只需「判断 → 一个依据」，四件套会把 300 字撑成说明书。
开篇五选一：悖论 / 场景代入 / 数字冲击 / 问题挑衅 / 故事开场。开头按平台判：公众号前 100 字、小红书首句两行内、口播前 3 秒，都必须指向核心矛盾。
具体性：不写"很多人""大家都"，写具体对象、时间、数字；外部数字标"已核 / 待核"。
**具体细节只有三个来源**：真实可核（有出处）/ 用户提供 / 待补。三者都拿不到时，写可核对的区间或范围（"面试了 6 家，4 家在同一周回复"），不编人名、对话、时间、百分比。为让文字"更具体"而虚构细节，视为伪造，不得交付。

改写模式在起草前多一步解构：

1. 核心主张是什么；
2. 逻辑骨架（先说什么、后说什么、哪里转折）；
3. 爆款因素 1–2 个（情绪、对立、获得感、身份）；
4. 语言特征 3–5 条（句长、人称、节奏、口头语）；
5. 来源记录：链接、作者、发布时间、授权状态。

然后换表达、换案例、换比喻重建。过渡句、列举句、总结句必须重写，不只换同义词。原作的事实主张保持不变，不新增事实。

### Step 5 质检

质检记录必须能被回查，不能只写结论句。

- 原创：钩子承诺在正文第几段兑现；抽 5 处具体性，每处记位置 + 原文片段（6–10 字）+ 判定；外部数字是否有来源状态；有没有为凑具体而编造的细节，逐条列。
- 改写：取 5 个段落（开头、两个论证段、案例段、结尾）与参考内容并排逐句比对；记录每段定位（首 6–10 字）+ 该段最长连续重合字数，结论写"抽样 5 段最长重合 X 字，未抽样部分未查"；15 字为本库自查下限，不是平台阈值；通过自查不等于平台判原创——平台与司法都看主题、角度、素材、表达、结构是否实质相似，同义词替换与语序转换不改变判定；核心张力是否保留。
- 商单：产品信息是否 ≤30%；卖点是否 ≤2 个；绝对化用语、功效承诺、对比贬损逐项查（口径见 `references/commercial-copy.md` §六）；必提信息是否齐全；广告标识——以知识介绍、体验分享、消费测评等形式推销，并附购买链接、带货组件或团购券的，须在开头可见处显著标明"广告"（《互联网广告管理办法》第九条，2023-05-01 施行），藏在文末折叠区之后视为未标。

## 输出格式

```text
# 成稿：<标题>
模式：原创 / 改写 / 商单

## 写作前决策
受众：……，正在经历……，希望得到……
已知信息：……
角度：……（为什么选它；与同类的区别；支撑它的证据）
钩子承诺：开头承诺……，在第 X 段兑现
结构：钩子 / 界定 / 论证 / 转折 / 案例 / 结论 字数分配
（改写）参考来源：链接｜作者｜发布时间
（改写）解构表：核心主张｜逻辑骨架｜爆款因素｜语言特征
（改写）授权状态：自有旧稿 / 已获授权 / 只学结构不搬内容 / 引用并注明来源
（改写）完成度：仅换表达 / 换表达+换案例 / 再+自有判断
（商单）Brief：品牌产品｜卖点｜受众｜平台与形式｜字数或时长｜软硬广要求与必提信息｜交付与轮次

## 正文
<成稿>

## 质检记录
- 实际字数：X 字（要求 Y 字）
- 承诺兑现：钩子承诺在正文第 X 段兑现，判定……
- 具体性抽查（5 处）：位置 + 原文片段 + 判定
- 编造检查：无 / 有（逐条列）
- 来源状态：
- （改写）15 字抽样比对（5 段）：段位 + 首 6–10 字 + 该段最长重合字数
- （改写）完成度：仅换表达（不可发）/ 换表达+换案例（可发，需授权）/ 再+自有判断（可标原创）
- （商单）品牌信息占比 / 卖点数 / 绝对化用语 / 功效承诺 / 对比对象 / 广告标识位置 / 禁用词
```

## 验收标准

**阻塞项：任一为 0，不得交付。**

- [ ] B1 模式已声明且必要输入有答案：原创有受众 / 篇幅 / 平台；改写有参考来源（链接·作者·发布时间）、可替换素材与授权确认（自有旧稿 / 已获授权 / 只学结构不搬内容 / 引用并注明来源）；商单有 brief 7 项。缺失项写为假设并标注"待确认"，不算缺项
- [ ] B2 受众一句话、角度决策句与钩子承诺写在正文之前，不是写完再补
- [ ] B3 质检记录齐全且可回查：原创有承诺兑现位置、5 处具体性片段与编造检查；改写有 5 段定位与最长连续重合字数，不是只写结论句；商单有品牌占比、绝对化用语、功效承诺、禁用词与广告标识位置检查

**计分项：**

- [ ] 1 结构符合所选模式：原创 / 改写走张力弧线，商单走 7:3 且植入有过渡
- [ ] 2 每段有论点句，段落之间靠逻辑推进，不靠"然而 / 总之"堆砌
- [ ] 3 开头按平台指向核心矛盾：公众号前 100 字、小红书首句两行内、口播前 3 秒；没有从背景介绍开始
- [ ] 4 具体性抽查 5 处都能落到对象、时间或数字；外部数字标来源状态；细节均有来源（真实 / 用户提供 / 待补），不为凑具体而虚构
- [ ] 5 商单产品信息 ≤30%、卖点 ≤2 个，过渡由前文问题自然引出，不出现"接下来介绍一下产品"式硬切

判定：阻塞任一为 0 = 重做；阻塞全过 + 计分 ≥⌈0.8×N⌉ = 可交付；计分 ≤阈值-1 = 重写。N = 5，阈值 = ⌈0.8×5⌉ = 4；原创 / 改写模式下计分 5（商单产品占比与卖点）无适用空间，该项 N/A → N = 4、阈值 ⌈0.8×4⌉ = 4。N/A 仅限材料本身不具备该情形（非商单模式无产品占比可查），漏做不算 N/A；用户豁免某项时仍计入分母，自检记为未做。

## Gotchas

1. **三种模式混写**
   改写写成了原创的口气，商单写成了纯软文，都会返工。先声明模式。

2. **先写正文后想角度**
   角度没定就动笔，写到一半发现与同类内容没区别，只能推倒。

3. **标题承诺大于正文兑现**
   标题给的是冲突，正文只给了方法，读者会认为被骗。

4. **改写只换同义词**
   句式、案例、比喻不变，15 字比对必然重合；这种稿子过不了平台原创检测。

5. **商单写成产品说明书**
   7:3 反成 3:7，读者在前 100 字就退出。先给价值，再给产品。

6. **"随着……时代"开场**
   背景铺陈不是钩子。第一段就要让读者知道自己为什么该看下去。

7. **改写写成洗稿**
   主张、案例、论证顺序三样都留着，只换词。平台判原创与司法判侵权看的都是实质相似，不是重合率；查重率低不构成免责。

8. **为凑具体而编细节**
   编一个人名、一句对话、一个百分比，读者当场查得到，信任一次性归零。宁可写范围，不造细节。

9. **广告标识藏在文末**
   附了购买链接、带货组件或团购券却不标"广告"，或标识放在折叠区之后，按《互联网广告管理办法》第九条属未标。
