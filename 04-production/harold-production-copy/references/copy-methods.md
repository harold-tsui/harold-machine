# 成稿方法

## 一、角度四来源

| 来源 | 用法 | 示例（示例，非真实数据） |
|---|---|---|
| 反直觉 | 与常见建议相反，且有事实支撑 | "越努力越焦虑" → "焦虑不是因为不努力，是因为努力无法被计价" |
| 具体化 | 把抽象判断落到一个人、场景或数字 | "行业在下行" → "周三下午，招聘软件上同一个岗位刷新了 4 次" |
| 时间位移 | 看三年前与三年后的变化 | "现在入场晚不晚" → "三年前做这件事的人，现在停在哪一步" |
| 跨领域嫁接 | 借另一领域的机制解释本领域 | 用"库存周转"解释个人技能贬值速度 |

用法：先列 3–5 种同类写法，找出它们的共同盲点，再从盲点里选角度。不要直接选"没人写过的角度"，要选"同类都绕开的角度"。
角度必须被现有材料撑住：写不出支撑它的证据或案例，就换角度，不靠形容词硬撑。"新"不是标准，"能被证明"才是。

## 二、五类钩子

| 钩子 | 结构 | 适用 |
|---|---|---|
| 悖论 | 先说一个反常识判断，再用材料解释 | 观点文、评论 |
| 场景代入 | 一个具体时间地点人物的瞬间 | 情感、职场、生活方式 |
| 数字冲击 | 一个与直觉不符的数字 + 口径 | 商业、行业分析 |
| 问题挑衅 | 直接质疑读者的默认做法 | 方法论、认知类 |
| 故事开场 | 一个人做了一件具体的事，结果出人意料 | 长文、人物 |

前 100 字必须落到核心矛盾；背景、定义、行业概况放到第二段之后。

## 三、张力弧线

```text
开篇悬念（一个具体冲突或反常识判断）
  → 第一次转折（原以为 A，其实 B）
  → 论证展开（证据、案例、机制）
  → 第二次转折（但 B 也有代价，或只在 C 条件下成立）
  → 结论（明确判断）
  → 行动（读者能做什么，或该重新看待什么）
```

第二次转折不能省。只有一次转折的文章，读起来像观点宣示。

## 四、段落四件套

1. 论点句：这一段要证明什么，一句话。
2. 证据或案例：数字、事件、原话、可核对的材料。
3. 分析：这个证据为什么支持论点，不能只贴素材。
4. 过渡：下一段要处理什么，用逻辑衔接，不用"然而""总之"。

## 五、字数配比（按总篇幅换算）

以 5000 字为例（示例，非真实数据）：

| 部分 | 字数 |
|---|---|
| 钩子 | 150–300 |
| 界定问题 | 400–600 |
| 论证一 | 800–1000 |
| 论证二 | 800–1000 |
| 转折 | 600–800 |
| 案例 | 600–800 |
| 结论与行动 | 300–500 |

3000 字按 0.6 系数折算；8000 字按 1.6 折算，超出部分优先给论证与案例，不给背景。

短文与口播不折算，直接按配额写：

| 形式 | 配额 |
|---|---|
| 小红书 300–800 字 | 钩子 ≤60 字（首屏两行内）；正文 3–5 个短段；结论一段收口；产品 / 行动收尾 |
| 口播 60 秒 | 220–260 字（语速 220–260 字/分钟） |
| 口播 120 秒 | 450–520 字 |
| 口播 180 秒 | 660–780 字 |

口播超出字数就删信息点，不靠加快语速硬塞。

## 六、具体性检查

把文中以下词替换为具体信息，替换不了就删句：

- 很多人 / 大家 / 大多数人 → 具体人群 + 数量或场景
- 最近 / 前段时间 → 具体时间
- 大幅 / 显著 → 具体幅度 + 口径
- 有研究表明 → 具体来源 + 年份

外部数字标注"已核（来源）/ 待核"；待核数字不能作为中心判断的唯一支撑。

**细节来源只有三类**：真实可核（有出处）/ 用户提供 / 待补。三类都拿不到时，写可核对的区间或范围，不编人名、对话、时间、百分比。为让文字"更具体"而虚构细节，属于伪造，不得交付。
