# 改写方法

> 适用范围：把自己的旧稿、授权素材或参考内容，换成自己的表达与结构。只处理文本层与结构层，不改变原作的事实主张。

## 一、解构表

改写前先填完，填不完不动笔：

| 维度 | 要提取什么 |
|---|---|
| 核心主张 | 一句话：作者到底要读者相信什么 |
| 逻辑骨架 | 先说什么、后说什么、在哪两处转折 |
| 爆款因素 | 1–2 个：情绪共鸣 / 对立冲突 / 获得感 / 身份表达 |
| 语言特征 | 3–5 条：句长、人称、节奏、口头语、标点习惯 |
| 案例结构 | 用了几个案例，各自承担什么功能 |
| 承诺 | 标题与开头向读者承诺了什么 |
| 来源记录 | 链接、作者、发布时间、授权状态（用于授权判断与后续注明来源） |

## 二、重建顺序

1. **换表达**：长句改短句或反之；书面语改口语；调整人称与叙述视角。
2. **换案例**：用同等功能的真实素材替换；没有替代素材时，删掉该段而不是保留原案例。
3. **换比喻**：原比喻属于原作的语言特征，必须替换或删除。
4. **重搭过渡**：过渡句、列举句、总结句最容易残留，全部重写。
5. **保留张力**：核心矛盾、两次转折、情绪落点保持同构，避免改成平铺说明。

## 三、质检方法

取 5 个段落（开头、两个论证段、案例段、结尾），与原文并排逐句比对。本法为抽样检查，不构成全文查重。结论不能只写一句判定，须给可回查的记录：每段定位（首 6–10 字）+ 该段最长连续重合字数。固定表述（机构名、法规名、专有名词）不计入重合，需单列说明。

- 抽样段落内无连续 15 字重合（结论写"抽样 5 段最长重合 X 字，未抽样部分未查"）；
- 句式结构不相同（主谓宾顺序、修辞方式）；
- 案例与比喻均已替换；
- 核心张力仍在（读者读完的判断与原作一致，但表达是自己的）。

任一不通过，回到对应步骤重写，不做局部同义词替换。

## 四、常见失败

| 失败 | 表现 | 修正 |
|---|---|---|
| 同义词替换式改写 | 句子骨架完全一致，只换形容词 | 回到"换表达"，改句式与视角 |
| 结构照搬 | 段落顺序、转折位置完全一致 | 重新安排论证顺序，至少改变一次转折位置 |
| 案例残留 | 仍用原作的人物、公司、数字 | 换成自有素材；没有就删段 |
| 过渡句残留 | "然而""不得不说""值得一提的是"成串出现 | 全部重写，改逻辑衔接 |
| 张力丢失 | 改成四平八稳的说明文 | 恢复核心矛盾与情绪落点 |

## 五、素材不足时的降级

- 没有可替换案例：只改结构与语言，明确标注"案例沿用原素材，需补充自有案例后再发布"。
- 没有目标风格：以"口语、短句、具体"为默认基线，写完请用户确认。
- 原作事实无法核实：原样保留事实并标"待核"，不改写、不放大、不添加新事实。

## 六、越界判定：什么情况不做

| 情形 | 判定 | 处置 |
|---|---|---|
| 核心主张、案例、论证顺序三样全留，只换表达 | 洗稿 | 停笔。换角度重写，或改引用并注明来源 |
| 核心主张保留，案例与论证顺序至少换掉一样 | 可改写 | 走第二、三步重建，仍需授权或自有素材 |
| 只借结构与角度，正文全部自写 | 改写的上限 | 主张仍源自原作时，注明灵感来源 |
| 用户要求"意思不变、看不出是同一篇" | 洗稿诉求 | 说明判定依据，给两条出路，等用户选 |

判定依据不是字面重合率。司法实践用「接触 + 实质性相似」：接触过原作品、且在表达层面构成实质相似，即可认定侵权。平台原创审核同样比对主题、角度、素材、表达与结构。查重率低不构成免责——有案例把洗稿压到 25% 以下规避审核，仍属侵权。

## 七、完成度三档

| 档位 | 做了什么 | 可否发布 | 可否标原创 |
|---|---|---|---|
| 仅换表达 | 换句式、换人称、换语序 | 不可 | 不可，属同义替换 |
| 换表达 + 换案例 | 再加自有或授权案例，换比喻与过渡 | 可发，需授权或自有素材 | 一般不建议 |
| 再 + 自有判断 | 加入自己的结论、取舍或方法 | 可发 | 可，前提是核心判断由自己给出 |

停在第二档，就只主张"整理"或"引用 + 评论"，不主张原创。
