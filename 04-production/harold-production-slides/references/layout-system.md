# 版式系统

> 使用方式：主入口选页型、定节奏；本文提供每类页型的信息结构、具体参数与错误对照。数值按 16:9（13.333 × 7.5 英寸）标定，括号内为 1920 × 1080 画布下的像素近似值。

## A. 页面类型库

一页只用一个页型。页型由"这一页要让人记住什么"决定，不由素材多少决定。

| 页型 | 结构（位置 + 元素） | 容量上限 | 常见错 |
|---|---|---|---|
| 封面定调 | 左上小标签（栏目/编号/日期）→ 中部超大主标题 → 下方一句副标题 → 右下场景与版本 | 主标题 ≤2 行、每行 ≤16 字；副标题 ≤20 字 | 首屏放目录；标题加三个形容词；背景塞满装饰 |
| 观点落锤 | 页面中心一句强结论 → 下方一句解释 → 角落章节编号或关键词 | 主句 ≤18 字；解释 ≤30 字；0 个列表 | 主句写成两句；配三条 bullet；用问句代替判断 |
| 三格拆解 | 顶部页面标题 → 主体 3 张等宽等高卡片 → 底部一句总结 | 卡片小标题 ≤8 字；说明 ≤2 行、每行 ≤15 字；总结 ≤20 字 | 三格写四格；卡片文字长短悬殊；总结重复标题 |
| 数字证据 | 左侧一个巨大数字 → 右侧"这个数字是什么" + 2 条解释 → 底部口径与来源 | 数字 ≤6 字符；解释每条 ≤20 字 | 只放数字不解释；百分比不写基数；来源缺失 |
| 新旧分界 | 左栏旧世界 3 条 → 中间箭头或细线 → 右栏新世界 3 条 → 底部一句判断 | 每栏 ≤3 条、每条 ≤12 字；判断 ≤20 字 | 左 3 条右 5 条；两栏不一一对应却不说明；中间用花哨图形 |
| 对照页 | 左右双栏，同一指标各一组数据（对象名 + 数值 + 口径）→ 差距用单一强调色标注 → 底部一句判断 | 双栏等宽；差异项 ≤3 条；每条 ≤12 字；判断 ≤20 字 | 两栏指标口径不一致；差距用多种颜色；差异项超过 3 条 |
| 行动路径 | 顶部方法名 → 主体 4–6 步横向或阶梯排列 → 底部最终结果 | 每步"动词 ≤6 字 + 说明 ≤12 字"；≤6 步 | 步骤用名词开头；8 步挤一行；步骤不等距 |
| 摘录引用 | 左侧引号或编号 → 中部引用原文 → 下方出处与一句解释 | 引用 ≤40 字；一页 1 句 | 引用超过 3 行；无出处却写成名言；一页放两段 |
| 全局导航 | 左侧总标题 + 一句说明 → 右侧 3–5 张章节卡（编号 + 标题 + 一句目标） | 章节标题 ≤10 字；目标 ≤15 字；3–5 个 | 放在第 1 页；列 8 个章节；只写标题不写目标 |
| 收尾定锚 | 一句判断或总结 → 一个下一步（谁 / 做什么 / 何时）→ 可选联系方式 | 判断 ≤20 字；下一步 ≤25 字 | 只写"谢谢"；二维码占半页；临时加新观点 |

### 结构细节

- **观点落锤**：主句必须是可被反驳的判断，不是描述。一页只有一句，解释句只负责补条件，不补充论点。
- **数字证据**：左侧数字与右侧解释视为一个整体，读数顺序是"数字 → 它是什么 → 为什么重要 → 口径"。变化幅度必须写清"相对谁、哪段时间"。
- **新旧分界**：左右条目数量不一致时，在底部判断句里说明差异原因；不能让人误以为一一对应。
- **对照页**：两个对象必须用同一指标、同一口径、同一量纲；差距只用一个强调色标注，其余保持灰阶；差距处同时直接标数值或加箭头 / 下划线，保证色觉差异与黑白打印下仍可读（颜色不作唯一编码）。
- **行动路径**：步骤数 ≥7 时拆成两页（前半"做什么"、后半"怎么落地"）；横向排列超过 6 个必然拥挤。
- **全局导航**：只承担"我们要去哪"，不承担论证；每张章节卡的"目标"要能和后面的页面一一对上。
- **收尾定锚**：判断句回答"所以呢"，下一步回答"然后呢"，两者缺一不可。

## A2. 图表选型（数据页专用）

图型由"这组数据要说明什么关系"决定，不由素材好不好看决定。先定关系，再选图型，最后配色。

| 要说明的关系 | 图型 | 关键要求 | 不要用 |
|---|---|---|---|
| 类别之间谁多谁少 | 横向条形图（类目多或名称长时） | 按数值排序；条文末端直接标数值 | 饼图比长短 |
| 随时间怎么变 | 折线图 | 标起点、拐点、终点；Y 轴不截断 | 堆叠面积图掩盖单条趋势 |
| 构成与占比 | 100% 堆叠条；≤4 项可用饼图 | 标最大项与"其他"；合计写 100% | 5 项以上用饼图 |
| 分布形态 | 直方图 / 箱线图 | 标中位数与样本量 | 只给平均数 |
| 两个量是否相关 | 散点图 | 标相关系数与样本量；写"相关不等于因果" | 用折线连接离散点 |
| 单一关键量级 | 大数字（数字证据页） | 数字 + 单位 + 基数 + 口径 | 数字孤零零不解释 |

通用规则：

- 图表标题写结论（同页面标题规则），不写"销售数据"。
- 坐标轴写单位；来源必标；无来源不上图。
- 配色 ≤3 色；差异项在图上直接标数值，不靠读者比长度或辨颜色。
- 一页一张主图；需要两图对比时，两图同尺寸、同坐标范围。

## B. 字号与层级

| 角色 | 字号（pt） | 行高 | 上限 |
|---|---|---|---|
| 封面主标题 | 36–54（≤12 字可到 54） | 1.05 | 2 行，每行 ≤16 字 |
| 章节页主标题 | 36–44 | 1.1 | 1 行 |
| 页面标题（结论句） | 28–34 | 1.2 | 2 行，每行 ≤16 字 |
| 观点落锤主句 | 40–52（≤10 字可到 60） | 1.15 | ≤18 字 |
| 卡片小标题 | 22–24 | 1.3 | ≤8 字 |
| 正文 / 要点（投影） | 18–20 | 1.5 | ≤15 字 / 条 |
| 正文 / 要点（自阅） | 12–14 | 1.5 | ≤15 字 / 条 |
| 图注 / 来源 | 12–14（自阅 10–12） | 1.4 | 1 行 |
| 大数字 | 100–140 | 1.0 | ≤6 字符 |
| 页码 | 10–12 | — | — |

规则：

- 一页最多 4 个字号层级；层级越多，观众越找不到重点。
- 上限按最小字号计；单行字数越多，字号越要取区间下限，否则会溢出。
- 投影场景正文不小于 18pt，自阅文档不小于 12pt，图注与来源不小于 12pt（自阅 10pt）；低于 12pt 的内容只进演讲备注或自阅版，不上投影页。
- 字号调大后单页字数与行数上限不变；装不下就拆页，不得回缩字号。
- 换算口径：1pt ≈ 1.333px（96dpi）；版式参数统一用 px 标注，字号可用 pt，换算按此口径。
- 字重最多 2 种（常规 + 半粗）；中文不用斜体、不整段加粗、不全部大写。
- 强调靠字号和字重，不靠三种以上颜色。
- 数字使用等宽数字；中英混排时中英文之间留约 1/4 字宽空隙。
- 标题不用句号；正文不用首行缩进。

## C. 留白与间距

| 项 | 取值 | 说明 |
|---|---|---|
| 左右外边距 | 0.75–1.0 in（108–144 px） | 全篇一致，不随页型变 |
| 上下外边距 | 0.6–0.8 in（86–115 px） | 底部留页码与来源位 |
| 栏间距 | 0.35–0.5 in | 三栏内容按此值分隔 |
| 卡片内边距 | 0.25–0.35 in | 四边相等，不压文字 |
| 标题到正文 | 0.2–0.3 in | 小于此值会粘连 |
| 区块间距 | ≥1.5 倍正文行高 | 用间距分组，不用分割线 |
| 文字覆盖率 | ≤60% | 设计目标，不参与计分 |
| 单页文字总量 | ≤120 字 | 观点页 ≤60；数据页 ≤80；导航页 ≤100 |
| 单页正文行数 | ≤6 行（不含标题） | 超过即拆页 |
| 单行字数 | 18–28 字 | 超过 30 字读者会串行 |

其它：

- 对齐只用左对齐或居中，一页内只用一种；不用两端对齐（中文会出现空洞）。
- 不用边框围住每个区块；优先用留白分组，其次用浅色底，最后才用线。
- 同一套 PPT 的页边距、标题基线位置必须全篇一致，这是"看起来有设计系统"的主要来源。

## D. 网格与分栏

- 12 栏网格，栏间距 0.35 in；常用切分为 2 栏（6/6）、3 栏（4/4/4）、4 栏（3/3/3/3）。
- 三格拆解必须等宽等高；改宽度就等于改变信息权重，除非内容本身有权重差异。
- 章节卡 5 个时用"3 + 2"或纵向列表，不硬排 5 列。
- 行动路径 4–6 步等距排列；步骤之间间距应大于步骤内部行距，避免读成一段话。
- 图文并排时，文字区与图片区的分隔线落在网格线上，不落在任意位置。

## E. 配色

每套 PPT：背景 60%、文字与结构 30%、强调色 ≤10%。编辑手册与暗场全篇只保留一个强调色；模块卡片用三色分工（见下）。

| 风格族 / 方向 | 背景 | 主文字 | 次文字 | 强调 | 线条 |
|---|---|---|---|---|---|
| 暗场冲击 | #0B0E13 | #F5F1E8 | #9AA3AE | #C9A227 或 #4C7DFF（二选一） | #2A2F38 |
| 模块卡片 | #0E1B2C | #F2F4F7 | #A9B6C4 | 珊瑚 #E4572E / 青绿 #2EC4B6 / 琥珀 #F2A541 | #24405C |
| 编辑手册 · 黑白编辑 | #F7F4EE | #1A1A1A | #6B665E | #9C4221 | #D9D3C7 |
| 编辑手册 · 蓝瓷研究 | #F4F7FA | #0F2740 | #5B7288 | #1F5F99 | #D6E0E8 |
| 编辑手册 · 森系长文 | #F3F1E7 | #1E3327 | #5E6F62 | #3F6B4F | #D8D6C6 |
| 编辑手册 · 暖纸叙事 | #FAF3E7 | #2E241C | #7A6A5A | #96562A | #E2D6C3 |
| 编辑手册 · 沙岩品牌 | #EFEAE3 | #2B2B2B | #5F594F | #7A5F3C | #D8D0C4 |

规则：

- 正文与背景对比度 ≥4.5:1；24pt 以上大字 ≥3:1。
- 表中色值已按各自背景实测，正文级均 ≥4.5:1。改动任一色值（换色、调深浅、加透明度）必须重新复算对比度；半透明色按与背景混合后的实际色值计，凭观感判断不算数。
- 状态与差异不能只用颜色区分：颜色之外至少再叠一种编码（数值标注、形状、箭头或文字标签）。
- 模块卡片的三色是"分工色"，不是装饰色：一色用于编号、一色用于结论、一色用于行动，全篇保持一致。该例外只适用于模块卡片，编辑手册与暗场仍为单强调色。
- 红色只用于风险、错误、负向数据；不要做装饰。
- 图表配色不超过 3 色，其余用同一色系的明度变化。
- 一套 PPT 中途不换背景色；章节页可用同色系加深一档。

## F. 图文搭配

两套交付方案，默认都给无图版：

| 方案 | 适用 | 要求 |
|---|---|---|
| 有图增强 | 已有产品图、截图、案例图或可用绘图工具 | 图必须服务观点；一页 1–2 张；封面图与主题强相关 |
| 无图稳态 | 无图片素材（多数场景） | 用标题、留白、卡片、分栏、数字、时间线、对照表建立质感 |

图文比例：

| 页面类型 | 图片占版面 | 说明 |
|---|---|---|
| 观点页 / 摘录页 | 0–30% | 最多一张小图或不用 |
| 对照页 / 流程页 | 0–20% | 图标不算图，全篇图标只用一种线宽 |
| 案例页 | 40–50% | 图注写明来源与场景 |
| 封面 / 全幅图页 | 60–80% | 压字处加 40–60% 遮罩 |

其它规则：

- 图片不拉伸变形，锁定纵横比；截图裁掉无关界面，只留要说明的区域。
- 图上已有文字时，不叠加新文字；必须叠加时先加遮罩并保证对比度。
- 全幅图最多每 3 页出现一次；连续两页全幅图视为节奏失控。
- 不放与观点无关的装饰图、渐变球、通用商务素材。
- 图中数据必须有口径；无来源的图不上页面。

## G. 页面节奏

- 疏页（观点、封面、引用）与密页（三格、数据、流程）交替。
- 疏密按单页上屏字数分档：疏 ≤60 字、中 61–100 字、密 101–120 字（或含 3 块以上卡片 / 数据）。
- 连续 3 页同版式必须更换。
- 每 4–6 页插入一个章节页或观点落锤页。
- 第一页钩子，第二或第三页给导航；结尾必须有判断或行动。

10 页示范节奏（示例，非真实数据；用 6 类页型）：

| # | 页型 | 疏密 | 作用 |
|---|---|---|---|
| 1 | 封面定调 | 疏 | 给出主题与冲突 |
| 2 | 观点落锤 | 疏 | 一句话结论 |
| 3 | 全局导航 | 中 | 说明路径 |
| 4 | 三格拆解 | 密 | 拆三个原因 |
| 5 | 数字证据 | 疏 | 给一个关键量级 |
| 6 | 三格拆解 | 密 | 拆三个落地模块 |
| 7 | 数字证据 | 疏 | 给第二个关键量级 |
| 8 | 观点落锤 | 疏 | 回应预设反驳 |
| 9 | 收尾定锚（判断） | 疏 | 回到主张 |
| 10 | 收尾定锚（行动） | 中 | 下一步与责任 |

本示范用 6 类页型（封面定调 / 观点落锤 / 全局导航 / 三格拆解 / 数字证据 / 收尾定锚），符合"全套 ≤6 类"。需要加入行动路径、新旧分界、对照页或摘录引用时，替换掉一个重复页型，不得叠加到 7 类以上。

## H. 常见错误对照

| 不该做 | 该做 |
|---|---|
| 标题写"背景介绍""项目进展" | 标题写结论："行业进入重构期" |
| 一页 8 条 bullet、每条两三行 | 拆成两页，每页 ≤3 条 |
| 放不下就缩到 10pt | 拆页，或把细节移入演讲备注 |
| 每页都是三格卡片 | 按页型换骨架，疏密交替 |
| 用 4 种字号 + 3 种强调色 | ≤4 级字号；1 个强调色（模块卡片的三色分工除外） |
| 三栏等宽里塞不等量内容 | 等量内容才等宽；不等量改纵向 |
| 数字只写"增长 3 倍" | 写清"相对谁、哪段时间、口径" |
| 引用没出处 | 标来源；无来源不用引号包装 |
| 封面做成目录 | 封面给钩子，目录放第 2–3 页 |
| 结尾只有"谢谢" | 一句判断 + 一个下一步 |
| 截图带浏览器边框和无关 UI | 裁到信息区，必要时加标注 |
| 全篇同一种深色 + 满屏装饰 | 留白 ≥40%，装饰服务于观点 |

## I. 单页自检

- [ ] 这一页能用一句话说清（且这句话就是标题）
- [ ] 页型唯一，结构与内容匹配
- [ ] 字数与行数在上限内（≤120 字、正文 ≤6 行）
- [ ] 字号不低于下限，层级 ≤4 级
- [ ] 边距、标题基线与其他页一致
- [ ] 强调色只有一个（模块卡片为三色分工），对比度达标
- [ ] 图 / 数字有口径与来源，或明确标注"示例，非真实数据"
- [ ] 删掉本页，整套论证会出现缺口（否则考虑合并或删除）
