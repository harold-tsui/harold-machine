# Production Slides · 版式落地

> 一句话：论点已经定了，这一层只回答"这一页长什么样"。

## 核心定位

- 适用：汇报、内部培训、发布、研究报告的逐页版式方案；把内容清单落成可交给 PPT / Keynote / Canva / WPS 的页面说明。
- 不适用：内容还没定、论点排序、数据计算、纯插画设计。
- 上游边界：叙事顺序与每页结论由 `harold-production-pack` 产出。本技能不新增、不合并、不重排论点；某页没有结论句时退回上游，不替它编。
- 默认交付：页面节奏表 + 三页试样 + 全套逐页规格 + 自检记录。

## 触发场景

- "页面清单有了，帮我定每页用什么版式"
- "这十页每页都在堆字，帮我压一下"
- "这套 PPT 每页都长一样，调调节奏"
- "没有配图工具，也要做得像样"
- "把这段结论做成一页观点页"

## 工作流

### Step 0 接料检查（缺一项先问，不要开工）

| 项 | 合格标准 | 缺失时 |
|---|---|---|
| 页面清单 | 每页一句结论，顺序已定；含时长或字数 | 退回 `harold-production-pack` |
| 页面数据 | 每页关键图/表、数据与口径、来源（与 pack 清单同列搬运） | 缺口径的页只做结构、不上数字；缺来源按"示例，非真实数据"标注或改用无图结构，并写入退回清单 |
| 视觉方向 | 先选族（暗场冲击 / 模块卡片 / 编辑手册），选编辑手册时再定方向；或允许默认 | 默认：编辑手册 · 黑白编辑 |
| 交付条件 | 工具、是否有图、投影还是自阅 | 按"无图 + 投影"处理并标注假设 |

只有主题、没有页面清单时，只做页型建议，不产出成品；用户急要版式时，最多给"母版骨架"（封面、章节页、正文页各一），并标注"内容待定，结构变化可能作废"。

### Step 1 选视觉方向

一套只选一个族与一个方向，中途不换色。

| 风格族 | 用在什么内容 | 气质 |
|---|---|---|
| 暗场冲击 | 趋势判断、发布开场、终局结论 | 深底、大标题、单一强调色、压迫感 |
| 模块卡片 | 内部培训、方法论、步骤拆解、清单 | 深底、三色分工、卡片与步骤条 |
| 编辑手册 | 汇报、研究、方案、深度内容 | 浅底、大留白、细线、分栏、靠比例取胜 |

选择规则：不知道选哪个 → 编辑手册；AI / 科技 / 研究 → 编辑手册 · 蓝瓷研究；要活泼 → 模块卡片；要稳 → 编辑手册 · 黑白编辑。编辑手册共 5 个方向：黑白编辑（默认）/ 蓝瓷研究 / 森林长文 / 暖纸叙事 / 沙岩品牌。色值与方向细分见 references。

### Step 2 标页面类型

十类页型，一页只标一个。全套 ≤6 类（10 页规模通常 4–6 类）；用满说明没做取舍。

| 页型 | 什么时候用 | 结构公式 |
|---|---|---|
| 封面定调 | 首屏、章节开场 | 小标签 + 主标题（≤2 行）+ 一句副标题 + 角落场景/日期 |
| 观点落锤 | 开场钩子、核心判断、金句 | 主句（≤18 字）+ 解释（≤30 字）+ 角落编号 |
| 三格拆解 | 三原因、三趋势、三模块 | 标题 + 3 等宽卡片（编号 + 小标题 + 2 行说明）+ 一句总结 |
| 数字证据 | 数据、成果、变化幅度 | 左大数字 + 右含义 + 2 条解释 + 底部口径 |
| 新旧分界 | 过去/现在、误区/正解 | 左旧 3 条 + 右新 3 条 + 中间分割 + 底部一句判断 |
| 对照页 | 同一指标对比两个对象（方案 / 竞品 / 前后版本） | 左右双栏，同一指标各一组数据 + 差距用单一强调色标注 + 底部一句判断 |
| 行动路径 | 方法步骤、执行路径 | 方法名 + 4–6 步（动词开头）+ 底部结果 |
| 摘录引用 | 金句、反馈、关键洞察 | 引号 + 引用（≤40 字）+ 出处 |
| 全局导航 | 总览、报告结构 | 左总标题 + 右 3–5 章节卡（编号 + 标题 + 一句目标） |
| 收尾定锚 | 结尾 | 一句判断（≤20 字）+ 一个下一步（谁 / 做什么 / 何时） |

选型规则：18 字内能说清的判断 → 观点落锤；三项并列 → 三格；只有一个数字 → 数字证据；有"以前 vs 现在" → 新旧分界；同一指标比两个对象 → 对照页；超过 6 步 → 先拆两页。完整结构与容量见 references。

### Step 3 套内容（四条硬规则）

1. 标题写结论句，不写话题。"行业背景" → "行业进入重构期"。
   - 结论句优先写"事实（含数字与对比对象）+ 含义"；无数字时写"判断 + 对决策的含义"。页面标题 ≤2 行、单行 ≤16 字，超出压成"标题 + 副标题"，不得缩字号。
   - 标题是名词短语但内容里有可支撑的事实 → 就地改写成结论句（保留原数据，不新增结论）。
   - 内容里没有任何可支撑事实 → 不猜，该页标"待补结论"并列入退回清单，其余页继续交付。
   - 封面、章节过渡页、纯图页豁免"结论句标题"，但必须有信息性标题（人物 / 时间 / 主题），不能是"封面""谢谢"。

   **标题连读测试（成套检查）**：全部页标题按顺序连起来读一遍，必须是一条能独立读懂的论证链。
   - 通过：每句有主语与判断，相邻页之间有"因为 / 但是 / 所以"的推进。
   - 不通过：断链（相邻页无逻辑关系）、重复（两页说同一件事）、无递进（全是并列陈述，没有结论收束）。
   - 不通过时只写入"退回上游"清单，写明缺哪一环、需 `harold-production-pack` 补什么；**不自行重排、不补标题**。
2. 一页一个核心观点，最多 3 个要点，每个要点 ≤15 个中文字符；正文不写长段落。
   - 三个要点必须并列：同一层级、同一句式、同一粒度（都是原因 / 都是步骤 / 都是对比项）；不允许一个是原因、一个是数据、一个是行动。
3. 放不下就拆页，不缩字号、不压行距。单页文字总量上限见 references。拆页后重排页码，正文引用"见第 X 页"必须同步更新；交付前做一次页码连续性检查。
4. 页面上只保留上屏字，且上屏字 ≠ 讲稿逐字。
   - 上屏字是"要记住的"（结论、关键词、数字）；讲稿是"要听懂的"（论证、例子、转场）。同一句既上屏又原样念，读与听争同一通道，理解反而下降。
   - 必须逐字上屏的场合（报价、法务原文、口径定义）：标注"念稿模式"，该页不受 ≤120 字上限约束，但须在交付说明里列出并写明原因。
   - 演讲备注写三件套：这页要证明什么（一句）/ 不上屏的证据与口径 / 与下一页的转场或最可能的提问。

### Step 4 排节奏

- 疏页与密页交替；连续 3 页同版式必须换。
- 每 4–6 页安排一个章节页或观点落锤页。
- 第一页给钩子，不给目录；目录放第 2–3 页。
- 结尾必须有总结、行动或判断，不能只有"谢谢"。

### Step 5 给参数

字号、间距、配色、图文比例从 references 取值，写具体数值，不写"美观大方"。
版式参数统一用 px 标注，字号可用 pt；1pt ≈ 1.333px（96dpi），换算按此口径。
字号下限按介质分：投影正文 ≥18pt，自阅正文 ≥12pt，图注与来源 12–14pt；低于 12pt 的内容只进演讲备注或自阅版，不上投影页。
数据页先按 references「图表选型」定图型，再配色；图型由数据关系决定，不由素材好不好看决定。
无配图时走无图稳态版：用标题、留白、卡片、分栏、数字、时间线、对照表；不编造图片、数据、出处。

交付介质决定版本，同一套内容只改密度，不改论点与页序：

| 版本 | 字号 | 单页字数 | 说明 |
|---|---|---|---|
| 投影 | 按上面下限 | ≤120 字 | 一页一屏，不安排滚动或翻页细节 |
| 自阅（PDF / 邮件） | 正文 12pt 起 | 可补到 ≤300 字 | 允许 2 段说明，图注可 10pt |
| 双端 | 先做投影版 | 另出讲义版 | 讲义内容进页下注或附录，不塞回投影页 |

### Step 6 三页试样 → 确认 → 全套

默认试样：封面、观点落锤或全局导航、三格拆解或行动路径（核心机制）。
试样一律用真实内容，不用占位文案；确认项限定为视觉方向、页型骨架、版式参数，不讨论"好不好看"。
用户确认方向后再输出全套，避免整套返工。
交付物只有一页时（如"把这段做成一页观点页"），跳过三页试样与节奏编排，直接出该页规格；自检第 7、8 项按 N/A 记录，判定按 N=6 / 阈值 5 复算。

### Step 7 自检

按"验收标准"逐项打勾，未过项写明改法。

## 验收标准

**阻塞项：任一为 0，不得交付，不看计分项。**

- [ ] B1 不越界：不新增、合并或重排上游论点；页面清单或结论句缺失时退回上游，不替上游补论点
- [ ] B2 不编造：图片、数据、出处均有来源，没有就换无图结构；示例数字标注"示例，非真实数据"
- [ ] B3 标题合格：内容页标题为结论句；无事实可支撑的标"待补结论"并列入退回清单，不编造结论；页面标题 ≤2 行、单行 ≤16 字；封面、章节过渡、纯图页豁免结论句，但须有信息性标题

**计分项：**

- [ ] 1 接料检查完整：页面清单、每页结论句、数据与来源字段齐备（缺项已标"待补"），退回项写明需上游补什么
- [ ] 2 页型标注正确：一页一型，全套 ≤6 类（10 页规模通常 4–6 类）
- [ ] 3 单页 ≤3 要点、每点 ≤15 字，上屏总字数 ≤120（观点页 ≤60 / 数据页 ≤80 / 导航页 ≤100），正文 ≤6 行，无长段落；三个要点并列（同层级、同句式、同粒度）；上屏不是讲稿逐字
- [ ] 4 信息放不下时拆页而非缩字号；拆页后页码与"见第 X 页"引用已同步；拆后总页数已回填核对，仍在 pack 给的时长 / 页数区间内（按 pack 的 1–2 分钟/页口径复算，不另立算法），超出时写明取舍（移入备注或附录、压缩其他页、退回上游）
- [ ] 5 字号 / 间距 / 配色给出具体数值，且与 references 一致（版式参数用 px，字号可用 pt）；正文对比度 ≥4.5:1、≥24pt 大字 ≥3:1；强调色 1 个（模块卡片为三色分工）；改动 references 色值后已复算对比度；差距与状态不只靠颜色区分（叠加数值、形状或箭头）
- [ ] 6 结尾有判断或行动；自检记录完整，并记录标题连读结论（通过 / 列入退回上游的缺口）
- [ ] 7 三页试样先行：先出封面 / 观点落锤或导航 / 三格拆解或行动路径（核心机制）三页试样，用户确认后才给全套；用户明确要求一次出全套时，已标注整套返工风险，并把试样作为第一版
- [ ] 8 节奏成立：首屏是钩子不是目录（目录在第 2–3 页）；每 4–6 页有章节页或观点落锤；疏页与密页交替；无连续 3 页同页型

判定：阻塞任一为 0 = 重做；阻塞全过 + 计分 ≥⌈0.8×N⌉ = 可交付；计分 ≤阈值-1 = 重写。N = 8，阈值 = ⌈0.8×8⌉ = 7；交付物只有一页内容时，第 7 项（三页试样）与第 8 项（节奏）无适用空间，两项 N/A → N = 6、阈值 5。N/A 仅限材料本身不具备该情形（单页任务无试样与节奏），漏做不算 N/A；用户豁免某项时仍计入分母，自检记为未做。

## Gotchas

1. **用版式救内容**
   一页塞三个结论，换成卡片布局也救不回来。先拆页，再谈版式。

2. **缩小字号硬塞**
   观众看不见的字等于没写。投影正文低于 18pt、要点超过 3 条，就是该拆页的信号；低于 12pt 的来源行只属于自阅版或演讲备注。

3. **整页装饰当设计**
   与观点无关的图标、渐变、插画只会稀释信息。编辑手册风靠留白与比例，不靠贴图。

4. **每页都做成卡片墙**
   十页同一种三格布局，观众第三页就走神。版式必须随页型换。

5. **替上游补论点**
   "这页标题没结论，我帮你编一个"——这是越界。缺结论就退回 `harold-production-pack`。

6. **编造数据或出处**
   数字没有口径、引用没有来源，宁可不放。示例数字必须标注"示例，非真实数据"。

7. **把讲稿搬上屏，再照着念**
   整段文字既上屏又原样念，观众要么读要么听，两边都丢一半。上屏只留结论与关键词，论证进备注；必须念原文时标"念稿模式"。

8. **只用颜色标差距**
   对照页用红绿区分好坏，色觉差异者看不出差别，黑白打印也全丢。颜色之外必须再有数值、箭头或文字标签。
