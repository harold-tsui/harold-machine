# 验收用例：版式落地

> 文中出现的页数、样本量与百分比均为示例，非真实数据。

## Case 1 · 10 页汇报，每页都在堆字

**输入**："这是我的 10 页汇报，每页大概 8 条要点，帮我排得好看一点。内容我已经定好了。"

**期望特征**
- 先判断这是密度问题，不是美化问题；不直接套模板。
- 逐页给出字数预算：单页 ≤3 个要点、每点 ≤15 字、上屏 ≤120 字且正文 ≤6 行。
- 优先拆页而不是缩字号：按 pack 的 1–2 分钟/页口径复算（15 分钟 8–15 页，推荐 10–15），10 页可扩到 12–14 页；扩页后总页数须仍落在 pack 给的时长区间内，超出则说明哪些内容移入演讲备注或附录，或退回上游压缩。
- 拆页后投影正文不小于 18pt，不靠缩到 12–14pt 换取容量；字号调大而装不下时继续拆页。
- 先出三页试样（封面 / 观点落锤或导航 / 三格拆解或行动路径）交用户确认，确认后才展开全套逐页规格。
- 为拆后的页面标页型（观点落锤 / 三格拆解 / 数字证据等），不出现连续 3 页同版式。
- 拆完把全部标题连起来读一遍，检查是否成链；断链或重复处写进"退回上游"清单，不自行重排论点。
- 上屏只留结论与关键词，不把要念的整段话搬上页；三个要点同层级、同句式、同粒度。
- 不删除论点：需要取舍时列出"建议移出"清单，交用户确认。
- 若某页只有名词短语标题：内容里有可支撑事实就地改写成结论句（保留原数据），没有可支撑事实则标"待补结论"列入退回清单，不代为编造，其余页继续交付。

**常见失败**：直接给 10 页漂亮模板；把 8 条压成 8 条小字；擅自删掉一半内容；每页都做成卡片。

## Case 2 · 把一段结论改成一页观点页

**输入**："把这段改成一页：我们调研了 20 家客户，其中 16 家表示不愿意为这项功能额外付费，原因主要是已有替代方案，其次是预算收紧。这说明这个功能短期内不适合单独立项，建议先并入现有套餐做验证。"

**期望特征**
- 提炼一句可被反驳的判断作为主句，≤18 字，例如"该功能短期不宜单独立项"。
- 解释句 ≤30 字，只补条件（对象、时间、范围），不展开第二条论点。
- 不上列表、不排三格、不加图标；页型明确标为"观点落锤"。
- 保留出处与口径：20 家样本、16 家、调研时间；不把 16/20 说成"80% 的用户"而不写基数。
- 被舍弃的调研细节放入演讲备注或下一页，不偷偷丢掉。
- 不新增原段落没有的结论（如"市场完全没有需求"属于过度外推）。
- 单页交付跳过三页试样与节奏编排；自检第 7、8 项记 N/A，判定按 N=6 / 阈值 5 复算。

**常见失败**：把原段落压缩后原样放上页面；主句写成"关于功能立项的调研结论"；配上柱状图稀释观点；扩写成三条并列洞见。

## Case 3 · 先要好看版式，内容还没定

**输入**："先帮我做一版高级一点的 PPT 版式，内容我后面再补，先要好看着急用。"

**期望特征**
- 拒绝成套版式先行，说明返工成本：结构一变，版式要重做。
- 给最小可行路径：先产出页面清单（每页一句结论）→ 确认 → 三页试样 → 全套。
- 引导回内容层 `harold-production-pack`，说明本技能只做版式落地。
- 如用户坚持，最多给"母版骨架"（封面、章节页、正文页各一），并标注"内容待定，结构变化可能作废"。
- 不虚构主题与文案来填满页面，不把骨架包装成成品交付。

**常见失败**：直接输出十页精美样张；用占位文案假装内容；答应"后面直接套"；全程不谈结构风险。

## 评分表（3 项阻塞 + 8 项计分，逐项 0/1）

**阻塞项：任一为 0，不得交付，不看计分项。**

| # | 检查项 |
|---|---|
| B1 | 不越界：不新增、合并或重排上游论点；页面清单或结论句缺失时退回上游，不替上游补论点 |
| B2 | 不编造：图片、数据、出处均有来源，没有就换无图结构；示例数字标注"示例，非真实数据" |
| B3 | 标题合格：内容页标题为结论句；无事实可支撑的标"待补结论"并列入退回清单，不编造结论；页面标题 ≤2 行、单行 ≤16 字；封面、章节过渡、纯图页豁免结论句，但须有信息性标题 |

**计分项：**

| # | 检查项 |
|---|---|
| 1 | 接料检查完整：页面清单、每页结论句、数据与来源字段齐备（缺项已标"待补"），退回项写明需上游补什么 |
| 2 | 页型标注正确：一页一型，全套 ≤6 类（10 页规模通常 4–6 类） |
| 3 | 单页 ≤3 要点、每点 ≤15 字，上屏总字数 ≤120（观点页 ≤60 / 数据页 ≤80 / 导航页 ≤100），正文 ≤6 行，无长段落；三个要点并列（同层级、同句式、同粒度）；上屏不是讲稿逐字 |
| 4 | 信息放不下时拆页而非缩字号；拆页后页码与"见第 X 页"引用已同步；拆后总页数已回填核对，仍在 pack 给的时长 / 页数区间内（按 pack 的 1–2 分钟/页口径复算，不另立算法），超出时写明取舍（移入备注或附录、压缩其他页、退回上游） |
| 5 | 字号 / 间距 / 配色给出具体数值，且与 references 一致（版式参数用 px，字号可用 pt）；正文对比度 ≥4.5:1、≥24pt 大字 ≥3:1；强调色 1 个（模块卡片为三色分工）；改动 references 色值后已复算对比度；差距与状态不只靠颜色区分（叠加数值、形状或箭头） |
| 6 | 结尾有判断或行动；自检记录完整，并记录标题连读结论（通过 / 列入退回上游的缺口） |
| 7 | 三页试样先行：先出封面 / 观点落锤或导航 / 三格拆解或行动路径（核心机制）三页试样，用户确认后才给全套；用户明确要求一次出全套时，已标注整套返工风险，并把试样作为第一版 |
| 8 | 节奏成立：首屏是钩子不是目录（目录在第 2–3 页）；每 4–6 页有章节页或观点落锤；疏页与密页交替；无连续 3 页同页型 |

判定：阻塞任一为 0 = 重做；阻塞全过 + 计分 ≥⌈0.8×N⌉ = 可交付；计分 ≤阈值-1 = 重写。N = 8，阈值 = ⌈0.8×8⌉ = 7；交付物只有一页内容时，第 7 项（三页试样）与第 8 项（节奏）无适用空间，两项 N/A → N = 6、阈值 5。N/A 仅限材料本身不具备该情形（单页任务无试样与节奏），漏做不算 N/A；用户豁免某项时仍计入分母，自检记为未做。
