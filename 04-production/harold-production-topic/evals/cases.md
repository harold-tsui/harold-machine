# 验收用例：选题

## Case 1 · 给一堆链接就要写

**输入**："这周的热点我都放这了，你挑一个写吧。"

**期望特征**
- 先补口径：目标读者是谁、发在哪、这周有没有时间窗口。
- "你挑一个写吧"视为代选授权：自选 1 条并标"代选，可回退"，不必停在短名单等回复。
- 输出宽池，每条带来源类型、时间、证据状态与失分维度，不给不带来源的候选。
- 用七维与三指标收敛到 2–3 条短名单，逐条给出保留 / 淘汰理由、覆盖量级与依据。
- 输出 12 项写作简报与至少 3 版标题，等确认后再写正文。
- 热榜题若读者关系为 ✘，明确淘汰，不因热度保留；单条爆款标"单点信号"，不当趋势。

**常见失败**：直接给一篇文章；按链接顺序挑第一条；只有结论没有筛选过程。

## Case 2 · 题很好但只能覆盖一小群人

**输入**："这个题我很想写，做跨境独立站的人都懂，但估计没多少人看。"

**期望特征**
- 判为高唤醒 + 窄覆盖，定级为"选写"。
- 给出上升路径：从这批人的具体处境折射更普遍的处境，并说明上升后哪些内容会变、哪些不变。
- 若无法上升到普遍处境，明确写"圈层内容，不建议主推"，并给出替代角度。
- 不把"我很想写"当成覆盖面的证据。

**常见失败**：因作者热情直接判必写；用"垂直领域也有价值"回避覆盖判断；上升到空泛人群，失去具体性。

## Case 3 · 要求把普通题改得像爆款

**输入**："这个题太普通了，帮我改得爆一点，标题越猛越好。"

**期望特征**
- 区分"改角度"与"改措辞"：指出原题的问题在角度，不在形容词。
- 给出 3–5 版标题，覆盖不同方向（处境焦虑 / 明确判断 / 身份表达），并说明各版对应的读者利益。
- 拒绝无事实底座的极端化：不编冲突、不编数据、不虚构人物。
- 标题强度与正文兑现度对齐：给出标题承诺在正文中如何兑现的说明；兑不了时先降强度，再考虑换角度。

**常见失败**：只做同义词替换；用夸张数字制造冲突；标题承诺超出材料能支撑的范围。

## Case 4 · 一轮筛下来没有及格的题

**输入**："这周就这些材料，你看能写哪个。"

**期望特征**
- 若合格题不足 2 条，输出"本周不推"或"建议换信源"，不硬凑到 2–3 条。
- 写清三条原因：缺哪一指标、缺什么材料、补哪类信源，并给补齐计划。
- 检索型刚需（政策、工具更新、流程清单）不按"低唤醒 = 不写"判死，标"资产型"并给收藏与复访判据。
- 负结论视为完成交付，不把"凑一个题"当成满足用户。

**常见失败**：为凑数放宽覆盖面；把两条弱题合并成一个模糊大题；直接说"没题可写"而不给补齐路径。

## 评分表（3 项阻塞 + 5 项计分，逐项 0/1）

**阻塞项：任一为 0，不得进入写作，不看计分项。**

| # | 检查项 |
|---|---|
| B1 | 口径 5 项有答案；缺失项写为假设并标注"待确认"；目标读者写明证据来源 |
| B2 | 短名单经过用户窄化：每条有保留 / 淘汰 / 合并 / 改角度的理由，没有未说明就定稿的题；合格题不足 2 条时给负结论与补齐计划，不硬凑 |
| B3 | 写作简报 12 项齐全；用户确认前没有输出正文；停在短名单的会话标"待确认"并止于短名单 |

**计分项：**

| # | 检查项 |
|---|---|
| 1 | 每条候选有来源类型与证据状态（已核 / 待核 / 材料不足）；"材料不足"的题留在宽池、不进短名单；趋势类候选有 ≥2 个独立来源且跨平台出现，否则标"单点信号"不进短名单 |
| 2 | 入短名单的题逐项给出三指标判断，不只给结论；覆盖面写量级区间与依据，无依据标"待核" |
| 3 | 定级落在四象限之一，并给出对应动作（必写 / 不写 / 选写 / 绝不写）；检索型刚需标"资产型"并给收藏与复访判据 |
| 4 | 标题 ≥3 版，且是角度变化，不是同义词替换；兑不了时先降强度，并标出缺哪块材料 |
| 5 | 简报中引用的数字与案例标明"已核 / 待核"，待核项不作为中心判断的唯一支撑 |

判定：阻塞任一为 0 = 重做；阻塞全过 + 计分 ≥⌈0.8×N⌉ = 可交付；计分 ≤阈值-1 = 重写。N = 5，阈值 = ⌈0.8×5⌉ = 4。本技能 5 项均适用、无 N/A 场景；漏做不算 N/A。
