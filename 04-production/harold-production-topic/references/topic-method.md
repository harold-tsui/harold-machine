# 选题方法

## 一、三硬指标

| 指标 | 判断问题 | 不过关的表现 | 过关的做法 |
|---|---|---|---|
| 覆盖面 | 是 1 万人关心，还是 1 亿人关心？ | 只有同行看得懂 | 从小众问题切到大众处境，如"写好 C++"→"35 岁还在写代码的人"；写量级区间（万级 / 十万级 / 百万级）与依据，依据用平台公开数据、读者反馈量或同类内容表现，无依据标"待核" |
| 张力 | 能不能一句话说清在冲突、反差或取舍什么？ | 只有情绪对骂，或让人误以为读者在互相对立 | 有可复述的张力；争议只是其中一种，对立落在事件、做法或外部对象上，不要求读者互相对立 |
| 获得感 | 是否替读者说出想说没说的话？ | 看完没有转发的理由 | 读者能借这篇内容表达自己的身份或立场 |

三项同时成立才进短名单。缺一项：降级为备选；缺两项：放弃。

**检索型刚需例外。** 政策变动、工具更新、流程清单、价格对比这类题唤醒度低但有人主动搜。不以"低唤醒 + 广覆盖 = 不写"判死，改判"资产型"：看是否有人搜、收藏与复访价值是否成立；成立则进短名单，标"资产型，长尾回收"，四象限照旧给出，动作不写"不写"。

**负结论。** 合格题不足 2 条时不硬凑，输出"本周不推 / 建议换信源"，写清缺哪一指标、缺什么材料、补哪类信源，并给补齐计划。这是合法交付。

张力的作用是让人有话说。争议只是张力的一种；反差、取舍、代价同样成立。如果对立发生在读者之间，读者会怕被反驳而少转发——所以对立必须指向问题一侧，不能划在读者之间。

## 二、情绪唤醒 × 覆盖矩阵

| 情绪唤醒 | 覆盖范围 | 定级 | 处理 |
|---|---|---|---|
| 高唤醒 | 广 | 必写 | 优先排期，配足素材；正面角度优先 |
| 低唤醒 | 广 | 不写 | 常规信息，没有传播势能 |
| 高唤醒 | 窄 | 选写 | 必须能折射普遍处境，否则归为圈层内容 |
| 低唤醒 | 窄 | 绝不写 | 纯干货、冷门知识，不硬推 |

高唤醒 = 愤怒、焦虑、敬畏、强烈共鸣；低唤醒 = 满足、平静、怀旧等提不起动作的情绪。判据是读者会不会产生转发或行动冲动，不是作者自己激不激动。

同等唤醒度下，能落到认同或共情的正面题比纯愤怒题更稳：纯愤怒提升评论，但压低信任与关注转化。

判断顺序：先看覆盖，再看唤醒度。反了会被"我自己很激动"误导。

## 三、二次加工三手法

1. **情绪优先于信息**
   先给读者一个能对上号的具体处境，再给方法。顺序反了就是说明书。

2. **二元对立**
   明确"反对什么 / 支持什么"，让判断可被复述。
   普通表达：新人要努力工作。
   加工后：把"努力"换成"在什么条件下努力才有用"。
   要求：对立面必须来自真实素材，不虚构对象。

3. **个案上升**
   从一个人的具体遭遇，指出一类人共同面对的结构问题。
   一个员工被裁 → 某类岗位的风险顺序；一次消费选择 → 某类人被如何说服。

## 四、标题改写四方向

| 原题类型 | 改写方向 | 示例（示例，非真实数据） |
|---|---|---|
| 方法干货 | 处境焦虑 | "如何提升职场竞争力" → "那个每天最早到的人，为什么先被优化" |
| 消费建议 | 明确判断 | "如何理性消费" → "劝你'对自己好点'的话，多半在替别人算账" |
| 产品功能 | 价值观筛选 | "早餐很好吃" → "别把生活过成免费早餐的样子" |
| 趋势观察 | 身份表达 | "年轻人不爱聚会" → "30 岁以后，离'看起来很忙'的人远一点" |

每个题至少出 3 版，覆盖不同方向；同一方向换词不算新版本。

**强度阶梯。** 优先级固定：真实准确 > 与正文一致 > 核心信息不误导 > 打开率。材料兑不了时按顺序处理：先降强度（弱化结论、限定范围、换兑现点）→ 再换角度 → 仍兑不了才整版不用，并写明缺哪块材料。不得为了强度编数字、编因果、编人物。

## 四之二、趋势判据

趋势与热点分两套判法：

| 类型 | 成立条件 | 不成立的处置 |
|---|---|---|
| 趋势 | ≥2 个相互独立来源；跨平台出现（社交 / 搜索 / 垂类至少两处）；已持续 ≥4 周 | 标"单点信号"，留宽池不进短名单 |
| 热点 | 以主体机构、当事方或权威媒体的原始发布为准，不看持续时长 | 只有转述、无原始出处的，标"待核" |

时长标注：2 周内"苗头"、4–8 周"可用信号"、8 周以上"确认趋势"。判据与标注同时写，不二选一。

## 五、候选记录表

| 字段 | 填写要求 |
|---|---|
| 主题 | 一句话，含具体对象 |
| 来源类型 | 公共热点 / 平台趋势 / 用户材料 / 垂类信源 |
| 时间 | 信号出现时间；常青题写"常青" |
| 目标读者 | 具体到处境，不写年龄区间 |
| 可讨论的问题 | 一句话，能形成判断分歧 |
| 证据状态 | 已核 / 待核 / 材料不足 |
| 建议动作 | 保留 / 淘汰 / 合并 / 改角度 / 待定 |

## 六、七维检查速查

- 读者关系：跟钱包、工作、身份、生活选择有关吗？
- 具体性：有明确对象、事件或知识点吗？
- 冲突性：有讲得清的矛盾或分歧吗？
- 时效性：窗口还在吗？热点按 ≤72 小时判、平台趋势按 ≤2 周判；常青题写明复查时点，不写"近期"。
- 差异性：有新案例、新问题或新结论吗？
- 证据性：有公开材料或可补充的事实吗？
- 兑现度：标题承诺的内容，正文讲得清吗？

七维只做通过与否，不折算分数；任何一维为 ✘ 都要在建议动作里说明影响，但不直接淘汰（证据性除外：证据性为 ✘ 的题不进短名单）。

宽池输出时，每条除基本字段外，列出判为 ✘ 或"待定"的维度名；全过写"无 ✘"。只写结论不写失分维度，等于七维没做。

与三指标的关系：七维判"能不能立住"，三指标判"值不值得推"；三指标只补判覆盖量级与获得感两项，冲突性沿用七维结论并补一句"对立落在哪一侧"。


简报确认前，不写正文；确认后新增事实冲突，标"待核"，不改主线。
