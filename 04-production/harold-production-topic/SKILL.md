# Production Line · 选题

> 一句话：先把题选对，再谈怎么写。

## 核心定位

- 适用：内容选题的发现、筛选、加工，以及开写前的方向确认（公众号、小红书、短视频、课程内容）。
- 不适用：正文写作（用 `harold-production-copy`）、事实核验（用 `harold-research-brief`）、商业取舍（用 `harold-decision-review`）。
- 一条线走到底：发现 → 筛 → 加工 → 简报 → 等开写信号。任何一步不跳。

## 触发场景

- "这周写什么"
- "这几个题哪个值得写"
- "帮我把这个题改得更有传播力"
- "先开个选题会，想清楚再写"
- "这个热点能不能跟"

## 工作流

### Step 0 口径（5 项）

目标读者 / 内容形式 / 发布平台 / 可用素材 / 时效窗口。
缺项只问一个最关键的，其余写假设并标注"假设，待确认"。目标读者要具体到处境，不写"25–35 岁职场人"；处境要能指到证据来源——读者原话、提问、评论或后台数据，只凭推测的写"假设，待确认"。
时效窗口写三档之一：热点 ≤72 小时 / 平台趋势 ≤2 周 / 常青（写明复查时点）；判不了写"待核"，不写"近期"。窗口已过的热点只走两条路：剥离时间钩子改成常青角度，或淘汰；不得以"待核"继续留在池里。
窗口要分两个时钟：信号已持续多久（判真伪，见 Step 1）、窗口还剩多久（判能不能写）。只剩一半以下的写"窗口紧张"，并在短名单里标注交付风险。

### Step 1 发现（候选池）

四类信源各自找，不混为一谈：

| 信源类型 | 找什么 |
|---|---|
| 公共热点 | 近期被广泛讨论的社会、消费、职场、商业事件 |
| 平台趋势 | 平台上正在上升的讨论、问答、评论反馈 |
| 用户材料 | 读者提问、评论、课程问题、业务观察、真实案例 |
| 垂类信源 | 目标行业的固定信息源，补热点之外的持续变化 |

每条候选记录：主题 / 来源类型 / 时间 / 目标读者 / 可讨论的问题 / 证据状态。
信源不可用时写"暂不可用"，不编造，也不把单一来源说成趋势。

趋势与热点分开判：

- 趋势类候选要同时满足三条才算成立——≥2 个相互独立的来源、跨平台出现（社交 + 搜索 + 垂类至少两处）、已持续 ≥4 周。缺任一条标"单点信号"，留在宽池不进短名单。
- 热点类不要求持续时长，按事件处理：以主体机构、当事方或权威媒体的原始发布为准，不拿转述当信源。
- 2 周内的增长写"苗头"，4–8 周写"可用信号"，8 周以上写"确认趋势"；三条判据与时长标注同时写，不二选一。

### Step 2 七维判断（形成宽池）

对每条候选逐维判断，只写 ✔ / ✘ / 待定，不打总分：

读者关系（跟钱包、工作、身份、生活选择有什么关系）、具体性（有明确对象或知识点）、冲突性（有讲得清的矛盾或分歧）、时效性（窗口是否还成立）、差异性（有没有新案例、新问题、新结论）、证据性（有无公开材料支撑）、兑现度（标题承诺的内容讲不讲得清）。

七维与三指标分工：七维是宽池初筛，判"能不能立住"，任一 ✘ 只记影响、不直接淘汰（证据性除外，见下）；三指标是短名单收紧，判"值不值得推"，只补判两项——覆盖量级（读者关系够不够大）与获得感（有没有转发理由）；冲突性直接沿用七维结论，只补一句"对立落在哪一侧"。获得感不并入覆盖面，单独判。
证据分两层：宽池可留"材料不足"，短名单只收"已核 / 待核"；"待核"可进短名单，但不得作为中心判断的唯一支撑。

宽池保留多样性，每条给：初步角度 / 读者利益 / 证据状态 / 建议动作（保留 / 淘汰 / 合并 / 改角度 / 待定），并列出判为 ✘ 或"待定"的维度名；七维全过写"无 ✘"。只写结论不写失分维度，等于七维没做。

### Step 3 三硬指标（收短名单）

| 指标 | 判断问题 | 过关标准 |
|---|---|---|
| 覆盖面 | 是 1 万人关心，还是 1 亿人关心？ | 能从小众问题切到大众处境；量级用平台公开数据、读者反馈量或同类内容表现估，写明依据，无依据标"待核" |
| 张力 | 能不能一句话说清在冲突、反差或取舍什么？ | 有可复述的张力，争议只是其中一种；对立落在事件、做法或外部对象上，不要求读者互相对立 |
| 获得感 | 是否替读者说出了想说没说的话？ | 读者愿意转发，借它表达自己 |

三项缺一，降级或放弃。短名单收 2–3 条，每条对应一种建议形式。

短名单每条必须写三件事：量级区间（万级 / 十万级 / 百万级，写不出版本按未判处理）、依据（数据或样本出处）、建议形式（公众号长文 / 小红书图文 / 短视频口播 / 课程单节 / 图文卡片，五选一，不自由发挥）。

**检索型例外。** 低唤醒 + 广覆盖的题若属读者会主动搜索的刚需（政策变动、工具更新、流程清单、价格对比），不以转发冲动判死，改判"资产型"：看是否有人搜、收藏与复访价值是否成立，成立则进短名单并标"资产型，长尾回收"；四象限照旧给出，动作不写"不写"。

**负结论是合法交付。** 合格题不足 2 条时不硬凑：输出"本周不推"或"建议换信源"，写清三条原因（缺哪一指标、缺什么材料、补哪类信源），并给一个补齐计划；这算完成，不算失败。

**产能闸。** 进短名单前判一次交付可行性：按窗口剩余时间是否有把握产出、手上是否有独家材料或一手案例。任一不成立，动作只能是"改角度"或"移到常青池"，不得凭热度保留。

短名单必须交用户窄化：每条写明保留 / 淘汰 / 合并 / 改角度的理由，用户选定 1 条后才进 Step 4。两种授权模式：

- **代选**：用户明确说"你挑一个写""按你的判断选"时，视为已窄化。自选 1 条，标"代选，可在简报阶段回退到第 2 条"，直接进 Step 4。
- **未授权**：停在短名单，输出止于短名单并标"待确认"。这是合法中间交付，不判 B3 失败；只有进入 Step 5 的会话才受简报 12 项约束。

不把"待定"自行改成定稿，也不因用户不回就跳过筛选。

### Step 4 定级与加工

高唤醒 × 覆盖范围定级（按读者会不会产生转发或行动冲动判，不按自己是否激动）：高唤醒 + 广覆盖 = 必写；低唤醒 + 广覆盖 = 不写；高唤醒 + 窄覆盖 = 选写（须能折射普遍处境）；低唤醒 + 窄覆盖 = 绝不写。高唤醒指愤怒、焦虑、敬畏与强烈共鸣；同等强度下优先能落到认同或共情的正面角度，纯愤怒题易起评论但伤信任，不作首选。

判为选写的题要给上升路径：说明从这批人的具体处境如何折射更普遍的处境，以及上升后哪些内容变、哪些不变。上升不成立时直接写"圈层内容，不建议主推"，并给一个替代角度，不因作者热情改判。

通过定级的题做二次加工：

1. 情绪优先于信息：干货包一层具体处境，先让读者对上号。
2. 二元对立：明确反对什么、支持什么；对立必须有真实素材做底座。
3. 个案上升：从一个人的遭遇讲到一类人的处境，不虚构人物和数据。

标题给 3–5 版，按四种方向各出一版：干货 → 处境焦虑；建议 → 明确判断；功能 → 价值观筛选；趋势 → 身份表达。改的是角度，不是同义词。

强度顺序固定：真实准确 > 与正文一致 > 核心信息不误导 > 打开率。每版标注承诺在正文哪里兑现。材料兑不了时先降强度（弱化结论、限定范围、换兑现点），再退回换角度；仍兑不了才整版不用，并写明缺哪块材料。不得为了强度编数字、编因果、编人物。

### Step 5 写作简报（12 项）

选题 / 目标读者 / 内容形式 / 核心问题 / 推荐角度 / 中心判断 / 内容承诺 / 结构顺序 / 需核实的事实 / 需补充的案例 / 最强反方 / 表达边界。

"内容形式"一项要同时写明形式、篇幅与发布平台——下游按这三项接料，缺一项会被退回。
"表达边界"写三件事：不碰的对象（具体个人、公司、未公开信息）、不用的手法（编造、恐吓、伪因果）、争议时的立场边界（反对做法，不贬低持相反意见的读者）。

简报里的"需核实"如实保留，不用推测补齐。

### Step 6 开写信号

简报经用户确认后才进入正文。确认后写作中发现新的事实冲突，标"待核"，不擅自改已确认的主线。

## 验收标准

**阻塞项：任一为 0，不得进入写作。**

- [ ] B1 口径 5 项有答案；缺失项写为假设并标注"待确认"；目标读者写明证据来源
- [ ] B2 短名单经过用户窄化：每条有保留 / 淘汰 / 合并 / 改角度的理由，没有未说明就定稿的题；合格题不足 2 条时给负结论与补齐计划，不硬凑
- [ ] B3 写作简报 12 项齐全；用户确认前没有输出正文；停在短名单的会话标"待确认"并止于短名单

**计分项：**

- [ ] 1 每条候选有来源类型与证据状态（已核 / 待核 / 材料不足）；"材料不足"的题留在宽池、不进短名单；趋势类候选有 ≥2 个独立来源且跨平台出现，否则标"单点信号"不进短名单
- [ ] 2 入短名单的题逐项给出三指标判断，不只给结论；覆盖面写量级区间与依据，无依据标"待核"
- [ ] 3 定级落在四象限之一，并给出对应动作（必写 / 不写 / 选写 / 绝不写）；检索型刚需标"资产型"并给收藏与复访判据
- [ ] 4 标题 ≥3 版，且是角度变化，不是同义词替换；兑不了时先降强度，并标出缺哪块材料
- [ ] 5 简报中引用的数字与案例标明"已核 / 待核"，待核项不作为中心判断的唯一支撑

判定：阻塞任一为 0 = 重做；阻塞全过 + 计分 ≥⌈0.8×N⌉ = 可交付；计分 ≤阈值-1 = 重写。N = 5，阈值 = ⌈0.8×5⌉ = 4。本技能 5 项均适用、无 N/A 场景；漏做不算 N/A。

## Gotchas

1. **把热榜当选题**
   热不等于读者关心。先过读者关系这一维，再看热度。

2. **只按自己的兴趣筛**
   覆盖面判断要站在目标读者，不是站在写作者。

3. **冲突没有事实底座**
   对立可以极端化表达，但不能编人物、编数据、编案例。

4. **标题只改措辞**
   "如何提升竞争力"改成"提升竞争力的 5 个方法"仍是同一个题。换角度，不换形容词。

5. **简报没确认就开写**
   方向未定时写正文，结构必然反复，事实也会漂移。

6. **选题会开成资料堆**
   只堆链接和摘要不算完成。选题会必须收敛到一个中心判断。

7. **把"低唤醒"当唯一判据**
   政策、工具、流程类内容靠搜索与收藏回收，不靠转发。低唤醒不等于不写，先看有没有人主动搜。

8. **等用户说"选哪条"**
   用户说"你挑一个写"就是代选授权。停在短名单不是谨慎，是没交付。
