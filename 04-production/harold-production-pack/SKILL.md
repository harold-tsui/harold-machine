# Production Line · 交付生产

> 一句话：先定结构和结论，再做版式。

## 核心定位

- 适用：研究报告、汇报 PPT、方案书、长文、项目提案的结构与成稿。
- 不适用：纯数据计算（用表格工具）、纯视觉设计（用设计工具）、研究本身（用 `harold-research-brief`）。
- 下游交接：结构定稿后交 `harold-production-slides`（PPT 版式）、`harold-production-visual`（视觉与配图）、`harold-production-polish`（语言层）、`harold-production-copy`（长文 / 公众号成稿）、`harold-production-web-story`（单页叙事网页）、`harold-production-knowledge-cards`（卡片流）；pack 只定结构与结论，不替代下游。
- 默认交付：可执行的页面 / 章节规格，再据此成稿。

## 触发场景

- "把这堆材料做成 PPT / 报告"
- "帮我写个方案书 / 公众号长文"
- "帮我搭个汇报结构"
- "这版太乱，帮我重排"
- "明天要讲 15 分钟，帮我理一下"

## 工作流

### Step 0 交付定义（5 项，缺一不可）

读者 / 场景 / 时长或篇幅 / 介质 / 必须回答的 3 个问题。
介质取值：PPT / 长文 / 方案书 / 报告（按长文处理）/ 单页网页 / 卡片流；其余形态按最接近的一种推断，并在交付规格写明"按 X 处理"。
缺项先问一个最关键的问题，其余写假设。
用户未给必答 3 问时，先从材料中提炼候选问题并列给用户确认；材料也提炼不出时，按"读者最想知道的 1 个判断 + 2 个支撑问题"提出假设，标注"假设，待确认"。
必答问题先做可答性预检：逐问标"材料可答 / 需补证据 / 建议删问"。"需补证据"的写明补什么、由谁补，进「假设与待确认」；"建议删问"的须用户确认后才删，不得默认保留一个材料答不了的问题。
配页口径：按每页 1–2 分钟折算，硬上限 = 时长 ÷ 1 分钟。15 分钟 ≈ 8–15 页（推荐 10–15）、30 分钟 ≈ 15–30 页（推荐 20–30），含封面与结论页，每页 1 个论点。时长指净讲述时长，不含问答与茶歇；场次含问答时先扣除（例：30 分钟含 10 分钟问答，按 20 分钟配页）。时长未定时按 15 分钟假设值核算，并在页面清单标"按 15 分钟假设配页，待确认"；不因时长待定而判 0。
篇幅口径：长文 / 方案书按阅读时长折算，目标字数 = 阅读分钟 × 300–500；方案书正文默认 ≤6 页（示例口径，可按组织调整；单倍行距约 500 字/页，6 页 ≈ 3000 字），页数为硬上限、字数为目标区间，两者冲突时以页数为准，方法与明细进附录；报告按长文处理。篇幅未定时按长文 10 分钟阅读折算，并标"按 10 分钟阅读假设，待确认"。

### Step 0.5 重排模式（输入是已有版本）

用户说"重排""太乱"且手里已有成稿时，先诊断、后动刀，不从头重做一遍。
四项诊断逐页做：每页是否只有一个论点 / 标题是否结论句 / 顺序是否结论先行 / 必答 3 问是否各有页面承载。
诊断结果分三档：
- 四项在所有页面都成立 → 仍先从原稿还原一页纸，再进 Step 3 核对页面规格。
- 有结构问题但主张成立（最常见）→ 先从原稿还原一页纸，再进 Step 2 重排结构。
- 整版没有主张 → 按 Step 1 补写一页纸，再走 Step 1–5。
重排仍须还原一页纸：从原稿提炼主张与 3 条证据；提炼不出就写明缺什么，不得因"已有成稿"跳过。
交付定义 5 项可从原稿反推的，直接标注取自哪一页，不再追问；仍缺的按 Step 0 处理。
原稿页数超出配页口径时，按 Step 0 口径压缩，并在改动清单写明删了哪几页、为什么。
交付须附改动清单：逐页标保留 / 调序 / 拆合 / 新增 / 删除，并写明理由；同时给页数总账（原 <n> 页 → 现 <m> 页，删 a / 增 b），只列逐页动作无法核对总数。

### Step 1 一页纸

一句主张 + 3 条证据 + 一个行动建议（ask：向谁、要什么决定或动作、何时做）。
3 条证据须来自不同来源或不同维度，至少 1 条是反证、边界条件或不利数据；同一数据的三种说法不算三条。
主张须是完整陈述句、可被反驳；"关于 X 的分析""X 的几点思考"这类标签不算主张，须写出明确判断。
一页纸写不出来时，输出"缺什么才能写出一页纸" + 页面清单草案，并明确标注"未定稿，不可直接成稿"；不得跳过一页纸直接给完整版式规格。
用户先要版式时，先说明返工成本，再给两个选项：A 先出页面清单、确认后套版式；B 先出骨架模板。用户在说明后仍要求先出版式 → 走 B，交付须标注"内容待定，版式随结构变化"，返工风险由请求方承担。

### Step 2 结构

每页 / 每节只承载一个论点；标题写成结论句，不写名词短语。
顺序按"结论 → 依据 → 行动"，不按工作过程。

### Step 3 页面规格

页面粒度按介质取：PPT 按页（一页一论点）；长文按章节（一节一论点）；方案书按"决策页 + 附录"（正文只放结论与依据，方法与明细进附录）。进附录的判据：读者不看它也能做决定；读者不看就无法决定的，留在正文。

| 页码 / 节号 | 结论句标题 | 时长 / 字数 | 关键图 / 表 | 数据与口径 | 来源 | 备注 |
|---|---|---|---|---|---|---|
每个数字标口径与来源；来源列格式：外部写 `机构 / 报告名 · 发布日期`，内部写 `系统名 · 截止日期 · 口径`，测算类写 `测算，方法→A<n>`；四项写不全视为无来源。数据与口径列须写对比对象（目标 / 上期 / 同业，或显式写明"单点事实"）；没有来源的图不上页面；时长 / 字数列：PPT 行写该页计划讲述的分钟数，合计须落在 Step 0 的配页口径内；长文 / 方案书行写本节的字数，合计须落在 Step 0 的篇幅口径内；备注列写该页的取舍、待补信息或附录指向。

图表诚实三条：柱状图与面积图 y 轴从 0；必须用非零基线时在图注写明起点与理由；不用双轴与 3D，双轴确实不可避时两轴分别标注并在备注说明。来源合规但轴被截断的图，仍算误导。

### Step 4 成稿

先文字后版式；图与正文不重复；每页留一句可以被记住的话。

### Step 5 验收

- 扫读测试：只看标题，能读懂该页在说什么；把所有标题连起来读，能还原整套论证（结论 → 依据 → 行动），不需要翻正文补逻辑。
- 朗读测试：30 秒内能听懂这一页在说什么，并能复述该页要记住的那一句（30 秒是理解阈值，与 1–2 分钟讲述预算不是同一量）。
- 删减测试：删掉 20% 内容（写明删了哪几页 / 哪几段），核心信息不丢。
- 图文测试：页面上的图没有被正文原样复述。
- 篇幅核对：合计页数 / 字数落在 Step 0 口径内；方案书须同时核对正文页数（≤6 页）与字数折算，页数优先。
- 必答核对：必答 3 问各至少 1 页，备注列标出的 Q1 / Q2 / Q3 可一一反查。
- 来源测试：随机抽 3 个数字，按来源列格式都能回溯到机构 / 系统 + 时点 + 口径。

## 输出格式

```text
# 交付规格：<主题>

- 读者｜场景｜时长 / 篇幅｜介质
- 必答 3 问：1… 2… 3…（每问标 可答 / 需补证据 / 建议删问）

## 假设与待确认
| 项 | 当前取值 | 依据 / 需谁确认 |
|---|---|---|

无假设时写"无"；「需补证据」的问题必须在此列出补什么、由谁补。

## 一页纸
主张：<一句>
证据：1… 2… 3…
行动：<向谁要什么决定或动作，何时>

## 页面清单
| 页码 / 节号 | 结论句标题 | 时长 / 字数 | 关键图 / 表 | 数据与口径 | 来源 | 备注 |
|---|---|---|---|---|---|---|

备注列须标该页回答哪一问（答 Q1 / Q2 / Q3）；必答 3 问各至少 1 页。

## 附录清单
| 编号 | 内容 | 对应正文 |
|---|---|---|
| A1 | <方法与明细> | <节号> |

正文引用附录时，备注列写 `→A1`；无附录的介质写"无"。

## 改动清单
| 页码 | 动作（保留 / 调序 / 拆合 / 新增 / 删除） | 理由 |
|---|---|---|

页数总账：原 <n> 页 → 现 <m> 页（删 a / 增 b）。
重排模式必填；非重排模式写"不适用"。备注列按 `答 Q1｜取舍｜待补｜→A1` 顺序书写，缺项留空。

## 验收记录
- 扫读｜朗读（含每页记忆点复述）｜删减｜图文｜篇幅｜必答 3 问｜来源：通过 / 不通过 + 说明；来源测试须写明抽检的 3 个数字
- 不通过项须写修订动作（改哪页、补什么数据、删哪个问题），只写"不通过"视为未完成验收
```

## 验收标准

**阻塞项：任一为 0，不得成稿，不看计分项。**

- [ ] B1 交付定义 5 项齐全：读者 / 场景 / 时长或篇幅 / 介质 / 必答 3 问都有答案，且每问标注材料可否支撑（可答 / 需补证据 / 建议删问）；缺失项已写为假设并标注"待确认"
- [ ] B2 一页纸先于版式：有主张与 3 条彼此独立的证据（不同来源或维度，至少 1 条为反证或边界条件）；写不出时已输出"缺什么才能写出"并标注"未定稿，不可直接成稿"，没有跳过一页纸直接给完整版式（重排模式下为"从原稿还原一页纸"）
- [ ] B3 数字可回溯：每个上页面的数字有口径与来源（机构或系统 + 时点 + 口径，测算注明附录），抽 3 个都能回溯

**计分项：**

- [ ] 1 结构一次成型：每页一个论点、标题是结论句、顺序结论先行（不是过程流水账）；只看标题、3 秒能读懂该页在说什么，标题连读能还原整套论证；重排模式下还须给出逐页改动分类（保留 / 调序 / 拆合 / 新增 / 删除）与页数总账
- [ ] 2 朗读测试：每页 30 秒内能听懂这一页在说什么，且能复述该页要记住的一句，有记录（30 秒是理解阈值，与 1–2 分钟讲述预算不是同一量）
- [ ] 3 删减测试：删掉 20% 内容后核心信息不丢，有记录并写明删了哪几页 / 哪几段
- [ ] 4 图与正文不重复：页面上的图不被正文原样复述
- [ ] 5 篇幅与交付口径一致：PPT 页数落在 Step 0 的配页区间内（含封面与结论页）；纯图版 / 高密度技术页按"一页一论点"核对，不受页数区间约束，但须在验收记录写明超页理由；长文按 Step 0 的字数折算给出并核对；方案书同时核对正文页数（≤6 页，超页即不通过）与字数折算，页数优先
- [ ] 6 一页纸有一个可执行行动建议（ask）：写明向谁要什么决定或动作、何时做，不是「下一步推进」式空话
- [ ] 7 必答 3 问各有页面承载：每问至少 1 页，备注列标出答 Q1/Q2/Q3，可一一反查

判定：阻塞任一为 0 = 重做；阻塞全过 + 计分 ≥⌈0.8×N⌉ = 可交付；计分 ≤阈值-1 = 重写。N = 7，阈值 = ⌈0.8×7⌉ = 6；单项 N/A 时 N = 6、阈值 5；两项同时 N/A 时 N = 5、阈值 4。N/A 仅限材料本身不具备该情形（纯文字稿无图 → 第 4 项 N/A；无口头汇报 → 第 2 项 N/A），漏做不算 N/A。

## Gotchas

1. **先美化再想结构**
   模板选得再好，救不了没有主张的内容。

2. **标题写名词短语**
   "行业分析""项目进展"没有信息量。改成"该市场增速已连续两年低于 5%"。

3. **一页三个论点**
   观众只能记住一个。拆页，不要缩小字号。

4. **图无口径、无来源**
   一张没有口径的图比没有图更危险。

5. **把过程当结论**
   "我们调研了 20 家"是过程；"其中 16 家不愿付费"才是结论。

6. **文字复述图**
   图已经说明的，正文不要再念一遍。

7. **页数当质量**
   15 分钟讲 40 页，等于没讲。按分钟配页；但该口径只对文字密集型的讲述汇报成立，纯图版、高密度技术页不受此约束，改按"一页一论点"控制。

8. **孤立数字**
   "规模 3,000 万"没有对比对象，读者无法判断是高是低。补目标、上期或同业，或写明这是单点事实。

9. **三条证据同一个数**
   把"行业报告说 30%、我们测算 30%、客户访谈提到 30%"当三点支撑。它们同源，只能算一条；另外两条要换维度，最好含一条反证。

10. **截断轴做出陡峭增长**
    柱状图不从 0 起，3% 的差异能看成三倍。来源写得再规范，轴截断仍是误导。
