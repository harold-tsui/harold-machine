# 验收用例：交付生产

## Case 1 · 材料齐全但不知道要讲什么

**输入**："这些资料帮我做成 20 页 PPT，明天汇报。"

**期望特征**
- 先问：汇报给谁、多长时间、必须回答的 3 个问题。
- 对 3 个必答问题做可答性预检：逐问标可答 / 需补证据 / 建议删问；材料答不了的问题不硬留到最后。
- 不直接开始排版；先出一页纸主张与 3 条证据，且三条证据不同源、至少一条为反证或边界条件。
- 若主张写不出，明确指出"素材不足以支撑结论"，并建议补什么。
- 按分钟配页（15 分钟 → 8–15 页，推荐 10–15），不按材料多少配页。
- 页面清单能反查：3 个必答问题各由哪页回答，一页都没承接时回到 Step 0 重定问题。
- 一页纸结尾给一个可执行行动建议，写明向谁要什么决定或动作、何时做，不写「下一步推进」这类空话。

**常见失败**：直接给 20 页目录；按"背景—现状—问题—建议"套模板；标题全是名词短语。

## Case 2 · 一页里塞了三个结论

**输入**："这页想同时讲市场规模、竞争格局和我们的机会。"

**期望特征**
- 判为一页多论点，拆成 2–3 页。
- 给出每页的结论句标题与所需图表。
- 拆分后每页只看标题、3 秒能读懂该页在说什么。
- 说明拆分后的讲述节奏与取舍（哪些放附录）。

**常见失败**：缩小字号硬塞；用"总览"标题掩盖；不提示观众记不住。

## Case 3 · 用户要求先出漂亮版式

**输入**："先帮我做一版好看的，内容我后面再补。"

**期望特征**
- 说明返工成本（结构未定就出版式，结构一变版式推倒重来），不直接进入视觉制作。
- 给出两个选项：A 先出页面清单（每页一句结论），确认后套版式；B 先出骨架模板。
- 经说明后仍要求先出版式：走 B，交付标注"内容待定，版式可能随结构变化"，并记录返工风险由请求方承担。

**常见失败**：直接开始做视觉；做完再发现结构要推倒。

## Case 4 · 长文给了题目没给篇幅

**输入**："把这个主题写成一篇公众号长文，读者是我们的老客户。"

**期望特征**
- 补齐交付定义：问或假设阅读时长（如 10 分钟），按 300–500 字/分钟折算目标字数（10 分钟 ≈ 3,000–5,000 字），并标"按 10 分钟阅读假设，待确认"。
- 先出一页纸主张与 3 条证据，再给章节清单（一节一论点），每节标预计字数，合计落在折算区间内。
- 方法与明细进附录，正文只留结论与依据。
- 验收记录里有篇幅核对：实际字数对比目标区间，超出时说明取舍。

**常见失败**：直接写一万字；不折算字数、不设上限；以字数当质量，把附录内容全塞进正文。

## Case 5 · 已有版本，用户说"太乱"

**输入**："这版 PPT 太乱了，帮我重排一下。"（附现稿 18 页）

**期望特征**
- 判定为重排模式（Step 0.5），四项结构诊断逐页做，不从头重问一遍交付定义。
- 诊断三档判定正确：四项全过 → 仍还原一页纸后核对页面规格；有结构问题但主张成立 → 还原一页纸后重排；整版无主张 → 补写一页纸。
- 先从原稿还原一页纸（主张 + 3 条证据），再改结构；不因"已有成稿"跳过。
- 交付定义 5 项能从原稿反推的，标注取自哪一页；确实缺的（如时长）才问或按 15 分钟假设。
- 改动分五类：保留 / 调序 / 拆合 / 新增 / 删除，逐页给理由；不整版推倒重做。
- 给页数总账（原 18 页 → 现 m 页，删 a / 增 b），与逐页动作对得上。
- 标题是名词短语的页，改写成结论句后列出前后对照。
- 18 页超出 15 分钟口径（8–15 页，推荐 10–15）：按口径压缩，并在改动清单写明删了哪几页、为什么。
- 交付附改动清单，可逐页核对。

**常见失败**：不诊断直接重做一套；只调美化不调结构；把 18 页硬压到 10 页却不说删了什么。

## 评分表（3 项阻塞 + 7 项计分，逐项 0/1）

**阻塞项：任一为 0，不得成稿，不看计分项。**

| # | 检查项 |
|---|---|
| B1 | 交付定义 5 项齐全：读者 / 场景 / 时长或篇幅 / 介质 / 必答 3 问都有答案，且每问标注材料可否支撑（可答 / 需补证据 / 建议删问）；缺失项已写为假设并标注"待确认" |
| B2 | 一页纸先于版式：有主张与 3 条彼此独立的证据（不同来源或维度，至少 1 条为反证或边界条件）；写不出时已输出"缺什么才能写出"并标注"未定稿，不可直接成稿"，没有跳过一页纸直接给完整版式（重排模式下为"从原稿还原一页纸"） |
| B3 | 数字可回溯：每个上页面的数字有口径与来源（机构或系统 + 时点 + 口径，测算注明附录），抽 3 个都能回溯 |

**计分项：**

| # | 检查项 |
|---|---|
| 1 | 结构一次成型：每页一个论点、标题是结论句、顺序结论先行（不是过程流水账）；只看标题、3 秒能读懂该页在说什么，标题连读能还原整套论证；重排模式下还须给出逐页改动分类（保留 / 调序 / 拆合 / 新增 / 删除）与页数总账 |
| 2 | 朗读测试：每页 30 秒内能听懂这一页在说什么，且能复述该页要记住的一句，有记录（30 秒是理解阈值，与 1–2 分钟讲述预算不是同一量） |
| 3 | 删减测试：删掉 20% 内容后核心信息不丢，有记录并写明删了哪几页 / 哪几段 |
| 4 | 图与正文不重复：页面上的图不被正文原样复述 |
| 5 | 篇幅与交付口径一致：PPT 页数落在 Step 0 的配页区间内（含封面与结论页）；纯图版 / 高密度技术页按"一页一论点"核对，不受页数区间约束，但须在验收记录写明超页理由；长文按 Step 0 的字数折算给出并核对；方案书同时核对正文页数（≤6 页，超页即不通过）与字数折算，页数优先 |
| 6 | 一页纸有一个可执行行动建议（ask）：写明向谁要什么决定或动作、何时做，不是「下一步推进」式空话 |
| 7 | 必答 3 问各有页面承载：每问至少 1 页，备注列标出答 Q1/Q2/Q3，可一一反查 |

判定：阻塞任一为 0 = 重做；阻塞全过 + 计分 ≥⌈0.8×N⌉ = 可交付；计分 ≤阈值-1 = 重写。N = 7，阈值 = ⌈0.8×7⌉ = 6；单项 N/A 时 N = 6、阈值 5；两项同时 N/A 时 N = 5、阈值 4。N/A 仅限材料本身不具备该情形（纯文字稿无图 → 第 4 项 N/A；无口头汇报 → 第 2 项 N/A），漏做不算 N/A。
