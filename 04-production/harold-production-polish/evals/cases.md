# 验收用例：去 AI 味

> 三条用例分别校准三类失效：改了但没改到点上、改对了方向但下手过重、把"像人话"误当"越口语越好"。
> 用例中的数字均为示意，**示例，非真实数据**。

## Case 1 · 学术 / 报告腔过重

**输入片段**

> 综上所述，随着数字化进程的不断推进，企业对于数据治理的重视程度显著提升。值得注意的是，数据治理在本质上是一项系统性工程，需要从战略层面进行统筹规划。与此同时，我们应当建立长效机制，持续优化数据质量，从而为业务决策提供有力支撑。总体而言，只有深刻理解数据治理的内在逻辑，才能真正释放数据价值。

**期望特征（可观察）**

- 诊断能报出具体处数：A 类（综上所述 / 值得注意的是 / 总体而言）、C 类（与此同时）、D 类（显著 / 深刻 / 有力）、D4 大词（本质上 / 内在逻辑）。
- 先标明基线与场景：有作者同类文本就标注来源，没有就写"单稿基线"；正式度定为"正式"（报告场景），不做口语化替换。
- 先抽不可动清单：数据治理、口径、数字化等术语原样保留，交付时逐项回核未变。
- 原文 ≤1000 字（按正文汉字数计），给紧凑诊断表（七类命中计数 + 命中类各 1 条例句，零命中写"无"），不省略诊断。
- 改写后至少有一处换成可核对的具体内容（某系统、某口径、某时间、某人数），或明确标注"原文无具体信息，需作者补充"，不虚构。
- 句长出现明显长短差；不再每句 20 字上下。
- 结尾不落在"释放数据价值"这类升华句上。
- 术语（数据治理、口径）保留，没有被改成"管数据"这类降级说法。

**常见失败**

- 只做同义词替换："显著提升"→"大幅提升"、"深刻理解"→"深入理解"，病症类型没变。
- 把套话删干净，但补进去的还是泛论，全文仍然没有一个事实。
- 为了"像人话"把"数据治理"改成口语词，专业准确性丢失。
- 编造"某企业三个月提升 30%"来填具体性缺口。

## Case 2 · 营销腔浮夸

**输入片段**

> 我们致力于为客户提供全方位、高品质、一站式的解决方案。依托卓越的专业能力与极致的服务体验，我们持续赋能客户，助力企业实现跨越式发展，共同开创更加美好的未来。

**期望特征（可观察）**

- 识别 D3（三个以上褒义形容词叠加）、D4（大词：赋能、跨越式发展）与 E1（四字排比）。
- 改写落到可验证信息：服务范围、计价方式、交付周期、案例数量中的至少两项。
- 删掉"共同开创更加美好的未来"式结尾，改为具体下一步或明确边界。
- 若原文确实没有事实，输出"待补 3 项：服务范围 / 报价方式 / 交付周期"，而不是用另一组形容词重写。
- 语气可以保留一定营销感，但形容词密度显著下降。
- 先定正式度档位（营销物料多为"中性"，偏口语会掉品牌调性）；不可动清单先抽出品牌名与承诺口径（"一站式""全方位"）再改。
- 原文句句有病，改动率必然偏高：修改说明须写明改动率并给出"病点密度极高"的理由，不是默默全改。

**常见失败**

- 改成了另一种广告腔（"让增长看得见"），仍是空话。
- 全删形容词后句子变得干瘪无信息，读起来像说明书残句。
- 把"一站式"删了却没问业务边界，改写后的范围描述与原文承诺不一致。
- 顺带改了品牌调性以外的内容（如擅改客户行业），越界。

## Case 3 · 改过头（负向校准）

**输入片段（原文已基本合格，仅有两处小问题）**

> 本季度复购率为 31%，较上季度下降 4 个百分点（示例，非真实数据）。主要原因是本季度未安排大促，上季度满减活动抬高了基数。从目前节奏看，下季度大概率回到 33% 附近。这个判断有风险：如果竞品继续跟进补贴，恢复会推迟。

**期望特征（可观察）**

- 判定为"轻微"，只处理"从目前节奏看"这类轻微过渡，或干脆不改。
- 数字、因果链、"这个判断有风险"的判断句全部保留。
- 不把"31%"改成"三成多"，不把"4 个百分点"改成"不少"。
- 不强行加"我"、不加网络口语（"直接起飞""卷不动了"）、不加感叹号。
- 修改说明首行汇总行写明"共改 1–3 处"、未命中类写"无"，并说明原文已达标，而不是交了 80% 的重写稿。
- 声明"单稿基线"（不假设作者另有作品），正式度定为"中性"，不做口语化替换；改动率 ≤20%。
- 未命中的类别写"无"，不硬凑例句；改动少于 3 处时按"全查"核对，不判 0。

**常见失败**

- 为显示工作量而重写全段，作者认不出自己的文字。
- 把书面表达一律改成口语："大概率"→"十有八九"，"推迟"→"往后拖"，正式度不匹配使用场景。
- 把限定语全部删掉，原本严谨的概率表述变成断言。
- 把"这个判断有风险"这类真人语气误判为 AI 腔而删除。

## 评分表（3 项阻塞 + 6 项计分，逐项 0/1）

**阻塞项：任一为 0，直接重做，不看计分项。**

| # | 检查项 | 通过判据 |
|---|---|---|
| B1 | 无编造 | 新增细节可追溯原文 / 作者，或明确标注待补；不为"自然"造事实 |
| B2 | 事实层未被改动 | 数字、术语、引用、口径与原稿一致；改写前已抽不可动清单（数字 / 术语 / 引用 / 专名 / 作者惯用句），交付时逐项回核未变 |
| B3 | 未越界改结构 | 论点、段落先后顺序、章节结论与原稿一致；句内重组与相邻段合并属语言层，不算越界；跨节移动段落或改动结论判越界 |

**计分项：**

| # | 检查项 | 通过判据 |
|---|---|---|
| 1 | 诊断有分类与处数 | A–D 给具体类别与处数，E 给轻微 / 中度 / 严重，F / G 给有 / 无；命中类附例句，零命中写"无"，不是"整体偏 AI" |
| 2 | 改动命中真实病点 | 改动 ≥3 处抽 3 处，少于 3 处全查，均能对应到分类判据 |
| 3 | 无同义替换式假改 | 删掉的套话没有用另一句套话补上 |
| 4 | 节奏处理到位 | E 类中度及以上的片段已切出长短对比（改写后连续 5 句极差 >5 字）且至少有 2 处明显句长突变，不靠插入单个 4–6 字短句凑极差，也不是全靠短句堆叠；诊断为轻微的保留原样即通过；全文不足 5 句时本项 N/A |
| 5 | 语气基线一致 | 改前已采样作者同类文本或声明"单稿基线"；改后正式度与正式 / 中性 / 口语三档场景相符，未滑向另一种模板腔 |
| 6 | 输出完整可核对 | 诊断按原稿正文汉字数（不含标题、标点与空白）分档——≤1000 字给紧凑诊断（七类命中计数 + 命中类各 1 条例句，零命中写"无"，不得省略诊断），>1000 字给完整诊断报告（七类逐项 + 总体 + 主要问题）；诊断首行给基线与正式度档位；修改说明首行给改动总处数、各类分布与改动率（改动句数 / 总句数），零改动写"原文达标，改动 0 处"，改动率 >60% 须写明理由；写清不可动清单回核与复扫结果；末行留痕通读结果 |

判定：阻塞任一为 0 = 重做；阻塞全过 + 计分 ≥⌈0.8×N⌉ = 可交付；计分 ≤阈值-1 = 重写。N 与阈值按场景换算（标 N/A 的项不计入分母）：常规 N=6、阈值 5；全文不足 5 句时第 4 项 N/A，N=5、阈值 4。N/A 仅限材料本身不具备该情形，漏做不算 N/A；用户豁免某项时仍计入分母，自检记为未做。
