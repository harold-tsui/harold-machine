# Polish · 去 AI 味

> 一句话：不是润色，是把 AI 的固定语型一处一处换掉。

## 核心定位

- 适用：已成形中文内容的语言层返修——口播稿、公众号、项目说明、知识帖、社媒文案、报告的文字段落。
- 只管语言层：用词、句式、节奏、语气、视角。
- 不管结构层：论点、章节顺序、每页结论、论证是否充分——那是 `harold-production-pack` 的活，本技能不越界。
- 不改事实层：术语、数字、引用、口径原样保留；为了"自然"牺牲准确，判失败。
- 改动幅度受基线约束：先采作者语气基线、定场景正式度，再动笔；基线拿不到就声明"单稿基线"，不凭感觉替作者定语气。
- 不适用：英文写作、合同/法务等必须保持规范文体的文本。
- 输入侧：接 `harold-production-copy` / `harold-production-pack` 的定稿；只交语言层差异，发现结构问题写明回上游，不在本技能改结构。
- 边界：不承诺"通过 AI 检测"——检测器误判率高，检测分数不作验收依据；AI 生成内容公开发布前，按《人工智能生成合成内容标识办法》与平台规则主动声明，本技能不放宽标识义务。

## 触发场景

- "帮我润色一下，去掉 AI 味"
- "这篇读起来太像 AI 写的，改一下"
- "让这段话更像我平时说话"
- "检查一下有没有 AI 写作痕迹 / 套话是不是太多"
- "结尾太假了，帮我换掉"

## 工作流

### Step 0 基线与场景（先定，再动手）

**语气基线**：优先取作者本人其他 2–3 段同类文本（公众号、讲稿、社媒各一段即可），记三件事——默认正式度、典型句长、是否惯用短句 / 反问 / 第一人称。取不到样本时以原稿为单稿基线，诊断首行标"单稿基线，语气项以原稿为准"。

**场景与正式度**：定一档——正式（公函、对外公告、报告）/ 中性（公众号、方案段落）/ 口语（口播、社媒）。定档决定改法上限：正式档不口语化，只删套话与空词；口语档允许拆句、加短句、换口语词；中性档两者都只做轻量。

**改动预算**：原文已达标（A–D 命中 ≤3 处）只改命中处，不整段重写。改动句数 ÷ 总句数 = 改动率，写进修改说明；改动率 >60% 须写明理由（原文病点密度极高），否则视为改过头。

### Step 1 不可动清单与全文扫描

先从原文抽出**不可动清单**：数字、术语、引用、专名（人名 / 机构 / 产品）、作者惯用句与口头特征。清单逐项记下，改写全程对照，交付时逐项回核；清单里的内容只能原样保留，不得为"顺"而替换。

再按 A–G 七类逐句标，只标注不改写。判据与处置：

| 类 | 病名 | 判据（可观察） | 处置 |
|---|---|---|---|
| A | 万能套话 | 出现"总的来说 / 值得注意的是 / 随着…时代的到来 / 在这个快节奏的时代"等 | 直删，不替换 |
| B | 机械并列 | 连续 3 句以上同构；或 5 句里起头全是"首先 / 其次 / 第一 / 第二" | 打散，改因果 / 转折 / 叙事推进 |
| C | 装饰性过渡 | "不仅如此 / 更重要的是 / 综合来看" 密集出现 | 删词，两段直接相邻，或换成具体因果 |
| D | 空洞形容词与大词 | "深刻 / 显著 / 一定程度上 / 某种意义上"代替具体信息；以大词、伪专业表述代替判断（本质上 / 内在逻辑 / 赋能 / 跨越式发展）；或把动作名词化（进行优化 / 作出决定 / 起到…作用） | 删形容词；大词追问"具体指什么、凭什么"，把答案写回去；名词化还原成动词；能找到数字 / 时间 / 结果就换上 |
| E | 节奏均匀与排比堆砌 | 连续 5 句里最长句与最短句相差 ≤5 字（极差 ≤5 字）；或连续 2 组以上四字排比 / 同构短语 | 切出长短对比；排比拆成具体动作，不留等长四字串 |
| F | 升华式结尾 | 最后 1–2 段只剩"愿我们 / 让我们 / 这不仅是…更是…" | 删掉，换具体动作或真实问题 |
| G | 视角悬空 | 全篇只有"我们 / 人们普遍认为"，无一处具体的人 | 加一处真实经历或具体场景 |
| D6 | 中文长句病 | 名词前定语超 2 层；一句里"的"≥3 个；"这 / 该 / 其 / 上述"指代不明；"对于…而言 / 就…来说"前置框架；一段里"不仅…而且 / 既…又 / 不但…还"≥2 组 | 定语拆成短句或后置；指代换成具体名词；删介词框架直接陈述；关联词只留一组 |

完整词表与逐条改写对照 → `references/ai-tone-lexicon.md`。

### Step 2 汇总评级

输出：先报基线与场景（抽样来源或"单稿"、正式度档位、改动预算），再给 A–D 各类处数，B 附 1 个典型例子；E 给"轻微 / 中度 / 严重"；F、G 给"有 / 无"。再给总体 AI 味程度：轻微 / 中度 / 明显 / 严重。

- 计数归并：同一处文字只计入一个类别，A–D 内按 A→B→C→D 取第一个命中类（A 最高）；跨类重叠在诊断表脚注写"另有 X 处同时符合 B/C，按 B 计"。E 按片段计、F 按结尾段计、G 全篇只记 1 处，三者不参与 A–D 的归并。
- D6 并入 D 类计数，不单列一类；举例时标 D6，便于回词表查改法。
- E 类门槛：按"连续 5 句极差 ≤5 字"的片段计数——轻微 = 1–2 处；中度 = 3–5 处或集中在同一段；严重 = ≥6 处或出现在标题与开头前 3 句。
- 子类编码：词表中的 D1–D5、E1–E2 是子类，诊断只报大类处数 / 等级，举例时可标子项号（如 D3、E1）。
- E 的字数极差是本地代理指标：只用来定位"句子长度是否过于均匀"，不代表可读性或质量结论；字数达标不等于稿子好，不单独据此判通过。

### Step 3 分段改写

归类固定按 Step 2 的优先级（A→B→C→D），不因是否含数字改归；下面只定处置动作——原文能找到可核数字 → 补具体表述；只有形容词、无信息可补 → 直删。

- A：删。删完读一遍，通就不补话。
- B：把并列改成因果链、转折或时间线。**只在列举逻辑真的需要顺序时保留"首先"**，装饰性的删。
- C：删过渡词，让两段靠内容接上；接不上说明缺的是逻辑，不是连接词。
- D：找原文里的数字、时间、结果顶上去；名词化还原成动词（"进行优化" → "改"）；找不到具体信息就问用户，不许编。
- D6：定语拆成短句或挪到名词后；"这 / 该 / 其 / 上述"换成具体名词；删"对于…而言"框架直接陈述；一段里关联词只留一组。
- E：重切句子——长句拆到能一口气读完，短句独立成句；长短要交替，不是全变短。至少制造 2 处明显句长突变，不得只插一个 4–6 字短句凑极差。
- F：删掉升华，最后一句落在具体动作、判断或遗留问题上。
- G：只加**能核实**的视角（"我试过 / 我们那次 / 客户当时"）；不加就没细节，不硬造。

改法受 Step 0 的正式度档位约束：正式档不做口语化替换，口语档不保留书面套话；两档都不能越过不可动清单。

### Step 4 复扫与事实回读（能朗读则朗读）

改写稿再跑一遍 A–G：改写时新引入的套话、新造的排比、新出现的悬空指代，逐条清零后才交付；确实改不掉的，在修改说明写明位置与理由。复扫只查"新病"，不重开一轮全文改写。

通读全文：哪里会自然换气，那里就该断句；哪句像背稿，重写那句；整体有没有快慢起伏。优先朗读；不能朗读时默读，但放慢到逐句在心里念出来，不要一眼扫过——不宣称两者效果相同。

再按不可动清单逐项回核改动过的段落，比对数字、术语、引用、专名、口径与原稿是否一致。这一步只核"有没有被改动"，不替作者查证真伪；发现原文本身的事实问题，写明"回上游核对"，不在本技能改。

### Step 5 交付

字数分档按原稿正文汉字数计，不含标题、标点与空白：
- ≤1000 字：给"七类命中计数 + 命中类各 1 条例句"的紧凑诊断表（可合并为一段，零命中写"无"），再给改写稿；不得省略诊断。
- >1000 字：先完整诊断报告，再给改写稿。结构见下。

交付必带三样：不可动清单逐项回核结果、改动率（改动句数 ÷ 总句数）、复扫结果（新增命中已清零 / 残留位置与理由）。

短文：

```text

A 套话 X 处｜B 并列 X 处｜C 过渡 X 处｜D 空泛 X 处｜E 节奏 轻微/中度/严重｜F 有/无｜G 有/无
例句：<命中类各 1 条，零命中写"无"，可合并为一段>

【改写稿】
<改写稿>

【修改说明】
共改 X 处（A×n｜B×n｜C×n｜D×n｜E×n｜F×n｜G×n，E 类另标 轻微/中度/严重；X 为各类之和），改动率 Y%（改动句数 / 总句数）；未命中类写"无"；零改动写"原文达标，改动 0 处"。
- [类型] × [处数]：[一个典型改法，标明"原 → 改"]
```

## 验收标准

**阻塞项：任一为 0，直接重做，不看计分项。**

- [ ] B1 无编造：新增细节可追溯原文 / 作者，或明确标注待补；不为"自然"造事实
- [ ] B2 事实层未被改动：数字、术语、引用、口径与原稿一致；改写前已抽不可动清单（数字 / 术语 / 引用 / 专名 / 作者惯用句），交付时逐项回核未变
- [ ] B3 未越界改结构：论点、段落先后顺序、章节结论与原稿一致；句内重组与相邻段合并属语言层，不算越界；跨节移动段落或改动结论判越界

**计分项：**

- [ ] 1 诊断有分类与处数：A–D 给具体类别与处数，E 给轻微 / 中度 / 严重，F / G 给有 / 无；命中类附例句，零命中写"无"，不是"整体偏 AI"
- [ ] 2 改动命中真实病点：改动 ≥3 处抽 3 处，少于 3 处全查，均能对应到分类判据
- [ ] 3 无同义替换式假改：删掉的套话没有用另一句套话补上
- [ ] 4 节奏处理到位：E 类中度及以上的片段已切出长短对比（改写后连续 5 句极差 >5 字）且至少有 2 处明显句长突变，不靠插入单个 4–6 字短句凑极差，也不是全靠短句堆叠；诊断为轻微的保留原样即通过；全文不足 5 句时本项 N/A
- [ ] 5 语气基线一致：改前已采样作者同类文本或声明"单稿基线"；改后正式度与正式 / 中性 / 口语三档场景相符，未滑向另一种模板腔
- [ ] 6 输出完整可核对：诊断按原稿正文汉字数（不含标题、标点与空白）分档——≤1000 字给紧凑诊断（七类命中计数 + 命中类各 1 条例句，零命中写"无"，不得省略诊断），>1000 字给完整诊断报告（七类逐项 + 总体 + 主要问题）；诊断首行给基线与正式度档位；修改说明首行给改动总处数、各类分布与改动率（改动句数 / 总句数），零改动写"原文达标，改动 0 处"，改动率 >60% 须写明理由；写清不可动清单回核与复扫结果；末行留痕通读结果

判定：阻塞任一为 0 = 重做；阻塞全过 + 计分 ≥⌈0.8×N⌉ = 可交付；计分 ≤阈值-1 = 重写。N 与阈值按场景换算（标 N/A 的项不计入分母）：常规 N=6、阈值 5；全文不足 5 句时第 4 项 N/A，N=5、阈值 4。N/A 仅限材料本身不具备该情形，漏做不算 N/A；用户豁免某项时仍计入分母，自检记为未做。

## Gotchas

1. **只换词不改节奏**
   读者说"读着不舒服"，八成是 E 类。把"深刻"换成"具体"救不了均匀的句长；先切句子，再挑词。

2. **删光了衔接，段落散架**
   删过渡词是为了让内容承接，不是删完就走。删后读不通，补的是逻辑，不是再塞一个"与此同时"。

3. **全切成短句，制造第二种机械**
   "这个问题很麻烦。我试了。解决了。"连写十句，和 AI 的长句阵一样假。长短交替才是目标。

4. **加"我"加过头**
   分析、科普类文章塞满"我个人觉得"，会把可信度改没。只在有真实经历的位置加一处。

5. **为了自然改坏事实**
   把"转化率提升 12%"改成"效果挺明显"，是失败而非成功（数字为示例，非真实数据）。原稿里的术语和数字是底线。

6. **把结构问题当语言问题改**
   通篇套话的根因可能是没有主张。这时只改措辞是刷墙；先说明"结构需要回到 `harold-production-pack`"，再改语言。

7. **越改越像另一种模板**
   去 AI 味的终点是像这个人说话，不是像另一种博主腔。改完对照原稿的语气基线，跑偏就退回。

8. **原文已经不错仍然大改**
   只有 1–3 处问题的稿子，只改这 1–3 处。大面积重写会让作者认不出自己的文章。

9. **把"过 AI 检测"当验收标准**
   检测器对非母语写作与非标准文体的误判率很高，同一篇稿在不同检测器上可以给出相反结论。改稿只看七类可观察病点；用户要求"降到 0%"时，先说明检测分数不作判据，再确认平台是否需要 AI 标识。

10. **没有基线就开改**
    只读一遍原稿就断定"像 AI"，改出来的是你的腔，不是作者的腔。先拿两段作者原文当尺子；拿不到就写"单稿基线"，别假装知道作者平时怎么说话。

11. **靠一句短句刷极差**
    插一句"解决了。"，五句极差立刻过 5 字，但节奏还是平的。极差只是最低门槛，至少还要有两处真实的句长突变。

12. **改动率没有上限**
    800 字的稿子改掉 700 字，作者认不出自己的文字。命中少就少改；改动率过 60% 必须说明是病点密度所致，否则按改过头处理。
