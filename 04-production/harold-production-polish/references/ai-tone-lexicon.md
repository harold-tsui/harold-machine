## A 类 · 万能套话

**规则：出现即删，不找同义词替换。** 删完读不通，说明删掉的那句本来就在承担结构作用，要补的是内容，不是另一句套话。

### A1 总结式开头 / 过渡

| 命中 | 改成 |
|---|---|
| 总的来说，这件事说明了三个问题。 | 这件事说明三个问题。（直接进内容） |
| 综上所述，方法比工具更重要。 | 方法比工具重要。（同上，删引导语） |
| 总而言之，先做小范围验证。 | 先做小范围验证。 |

### A2 提示读者注意

| 命中 | 改成 |
|---|---|
| 值得注意的是，复购率在下滑。 | 复购率在下滑。 |
| 不难发现，用户更愿意用手机下单。 | 七成订单来自手机端。 |
| 显而易见，这个方案成本更低。 | 这个方案少花一笔外包费。 |

### A3 时代背景开头

| 命中 | 改成 |
|---|---|
| 随着人工智能时代的到来，越来越多的企业开始关注效率。 | 去年开始，我们接触的团队里有 6 家在试 AI 排班（示例，非真实数据）。 |
| 在当今社会，内容创作者面临巨大竞争。 | 现在一条视频的生命周期大约只有 3 天（示例，非真实数据）。 |
| 在这个快节奏的时代，人们更需要停下来思考。 | 删掉整句，从下一句的具体事实开始。 |

### A4 空泛共情

| 命中 | 改成 |
|---|---|
| 不少人都有这样的体验：明明很努力，结果却不理想。 | 我连着三个月加班，方案还是被退回。 |
| 越来越多的人开始意识到复盘的重要性。 | 真正做完复盘的人不多；我们组 8 个人里只有 2 个。 |

### A5 结尾客套

| 命中 | 改成 |
|---|---|
| 希望本文能对你有所帮助。 | 删。 |
| 欢迎关注、点赞、收藏。 | 删，或换成一句具体的下一步（"下周我会把这套模板放出来"）。 |
| 这是一个值得深思的问题。 | 换成这个问题本身："如果下季度预算砍半，先砍哪一项？" |
| 我们需要认真思考。 | 删；或写出"要决定什么、什么时候决定"。 |

## B 类 · 机械并列与顺序词

**判据**：连续 3 句以上句式完全同构；或取任意 5 句连续内容，起头全是顺序词。
**改法**：并列 → 因果链 / 转折 / 时间推进。

### B1 顺序词堆叠

```text
命中：
首先，我们要做好准备工作。
其次，我们需要制定详细的计划。
再次，我们应当严格执行方案。
最后，我们总结复盘积累经验。

改成：
准备工作很多人跳过了，这是后面反复返工的根源。
计划不需要完美，能执行的计划比精致但搁置的计划有价值得多。
执行中发现的问题，往往比计划阶段预想的更奇怪——这时候怎么应对比计划本身更重要。
```

注意：改写后不必强留四段。宁可三段，也不要为凑结构再补一句。

### B2 "不是…而是"连续排比

| 命中 | 改成 |
|---|---|
| 这不是方法问题，而是认知问题；不是能力问题，而是态度问题；不是执行问题，而是机制问题。 | 方法、能力、执行都没问题，卡住的是机制——没人对结果负责。 |

### B3 每段都用"我们需要"

| 命中 | 改成 |
|---|---|
| 我们需要统一口径。我们需要明确责任人。我们需要建立复盘机制。 | 先把口径统一，再指定一个人对结果负责；复盘放月度会上做，不另开会。 |

### B4 伪结构："三个维度 / 五个层面"

| 命中 | 改成 |
|---|---|
| 从三个维度来看：第一是效率，第二是成本，第三是体验。 | 效率提升靠模板，成本省在人力，体验的变化要等一轮用户反馈才看得出来。 |

## C 类 · 装饰性过渡词

**规则**：先删。删后两段接不上，说明缺的是逻辑，要补具体因果，不是换一个过渡词。

| 命中 | 改成 |
|---|---|
| 不仅如此，转化率也在下降。 | 转化率同期也降了。 |
| 与此同时，竞品开始降价。 | 那两周竞品在降价。 |
| 除此之外，还要考虑人力成本。 | 人力成本另算，一个月约 2 人（示例，非真实数据）。 |
| 更重要的是，团队开始失去信心。 | 真正麻烦的是团队开始不信这套做法了。 |
| 值得一提的是，这套流程只用了两周就落地。 | 落地只花了两周。 |
| 需要指出的是，以上数据来自样本调研。 | 以上数据来自 120 份样本，不是全量。 |
| 总体而言，项目进展符合预期。 | 三期里程碑已过两期，第三期延后一周。 |
| 从整体上看，方案可行。 | 方案可行，前提是预算能批下来。 |
| 对于这个问题，我们的判断是… | 我们的判断是…（删引导语） |
| 针对这一现象，可以从两方面理解。 | 有两种解释，其中一种能对上数据。 |
| 就这一点而言，我更倾向于后者。 | 我更倾向于后者。 |

补充判据：一段里出现 2 个以上这类词，基本可判定为"用过渡词代替论证"。

## D 类 · 空洞形容词与模糊限定

**规则**：删掉形容词，用数字、时间、结果顶上。找不到具体信息就问，不许编。

### D1 宏大形容词

| 命中 | 改成 |
|---|---|
| 这个方案非常有效，产生了深远的影响。 | 用这个方案，我三天内解决了卡了两个月的问题（示例，非真实数据）。 |
| 这是一次深刻的变革。 | 报销从 5 个签字减到 1 个，平均 2 天到账（示例，非真实数据）。 |
| 效果显著提升。 | 退款率从 8% 降到 5%（示例，非真实数据）。 |
| 团队表现卓越。 | 三个人把上线时间提前了 10 天（示例，非真实数据）。 |
| 这是一个关键节点。 | 这一步决定后面三个月做不做。 |

### D2 保险式限定语

| 命中 | 改成 |
|---|---|
| 这在一定程度上提升了效率。 | 每周少开两次会。 |
| 某种意义上，这也是一种妥协。 | 这就是妥协：预算没批，范围砍了一半。 |
| 相对来说，方案 A 成本更低。 | 方案 A 比 B 少花一笔外包费。 |
| 从某种角度看，失败也有价值。 | 这次失败留下了一份可复用的检查表。 |
| 不同程度地受到影响。 | 三个门店停业两天，其余正常。 |

### D3 形容词叠加

| 命中 | 改成 |
|---|---|
| 提供全面、系统、专业的解决方案。 | 提供三件事：诊断、排期、验收标准。 |
| 打造高效、协同、可持续的团队。 | 每个人固定一个交付口，周会只对进度。 |

判据：连用 3 个以上褒义形容词修饰同一名词，几乎必然是空话。

## D4 类 · 大词与伪专业表述（D 类子项）

这类词看起来像结论，实际是把判断往后推了一层。处理方式一致：**追问"具体指什么、凭什么这么说"**，把答案写回去。

| 命中 | 改成 |
|---|---|
| 本质上是组织能力问题。 | 具体是三个人干着同一件事，没人拍板。 |
| 要理解它的内在逻辑。 | 它是先收钱再交付，所以现金流好看。 |
| 这是底层逻辑的差异。 | 两家的分成规则不一样，一个按流水，一个按利润。 |
| 形成闭环。 | 问题从提出到关闭，走同一个人，两周内结。 |
| 提升颗粒度。 | 把月度数据拆到周。 |
| 赋能一线。 | 给一线开放改价权限，上限 5%。 |
| 沉淀方法论。 | 把这次的排期表留成模板，下次直接用。 |

注意：行业里确实有需要精确使用的大词（法律、财务、技术标准）。这类词属"白名单"，见文末。

## D5 类 · 名词化与弱动词（D 类子项）

**判据**：把动作藏进名词，前面垫一个不承担信息的空动词——"进行 / 开展 / 实施 / 作出 / 给予 + 名词"，或"起到…的作用"。

**改法**：还原成动词，删掉垫词。找不到具体动作就问，不补空话。

| 命中 | 改成 |
|---|---|
| 对流程进行优化。 | 改一下流程（砍哪两步、谁来改）。 |
| 作出暂停投放的决定。 | 决定暂停投放。 |
| 起到了降低成本的作用。 | 成本降了（降多少、从哪降）。 |
| 开展一次数据核对工作。 | 核一遍数据。 |
| 给予充分的支持。 | 批预算、给两个人（写具体给了什么）。 |

注意：正式文本里的固定搭配（"进行体检""作出判决"）属白名单，不硬拆；只在垫词不承担信息时删。

## D6 类 · 中文长句病（D 类子项）

**判据**（命中任一即计一处）：
- 名词前定语超过 2 层，一口气读不完；
- 一句里"的"出现 3 次以上；
- "这 / 该 / 其 / 上述 / 前者"指代不明，回看不出指谁；
- "对于…而言 / 就…来说 / 在…方面"作前置框架，去掉后意思不变；
- 一段里"不仅…而且 / 既…又 / 不但…还"出现 2 组以上。

**改法**：断句、后置、指名、去框、减连词。定语拆成独立短句；指代换成具体名词；介词框架删掉直接陈述；关联词一段只留一组。

| 命中 | 改成 |
|---|---|
| 我们需要建立一个能够支撑多业务线同时运行并且在不同区域保持一致的数据口径管理机制。 | 多业务线要同时跑，数据口径就得一致。现在缺一个管口径的机制。（拆定语） |
| 对于已经完成数字化转型的企业而言，其在进行组织调整时所面临的阻力主要来自于既有流程的惯性。 | 转完型的企业调组织，阻力多半来自老流程。（去框架 + 换指代） |
| 这不仅是流程问题，也是数据问题。既要统一口径，又要重建权限，还要改考核。 | 卡点在数据：三家口径不一，权限也没人管。考核先不动。 |

## E 类 · 节奏与排比堆砌

**判据**：AI 生成的中文句长高度均匀，多在 15–25 字。取连续 5 句，若字数差都在 5 字以内，判节奏机械。连续 2 组以上四字排比或同构短语（E1、E2）也计入 E 类，即使单句句长并不均匀。

```text
命中（每句约 20 字）：
这个问题需要我们认真对待，因为它影响着我们的生活。
很多人在面对这种情况时都会感到困惑，不知该如何处理。
我们可以采取一些有效的措施来改善这种情况，提升质量。

改成（长短交错）：
这个问题很麻烦。
不是说不能解决，而是很多人根本不知道从哪下手——确认问题在哪才是第一步。
我后来试了这个方法，解决了。
```

要点：
- 短句可以只有 4–6 字："解决了。""不划算。""我试过。"
- 长句靠破折号、括号带出补充，不必每句都完整主谓宾。
- 一段里至少有两处句长突变；只插一个 4–6 字短句把极差刷过 5 字，不算改好，前后句仍要长短交替。

### E1 四字排比

| 命中 | 改成 |
|---|---|
| 统一思想、凝聚共识、形成合力、推动落地。 | 先让三个人同意一件事：谁改、改到什么时候。 |
| 有温度、有深度、有态度。 | 会说人话，敢下结论。 |

### E2 每句都是"通过…实现…"

| 命中 | 改成 |
|---|---|
| 通过优化流程实现降本，通过培训实现提效，通过数据实现精细化。 | 流程砍掉两道审批，省一个人力；培训只做新人第一周；数据先看三个指标。 |

## F 类 · 升华式结尾

**规则**：最后 1–2 段的空洞升华直接删，换具体动作、判断或真实问题。

```text
典型 AI 结尾（删掉）：
"生活就是如此，需要我们不断探索和前行。"
"愿我们都能在这条路上找到属于自己的答案。"
"这不仅仅是一个选择，更是一种态度。"
"让我们共同努力，迈向更美好的明天。"
```

| 命中 | 改成 |
|---|---|
| 愿我们都能找到自己的节奏。 | 我现在的做法是每周只排三件必做的事，其余往后放。 |
| 这不仅是工具的改变，更是思维方式的升级。 | 工具换了以后，开会时间从每周 6 小时降到 2 小时（示例，非真实数据）。 |
| 未来可期，共同成长。 | 下个月我会再跑一次同样的流程，看数据有没有变化。 |

可接受的结尾只有三类：一个具体动作、一个明确判断、一个还没答案的真问题。三者都没有，就停在上一段。

## G 类 · 视角缺失

**规则**：全篇只有"我们 / 人们"是信号。补一处能核实的视角即可，不必通篇第一人称。

| 命中 | 改成 |
|---|---|
| 人们普遍认为，面对挑战时需要保持积极心态。 | 我以前也这么想，直到第三次失败后才发现这句话的问题在哪。 |
| 我们需要改变这种观念，重新审视自己的选择。 | 让我改主意的是那次复盘：三个月投入，实际用上的功能只有一个。 |
| 很多团队都会遇到类似问题。 | 我们那组 12 个人，前两个月就卡在这一步。 |

边界：科普、分析、报告类文本，加 1–2 处具体来源（"某次访谈中，对方提到…"）通常比加"我觉得"更合适。

## 成段改写对照

### 对照 1 · 报告腔（A + C + D 混发）

```text
原：
总的来说，随着数字化转型时代的到来，越来越多的企业开始重视数据建设。值得注意的是，数据治理是一个系统性工程，需要从战略高度重视。更重要的是，我们要建立长效机制，持续提升数据质量，从而为业务赋能。

改：
我们去年上了一套报表系统，前三个月没人用。
原因不复杂：字段口径三套，同一个"活跃用户"在三个部门是三个数。
后来只做了一件事——把口径写进一张表，谁改谁签字。三个月后，日报的打开率从两成涨到六成（示例，非真实数据）。
```

### 对照 2 · 营销腔（D3 + E1）

```text
原：
我们致力于为客户提供全方位、高品质、一站式的解决方案，以卓越的专业能力和极致的服务体验，助力企业实现跨越式发展。

改：
我们只接三类活：门店开业、季度促销、新品发布。
报价按项目算，不含投放；改稿两轮以内不另收费。
去年做了 14 个门店项目，其中 11 个在开业当天回本（示例，非真实数据）。
```

### 对照 3 · 过度口语化（反向示例，说明改过头）

```text
原（规范但可读）：
本季度复购率为 31%，较上季度下降 4 个百分点，主要受促销节奏变化影响。

改过头（失败）：
复购率掉了点，就那样吧，反正大家都懂，促销搞得乱七八糟的。

合格改法：
复购率从上季度的 35% 掉到 31%（示例，非真实数据）。主要原因是这季度没做大促，上季度那波满减拉高了基数。
```

要点：口语化是让句子顺，不是把精确信息换成含糊词。数字与因果必须留下。

## 白名单 · 不该动的地方

| 情况 | 处理 |
|---|---|
| 列举逻辑真的需要顺序（操作步骤、SOP、法条） | 保留"第一步 / 第二步"，只删装饰性顺序词 |
| 正式报告、公函、对外公告 | 保留规范表达，只删套话与空形容词，不强行口语化 |
| 行业术语、法务/财务/技术专有表述 | 原样保留，不替换成"更好懂"的说法 |
| 原文本来就写得好的句子 | 不动。改了反而生硬 |
| 数据、引用、口径 | 一律不动；原文没有数字时，不许新编 |
| 作者的个人语气特征（爱用短句、爱用反问） | 保留，这是"像本人"的依据，不是 AI 味 |
