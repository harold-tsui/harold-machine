# 验收用例：图文视觉

## Case 1 · 只有一段文案，要出成套封面

**输入**："就这段介绍我们新版排课工具的文字，帮我做一套社媒封面和图。"

**期望特征**
- 先把文案压成一句 6–14 字主判断，并标"待确认"，再谈视觉。
- 给出卡片脚本：每张一句判断、一个目的、一个主组件；张数按原文长度定（3000 字以内 → 1 封面 + 2–4 张内文图），不套固定张数模板。
- 输出完整参数：比例 3:4、边距、三级字阶、主色 + 强调色及占比。
- 逐页 prompt 可复制，且写明中文限定（短、少、清晰）或改用 HTML/CSS 渲染。
- 至少 3 种页面结构：封面 / 机制页 / 数字页 / 收束页，不复制同一模板。
- 无来源的数字标"示例，非真实数据"。

**常见失败**
- 直接给一整组同模板，只换标题。
- 把原文段落整段搬进图里。
- 只写"黑底绿字、科技感、高级"，没有任何版式参数。
- 封面标题 20 字以上，缩小字号硬塞。

## Case 2 · 用户给参考图要求复刻风格

**输入**："就按这张图的感觉，把我们的内容也做一套。"（附一张深色终端风卡片）

**期望特征**
- 先拆解参考图，而不是马上生成：媒介、网格与边距、字号层级、色值占比、组件清单、留白节奏。
- 把结果写成"风格契约"（可复用的规则），再用用户自己的文案重排。
- 明确划掉不能复刻的部分：对方的账号名、水印、品牌标识、原文案与真实数据。
- 若参考图尺寸与目标渠道不符，说明如何等比迁移（改边距与字阶，不拉伸）。
- 交付里含一页试样，方便用户先确认再批量。

**常见失败**
- 只回"好的，仿照这个风格"，然后给一段泛化 prompt。
- 把"高级感"复刻成"高对比 + 发光更多"。
- 连对方的水印、头像、账号一起复刻。
- 直接拉伸参考图尺寸，字阶与边距全部失真。

## Case 3 · 用户要求生成真实数据图表

**输入**："画一张我们 2025 年市场规模的图，数据你看着编，看着专业就行。"

**期望特征**
- 拒绝编造：说明视觉层不能替代数据来源。
- 区分三种状态并落字：真实（有来源与口径）、待核验、示例（非真实数据）。
- 给替代路径：用户提供数字与口径 → 按其渲染；无数据 → 先出带占位框的版式，标注"待填真实数据"。
- 说明为什么不把数据交给生图模型：数字会失真、无法核对；建议 HTML/CSS 或表格工具出图。
- 若坚持要示意图，输出里必须出现"示例，非真实数据"字样。

**常见失败**
- 顺手编三个漂亮数字（如"8.7 亿""增长 240%"）并当成事实。
- 让生图模型在图上写数字，出现错位与错字仍交付。
- 只在末尾写一句"数据仅供参考"，正文却按真实数据排版。
- 用"行业公开数据"含糊带过，不给口径。

## Case 4 · 只要一条 prompt，不成组出图

**输入**："图我自己出，就给我一条能直接用的 prompt。"（附一段 200 字的产品更新文案）

**期望特征**
- 先判模式为"只要 prompt"，不跑卡片脚本，也不问"要不要顺便做套图"。
- 先给视觉命题（6–14 字，可独立成立），并说明它落在 prompt 的叙事层，而不是标题层。
- 只给 1 条 prompt，覆盖九层；版式约束写进 prompt 本身：比例、边距占比、字阶比、单强调色及占比上限、对比度要求。
- 中文处理有明确选择：交给 HTML/CSS，或限定"简体中文、6–14 字、少字清晰"。
- 质检以约束代替渲染：三项写进 prompt，并注明"以约束代替渲染核验"。
- 文案里的数字标为示例或待核验，不写成事实。

**常见失败**
- 仍然先输出 5 张卡片脚本，再补一段 prompt。
- 只有风格词，没有任何版式参数。
- 让模型在图上写整段中文。
- 用户只要 1 条，硬凑三版。
- 顺手编数字，或把示例数据写得像真实数据。

## 评分表（3 项阻塞 + 7 项计分，逐项 0/1）

**阻塞项：任一为 0，不得交付，不看计分项。**

| # | 检查项 |
|---|---|
| B1 | 不编造：数字标注真实 / 待核验 / 示例，无编造；没有来源就不按真实数据排版 |
| B2 | 不越界：不改内容结构，不混入 PPT 版式规格；无原文时不虚构主判断，改出配图位预留清单 |
| B3 | 主判断成立：成组卡片时，一句话且可脱离原文独立成立；只要 prompt 时，以"视觉命题"（画面要让读者看到什么）替代，同样须一句话、可独立成立 |

**计分项：**

| # | 检查项 |
|---|---|
| 1 | 卡片脚本每页一个判断，张数按字数口径有依据而非套模板；只要 prompt 时本项 N/A |
| 2 | 版式参数具体：尺寸、边距、三级字阶、色比、文字对比度（正文 ≥4.5:1、大字 ≥3:1）；结构图 / 对比图参数齐备（对比图双色须同色系两档明度，并有文字标签 / 线型 / 纹理等非颜色编码） |
| 3 | prompt 覆盖九层：媒介、主体、构图、光线、材质、色彩、叙事、文字/版式、负面约束 |
| 4 | 中文可读性有方案（短大字，或改走 HTML/CSS） |
| 5 | 一组图至少 3 种页面结构，非同一模板复制；只要 prompt 或无成组交付时本项 N/A |
| 6 | 质检三项逐项给结论：缩到信息流缩略尺寸（约屏宽 1/3）2 秒内能读出主标题、每页一个视觉中心、荧光色像素占比不超过画面 10%；只要 prompt 时以 prompt 内的版式约束代替渲染核验 |
| 7 | 复刻参考图时只复刻版式契约（网格 / 字阶 / 色比 / 组件），不复制对方账号、水印、品牌标识与原文案；非复刻场景记 N/A，不计入分母 |

判定：阻塞任一为 0 = 重做；阻塞全过 + 计分 ≥⌈0.8×N⌉ = 可交付；计分 ≤阈值-1 = 重写。N 与阈值按场景换算（标 N/A 的项不计入分母）：成套卡片 7/6；成套卡片且非复刻 6/5；只要 prompt 5/4；只要 prompt 且非复刻 4/4（N/阈值）。N/A 仅限材料本身不具备该情形，漏做不算 N/A；用户豁免某项时仍计入分母，自检记为未做。
