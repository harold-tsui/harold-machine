# 案例库（结构参考）

> 说明：以下案例只保留结构与约束写法，用于对照提示词的骨架，不含可识别的人物、账号或品牌信息。
> 案例中的数值、单位、品牌均为占位示例，非真实数据。

## 1. 博物馆图鉴式中文拆解图

适用：知识科普、器物 / 服饰 / 体系拆解、培训讲义单页。
骨架：

```text
请根据【主题】生成一张博物馆图鉴式中文拆解信息图：
真实写实主视觉 + 结构拆解 + 中文引线标注 + 材质说明 + 色彩含义 + 核心特征总结。
版式固定：顶部主标题/副标题/导语；左侧结构拆解区（引线标注 + 局部特写）；
右上材质工艺区（真实纹理小样）；右中纹样色彩寓意区（色板 + 解释）；
底部构成流程 + 一句话总结。
米白 / 绢纸白纸感背景，简体中文，清晰规整；避免海报感、电商感、动漫感、糊字、假材质。
```

关键点：分区写死，模型才不会自由排版；"引线标注"必须明写。
不要：把"高级感"堆在前三句而版式不写。

## 2. 轮廓宇宙叙事海报

适用：单张封面、品牌主题、年度回顾。
骨架：

```text
请根据【主题】自动选择一个最有象征意义的主轮廓载体（门、塔、侧脸、眼睛、裂缝、圆环均可），
让完整叙事世界生长在这个轮廓之内 / 之上 / 之边界，而不是简单装进容器。
要求：轮廓清晰且居核心；内部有远中近景递进；细节丰富但不拥挤；
收藏版海报构图 + 纸张颗粒 + 飞白 + 大面积留白 + 低饱和配色。
避免：瓶子/沙漏等常见容器套路、素材拼贴、游戏宣传图感、形式大于内容。
```

关键点："先选轮廓再长世界"是强支点写法；负面词要否掉最省事的那几个容器。
不要：只说"史诗感海报"，模型会返回满屏奇幻拼贴。

## 3. 极端透视字体海报

适用：活动主视觉、口号型封面、线下物料。
骨架：

```text
[场景/表面]，giant bold sans-serif typography of "[文字]" painted onto the surface，
从近端沿表面向远端 progressively foreshortens，
letterforms conform to surface curvature, surface-integrated not floating；
部分文字被前景遮挡，缝隙中露出，形成纵深穿插；
[双色描边]，extreme perspective distortion aligned to vanishing point，
cinematic lighting, poster-grade integrated typography。
```

关键点：文字是结构的一部分，不是贴上去的图层；写清"贴合曲面 / 不悬浮"。
不要：只说"立体字"，会得到廉价 3D 字效。

## 4. 城市海报（S 型动线 + 双重曝光）

适用：城市 / 地域主题、年度盘点、品牌叙事封面。
骨架：

```text
[城市] 主题海报，S 型流动构图：一个微缩人物挥动 [元素]，动势向上延伸，
逐渐变形为 [山脉/河流/城市全景]，沿途叠加地标序列。
大面积留白，[主色] 为主，辅助色克制；左下角主标题 + 竖排副标题，字迹完整清晰。
整体清新脱俗，避免堆砌与拥挤。
```

关键点：一条动线串起全部元素，元素再多也不乱；标题位置写死。
不要：把地标逐个罗列却不给动线，那是素材清单。

## 5. 手绘城市地图 / 信息插画

适用：攻略、路线、区域盘点、活动指引。
骨架：

```text
手绘风格城市地图（主题 [X]）：鸟瞰简化地图为底，标注主干道与地标但不追求比例；
分布 [N] 个手绘小插画点位，每点约占画面 5%，旁注店名 + 一句推荐语；
边缘用与主题相关的元素做手绘边框；右下角指南针与图例；左上角手绘美术字标题。
水彩 + 彩铅质感，暖色系为主，1:1。
```

关键点：点位数、占比、注文字数都要给数，否则插画会糊成一团。
不要：只写"手绘风、可爱、丰富"。

## 6. 平台截图拟态

适用：把观点包装成"截图"、模拟产品界面、对话体叙事。
骨架：

```text
生成一张竖版 [平台] 截图风格图片，比例 9:16。
顶部系统状态栏（时间 / 电量 / 信号）；中部为主体内容；
底部叠加半透明对话框：左侧头像，右侧第一行角色名，下两行简体中文台词；
整体高清、光线柔和、界面间距真实。
```

关键点：截图的可信度来自状态栏、间距、图标节奏这些"证据"。
不要：用真实品牌界面与真实人物身份（涉及授权与造假风险）。
如需仿制某 App，改成"通用深色模式社交界面"。

## 7. 涂鸦速写风

适用：观点图、轻松科普、内页插图。
骨架：

```text
以涂鸦速写风表现【主题】：快速勾勒、线条粗细不一、略带凌乱但有节奏；
干刷色块，保留刷痕与飞白；背景以留白为主，可加箭头、圈画、随手字；
整体轻松、未完成感、有设计感；不要水彩晕染、不要柔和雾化、不要纸纹堆砌。
```

关键点：负面清单比正面描述更能定住风格。
不要：把"涂鸦"写成"手绘插画"，会变成精致插画风。

## 8. 商品广告照

适用：产品图、详情页头图、上新封面。
骨架：

```text
商品广告写真：[季节/场景]，[商品品类]，名称占位 = "[示例名]"，规格 = [示例规格]。
先研究该类目近年高转化的视觉套路，再据此定构图与光线；
[主色] 为主，[辅助色] 点缀；1:1；产品占画面 [比例]；
保持真实材质与反射，避免过度修图。
```

关键点：先"研究套路"再"定规格"，这句本身就是 prompt 的一部分。
不要：只写"高级商品图"，会得到通用图库感。

## 用法

- 先找结构最接近的一条，替换占位符，不要整段照搬。
- 案例只提供骨架，版式参数回 `visual-system.md` 取。
- 引用他人作品风格做商用交付时，改到"结构相似、表达不同"，并保留来源记录。
