# 版式、配色与组件规范

用于竖版社媒图文：深黑底 + 终端窗口 + 信息图卡片，做成"被拆成卡片的发布说明"。

## 一句话风格

黑底、荧光高亮、终端窗口、数据卡、时间线、大字号中文判断——像一份产品发布说明被拆成了卡片。

## 画面 DNA

必备：

- 深黑背景，不纯平黑：要有细噪声、扫描线、暗纹或网格。
- 1 个超大中文标题，形成第一视觉锚点。
- 1 个主组件：终端窗口 / 数据看板 / 时间线 / 指标卡。
- 小号英文标签：`CORE UPDATE`、`TIMELINE`、`NUMBERS`、`STRATEGY`、`RELEASE NOTES`。
- 局部荧光色：绿为主，黄 / 青 / 粉为辅助。
- 底部状态条、日期、版本号、命令行或一句短结论，增强"技术发布感"。

不要做：

- 满屏装饰线条。
- 廉价蓝紫渐变铺底。
- 每个盒子都做玻璃拟态。
- 随机 3D 图标、机器人、小人、科技城市背景。
- 中文文字又小又多。

## 尺寸与网格

- 推荐尺寸：`1080 x 1440`（3:4 竖版）。1:1 用 `1080 x 1080`，9:16 用 `1080 x 1920`。
- 安全边距：左右 `70–90px`，顶部 `70–110px`，底部 `144–200px`（≥10%，避开信息流标题栏与互动图标）。
- 主内容宽度：`900–940px`。
- 垂直节奏：
  - 顶部标签区：`60–90px`
  - 大标题区：`220–360px`
  - 主组件区：`350–550px`
  - 底部结论 / 状态区：`80–160px`

同一套图里这五条栅格必须一致；换版式只换组件，不换边距。

## 字体规则

中文标题：粗黑体，字重 800–900；封面 `120–180px`，正文页 `86–130px`；行距 0.95–1.08。

中文正文：中黑体 / 苹方 / 思源黑体，`32–44px`，行距 1.35–1.55。

英文与代码：等宽字体，字距略大，`22–34px`，只用于标签、命令、日期、版本、状态条。

字阶只留三级：标题、正文、标签。出现第四级就是层级失控。

对外发布只用可商用或系统字体；交付注明字体名与授权状态，不确定标"待确认"，不把未授权字体写进 prompt 让模型模仿。

## 色彩系统

基础色：

| 用途 | 值 |
|---|---|
| 背景黑 | `#070908` |
| 卡片黑 | `#151716` |
| 边框灰 | `#2B302E` |
| 正文白 | `#ECEEEE` |
| 次级灰 | `#8B9299` |

强调色：

| 用途 | 值 |
|---|---|
| 主强调绿 | `#00F58A` |
| 数据黄 | `#FFD84D` |
| 冷青 | `#2ED9FF` |
| 警示粉 | `#FF5EBB` |
| 暖橙 | `#FF7A45` |
| 冷紫 | `#A56BFF` / `#6EA8FF` |

使用比例：黑灰 80–88%，白字 8–12%，主强调 4–7%，辅助强调 1–3%（强调色合计 ≤10%）。
一个页面只用一个主强调色，辅助色只给数据和标签。
对比图例外：允许双色，但必须是同一色系的两个明度档（如 90% / 55%），不引入第二种色相。
文字对比度按 WCAG AA 兜底：正文与小字 ≥4.5:1，大字（≥24px 常规或 ≥18.66px 粗体）≥3:1。深灰底上的次级灰（如 `#8B9299`）只能用于非关键标签；承载信息就得提亮到 4.5:1。
强调色与背景的实际对比度要验算，不靠肉眼；同一组图里所有文字色对必须逐一过线。

浅底（博物馆图鉴族）：底 `#F4F0E6`，正文 `#2A2723`，辅助 `#8C8578`，强调 `#9B3B2E`；纹理用纸纹与细噪点，不用渐变。

## B 族 / C 族参数

A 族（深黑终端）的网格、字阶、组件按上文执行。B / C 族共用尺寸与安全边距，分区与字阶按本表。

### B 博物馆图鉴

| 项 | 参数 |
|---|---|
| 分区 | 顶部标题区 `180–260px`；中心主视觉 `480–620px`；底部总结 `120–180px` |
| 字阶 | 标题 `72–110px`；正文 `28–36px`；引线标注 `24–30px` |
| 引线标注 | 单条 ≤14 字；标注区不超过画面 1/3；引线只用直角转折 |
| 组件 | 中心主视觉 + 引线标注 + 材质小样 + 色板 + 底部构成流程 |
| 配色 | 底 `#F4F0E6`，正文 `#2A2723`，强调 `#9B3B2E`；辅助 `#8C8578` 只用于 ≥24px 的大字，小标签改用正文色 |

### C 叙事海报

| 项 | 参数 |
|---|---|
| 支点 | 强轮廓 / 强动线 / 强光源三选一，其余元素服从支点 |
| 留白 | ≥40%；文字块 ≤3 个（标题、副标题、落款） |
| 字阶 | 标题 `96–150px`；副标题 `30–40px`；落款 `22–28px` |
| 标题 | 6–14 字，位置固定左上或底部，不居中漂浮 |
| 配色 | 主色 1 + 中性 2；不引入荧光色，层次靠明度不靠饱和度 |

## 组件库

### A. 终端窗口

适合：功能更新、操作流程、命令流。
结构：顶部三色圆点 → 标题栏 → 命令行与输出行（箭头 / 勾 / 进度点）。
文案结构：

```text
$ 执行"批量导出全部画板"
  -> 打开应用 ✓
  -> 导出 24 个画板 ✓

$ 执行"跑一遍登录流程"
  -> 逐步点击 ...
  ✓ 3/4 用例通过
```

### B. 巨型标题页

适合：封面、强观点、章节页。
结构：顶部小标签 `[ 01 / CORE UPDATE · 2026.04 ]` → 大标题 2–3 行（关键词单色）→ `//` 开头的副标题 → 一个宽终端框或前后对比框。

### C. 时间线卡

适合：产品演进、战略阶段、模型迭代。
结构：≤5 个节点；日期左对齐、事件右对齐；最新节点加 `LATEST`；细分割线维持秩序。

### D. 数据三联卡

适合：增长、速度、收入、转化、规模。
结构：横排 3 张卡；每张一个大数字 + 2 行解释；左侧一条彩色竖线；绿 / 黄 / 粉分别对应规模、增长、效率。

### E. 底部结论条

适合：每页收束。
结构：半透明深色矩形；左侧关键词，右侧结论；文案 1–2 行、≤40 字。

### F. 冷紫暖橙变体

适合：设计工具、应用构建、创意类选题。
结构：仍为深黑底，中心可加紫蓝柔光；主强调换暖橙；组件边框用紫蓝霓虹。发光只在边框周围，不铺满全图。

### G. 结构图

适合：机制、系统、层级、流程拆解。
可执行参数：节点数 3–7 个；单行文字 ≤14 字；垂直行高 = 1.4 倍字号；连线只用直角（横 + 竖），不用斜线或曲线。

### H. 对比图

适合：前后变化、方案对比、竞品对比。
可执行参数：左右分屏 1:1 或 2:1；双栏各一个标题；差异项 ≤3 条；差异值用同一色系的两个明度档（如 90% / 55%）标注，并再加一种非颜色编码（文字标签 / 线型 / 填充纹理），不靠颜色单独区分。

## 卡片类型模板

### 01 封面

目的：让用户停住。
必须有：6–14 字主标题；1 个强变化判断；1 个小终端窗口或前后对比组件；3 个数字 / 标签可选。
标题公式：`X 大变身` / `X 来了，Y 慌了` / `不是 A，是 B` / `一年走完 N 级跳` / `从 A 到 B`。

### 02 核心更新

目的：解释发生了什么。
结构：章节标签 → 大标题（如"能操作你的电脑了，不只是写代码"）→ 中部终端窗口展示 2 个具体任务 → 底部能力标签。

### 03 时间线

目的：给变化找历史坐标。
结构：大标题 → 中部时间线 → 底部一句关键判断。

### 04 数字页

目的：证明增长或冲击。
结构：大标题 → 3 张数据卡 → 终端风列表 → 底部趋势状态条。数字必须带口径。

### 05 战略页

目的：给出独家判断。
结构：大标题 → 树状结构 / 系统图 → 引用式判断 → 底部 next 状态条。

### 06 收束页

目的：让用户收藏、转发。
结构：顶部完成状态 `[ ✓ ] UPDATE · DONE` → 中央一句话总结 → 3 个阶段小卡 → release notes 风格签名。

## 复刻契约（照参考图做一套时，先填这张表）

| 项 | 记录什么 | 迁移规则 |
|---|---|---|
| 画布 | 比例与像素 | 换成目标渠道尺寸；比例不一致时扩边，不拉伸 |
| 网格 | 列数、边距占宽比例 | 按百分比换算，保持同一边距占比 |
| 字阶 | 标题 / 正文 / 标签的像素与倍率 | 保留倍率关系（如 4 : 2 : 1），整体缩放 |
| 色彩 | 底色、强调色值与占比 | 换色值不换占比；语义色不跨页互换 |
| 组件 | 元素清单与相对位置 | 保留结构关系，内容全部换成本方文案 |
| 留白 | 主要留白区位置与占比 | 不压缩留白去塞内容 |
| 质感 | 噪点 / 纸纹 / 反光来源 | 用同类质感，不叠加对方特有装饰 |

不可复刻：账号名、头像、水印、品牌标识、原文案、真实数据、可识别人物肖像。
交付顺序：契约表 → 1 页试样 → 用户确认 → 批量出图。

## 中文准确时改走 HTML/CSS

生图不适合承载中文正文。中文多、数据多时：HTML/CSS 负责全部文字、版式、组件，生图只出背景纹理，最后截图导出 PNG。

```css
body {
  width: 1080px; height: 1440px;
  background:
    linear-gradient(rgba(255,255,255,.025) 1px, transparent 1px),
    radial-gradient(circle at 50% 30%, rgba(0,245,138,.12), transparent 32%),
    #070908;
  background-size: 100% 4px, 100% 100%, 100% 100%;
  color: #eceeee;
  font-family: "PingFang SC", "Noto Sans CJK SC", sans-serif;
}
.mono { font-family: "SF Mono", "JetBrains Mono", monospace; }
.accent { color: #00f58a; }
.panel {
  background: #151716;
  border: 1px solid #2b302e;
  border-radius: 10px;
  box-shadow: 0 0 40px rgba(0,245,138,.06);
}
```

## 发布前自检

- 缩到宽 360px（约屏宽 1/3），只看 2 秒，能复述主标题且不误读。
- 每页只有一个视觉中心。
- 中文无乱码、错字、尴尬断行。
- 荧光色像素占比不超过画面 10%。
- 正文与小字对比度 ≥4.5:1，大字 ≥3:1。
- 对比图除颜色外有文字标签、线型或纹理区分。
- 底部 10% 只放装饰，标题、结论与数字不进遮挡区。
- 组件对齐、边距一致。
- 字体可商用或为系统字体，授权状态已注明。
- 数据与日期已核验，或明确标为示意。
- 一组图至少 3 种页面结构，不是同一模板复制整组。
- 封面强、正文清楚、结尾有观点。
