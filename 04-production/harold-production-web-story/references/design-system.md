# 视觉框架清单

一页框架，够用就好。每页做视觉决策前对照一遍。

## 布局

- 移动优先：先写 375px 布局，桌面端用 `min-width` 媒体查询做加法。
- 容器最大宽度 1080~1200px；章节间距大、卡片内间距小，层级靠间距拉开。
- 间距用 8 的倍数（8/16/24/40/64）。
- 阅读预算：全文 2–3 分钟读完，每章正文 40–120 字。

## 配色与字体

- 主色 1 个 + 中性色 3~4 阶 + 强调色 1 个，每页只允许一个视觉记忆点。
- 正文与背景对比度 ≥ 4.5:1。
- 中文用系统字体栈（`-apple-system, "PingFang SC", "Noto Sans SC", sans-serif`），字号层级不超过 5 级。
- 圆角、阴影全站各统一一档。

## 动效

- CSS transition 能解决就不用动画库。
- 标配三样：滚动进入淡入、hover 微浮起、锚点平滑滚动。
- 时长 150~300ms；尊重 `prefers-reduced-motion`。

## 反 AI 味（最重要的几条）

- 标题写论点，不写类目名（"行业分析"→"这个行业正在发生的一件事"）。
- 数字必须带来源；没来源就写事实，不写数字。
- 不用 emoji 当图标，不用紫蓝渐变 hero 配三栏卖点卡片。
- 不写"赋能""一站式""全方位"这类空话。

## 交互

- 锚点导航、卡片展开、维度切换 Tab 三样覆盖绝大多数需求。
- 独立可点元素（导航项、按钮、卡片链接）触控高度 ≥ 44px（内部标准，严于 WCAG 2.5.8 的 24×24 AA），图标按钮宽高均 ≥ 44×44px；正文句子内的来源链接按 WCAG 2.5.8 Inline 例外豁免，但同一段内相邻链接要留出间距。
- 有 sticky / fixed 导航时，页面设 `scroll-padding-top`，章节设 `scroll-margin-top`，值不小于导航高度。
- 关键信息不要藏在 hover 里（手机没有 hover）。

## 可访问与分享

- 信息图写 `alt`：一句话说清它传达的结论；纯装饰图 `alt=""`，不要省略属性。
- 键盘 Tab 到导航、按钮、卡片链接时焦点框必须可见；不要用全局 `outline: none` 抹掉。
- `prefers-reduced-motion: reduce` 时关闭滚动进入淡入与平滑滚动，只保留即时状态变化。
- head 必备：`<html lang>`、`<title>`、`og:title` / `og:description` / `og:image`（绝对 URL、1200×630）。
- hero 图用 WebP / AVIF，宽按容器 2 倍、单张 ≤300KB，写 `width` / `height`；首屏 LCP ≤2.5s、CLS ≤0.1、INP ≤200ms（Core Web Vitals「良好」档）。
- 不劫持滚动：不拦截 wheel / touch、不做滚动锁定；叙事含义写在真实 DOM 文本里，读屏与键盘用户能完整拿到。
