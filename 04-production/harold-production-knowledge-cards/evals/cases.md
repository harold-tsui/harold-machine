# 知识卡片流 · 验收用例

三条用例覆盖：正常批量、人物主题、边界（低可信 + 合规 + 离线）。

---

## Case 1 一句话要一副牌

**输入**："帮我把常见的私域运营名词做成卡片，20 张左右。"

**期望**

- 先用一句话补齐三件事：主题边界（私域运营术语）、张数（20）、分类体系（如 concept / traffic / conversion / risk），缺项标"假设"。
- 出词有来源：要么用户给词表，要么用 `next_term.py --peek` 从词库按优先级出，并说明剩余量。
- 每张卡 `definition` 30–160 字、`termZh` 2–20 字、`misuse` 写了具体错法（例："以为加微信就是私域"），不是把定义换个说法。
- `definition` 首句给"属 + 种差"，不出现"XX 就是 XX 流量"这类循环定义，也不用本副牌里还没解释的术语解释它。
- 交付前给自检结果，再给 `terms.json` 与 `deck.html`。

**不通过**：直接吐 20 段文字；或卡片标题写成完整句子；或 `misuse` 空缺。

---

## Case 2 人物拆解

**输入**："做一套 40 张的创业者人物拆解卡片。"

**期望**

- 分类用五段式：`life` 6–8 / `works` 8–11 / `mind` 7–9 / `fall` 5–6 / `lesson` 7–8，总数落在 33–42。
- 渲染前显式给 `categories` 五段映射，否则渲染器会因缺中文标签退出。
- `fall` 段有失败、争议或暗面，不是整副牌吹捧。
- `works` 每张写清"当时行业默认是什么、他改了什么"。
- `mind` 每条能配一句当事人原话；找不到原话就标"原话未核实"，不编。
- `lesson` 是可迁移结论，落到读者自己的业务，不是"要努力"这类空话。

**不通过**：整副牌只有里程碑与成就；或 `fall` 段被合并进 `life`。

---

## Case 3 边界：低可信、合规与离线

**输入**："把这 10 个新兴概念做成卡片，其中几个网上说法不一致，有两个涉及宣传话术。"

**期望**

- 说法不一致的概念 `confidence` 标 <0.6，卡片底部出现"业内无统一口径，以下为常见用法"。
- 涉及宣传话术的卡 `riskFlag=advertising`，卡片底部附风险提示；该卡不得出现无事实依据的绝对化用语（"最""第一""保证"等）；非广告卡不按广告口径逐词扫（《广告法》第九条第三项、《广告绝对化用语执法指南》）。
- 无确切来源的数字留空 `metricHint`，不编"约 30%"。
- 生成的 HTML 单文件零外部依赖，双击可开；滚轮翻一页、目录跳转、分类筛选、复制本条四项都实际可用。
- 在 700px 高的视口下打开，卡片底部的风险提示与关联词仍可见（卡片内可滚），没有被裁掉；Tab 能依次到达目录、筛选、复制与自动播放。
- 系统开启「减少动效」时打开，翻页直接切卡、不做位移动画，自动播放仍由用户点击才启动。

**不通过**：给低可信概念标 0.9；或 `riskFlag` 填了但没提示语；或 HTML 引用了外链字体与 CDN 脚本导致离线打不开；或短屏下风险提示被裁、键盘无法到达上述按钮；或忽略减少动效设置。

## 评分表

**阻塞项：任一为 0，不得交付。**

- [ ] B1 卡片写法合规：`definition` 30–160 字且不循环定义、不引用本套牌未解释的术语，`termZh` 2–20 字且是名词不是句子，`misuse` 非空且写了具体的错法
- [ ] B2 不编造：`sourceType=officialDoc` 的卡片写得出可复核出处；`sourceType=inferred` 的卡片没有具体数据与出处；`confidence<0.6` 的卡片有"业内无统一口径"提示；`riskFlag≠none` 的卡片有风险提示
- [ ] B3 产物可离线：HTML 为单文件零外部依赖，双击可开，翻页、目录、筛选、复制四个交互都可用，键盘可达且焦点可见，尊重 `prefers-reduced-motion`

**计分项：**

- [ ] 1 分类体系显式声明，渲染后卡片上没有裸英文 key
- [ ] 2 同批去重：`termZh` 与别名不重复，`termId` 为 `前缀-4位` 且递增
- [ ] 3 人物卡用五段式，且 `fall` 段写了失败与争议（非人物主题标 N/A）
- [ ] 4 `misuse` 写了"谁、在什么场景下、付出什么代价"三项中的至少两项，不是把定义换个说法
- [ ] 5 `plainAnalogy` 的类比取自卡片主题之外的日常场景，且除 `termZh` 本身外不出现本套牌里的其他术语
- [ ] 6 用了游标脚本的场景已执行 `--commit`（未使用标 N/A）

判定：阻塞任一为 0 = 重做；阻塞全过 + 计分 ≥⌈0.8×N⌉ = 可交付；计分 ≤阈值-1 = 重写。N = 6，阈值 = ⌈0.8×6⌉ = 5；非人物主题第 3 项 N/A、未使用游标脚本第 6 项 N/A，单项 N/A → N = 5、阈值 ⌈0.8×5⌉ = 4，两项同时 N/A → N = 4、阈值 ⌈0.8×4⌉ = 4。N/A 仅限材料本身不具备该情形（非人物主题无 fall 段可查、未用游标脚本无 commit 可查），漏做不算 N/A；用户豁免某项时仍计入分母，自检记为未做。
