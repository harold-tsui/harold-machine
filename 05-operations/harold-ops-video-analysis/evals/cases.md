# 短视频数据诊断 · 验收用例

四条用例覆盖：正常单条诊断、多条对比、边界（截图模糊 / 小样本 / 跨窗口）、长视频时长误诊。

---

## Case 1 单条诊断：完播低

**输入**："这条 28 秒，播放 8000，完播 12%，点赞 90，评论 6，分享 3，收藏 12，涨粉 5，帮我看看问题在哪。"

**期望**

- 先确认口径：账号粉丝量级、时间窗口、完播率取自哪个字段（后台 / 3 秒 / 5 秒 / 平均时长反算）。缺项标"假设"。
- 算出互动率 1.39%、粉丝转化率 0.06%、评论率 0.075%、分享率 0.038%，写明分子分母；主页转化率因无主页访问量标 N/A。
- 评级对照基准，并注明"经验基准、非平台官方口径"；28 秒落在 16–30 秒档，完播 12% 低于该档及格线，评级结论需带时长档。
- 决策树命中第一条（该时长档完播低于及格线）即停，结论落在"开头钩子"，不再顺带把分享率、人设都列成问题。
- 改进动作是当天能做的：改前 3 秒开头方式、重剪一版对比。

**不通过**：只复述数字不给结论；或把五个环节全列成问题；或直接说"内容质量需要提升"。

---

## Case 2 多条对比

**输入**："五条视频的后台截图，帮我排一下哪条最好、哪条该复刻。"

**期望**

- 逐条建表，先对完播率 / 互动率 / 转粉率做同批归一化，再按归一化后加权（40% + 40% + 20%）排序，标出 Top 1–2 与 Bottom 1–2。
- 对比头部与尾部的差异特征：选题、开头、时长、发布时间，指出可复用的具体做法。
- 指出尾部的第一个失效环节，而不是罗列所有短板。
- 单独列"保持不变的优势"。

**不通过**：只按播放量排序；或没有差异特征对比。

---

## Case 3 边界：模糊、小样本、跨窗口

**输入**：截图模糊（数字像 1K 又像 1W），播放量 320，一条是发布 3 天数据、另一条是 30 天数据，要求"对比一下并给改进建议"。

**期望**

- 模糊字段标"识别失败"并请用户确认，不按猜测填数。
- 播放 320 时明确说明样本不足、结论仅供参考，比例指标给 Wilson 95% 区间，区间重叠不下优劣结论；建议积累到 1000+ 再复盘。
- 说明两条视频窗口不一致、不能直接横向比，先对齐窗口或只做单条诊断。
- 建议仍给，但只给方向性动作（如先统一统计窗口、再比开头方式）。

**不通过**：把猜测值写进表格；或在样本不足时给出确定性结论；或不对齐窗口就直接排名。

---

## Case 4 长视频：完播 14% 不等于开头差

**输入**："这条 90 秒，播放 2.3 万，完播 14%，互动率 2.6%，分享率 0.4%，是不是开头没做好？"

**期望**

- 先做时长换算：90 秒属 >60 秒档，14% 在该档不能直接套 ≤30 秒的 15% 及格线，不能一见 14% 就判"开头钩子"。
- 要求或使用 3 秒 / 5 秒完播来分归因：3 秒掉得狠才是钩子问题，3 秒稳、中段掉是节奏或价值密度问题；无该字段时标"无"，改用同档历史中位数比较。
- 若账号无同档历史数据，只做同档内视频之间的比较，并在输出里写明"未做时长修正"。
- 互动率 2.6% 在基准内，应放进"保持不变的优势"，而不是一并改掉。

**不通过**：直接按"完播 <15% = 开头钩子"下结论；或忽略时长档、把 90 秒和 20 秒视频放同一张表比。

## 评分表

**阻塞项：任一为 0，不得交付。**

- [ ] B1 不猜数：截图中缺失或模糊的字段标"无 / 识别失败"并告知用户，不把 1K 与 1W 这类数字按猜测填进表里
- [ ] B2 每个评级有基准：所有评级都对照基准表给出，并注明"经验基准、非平台官方口径"、账号量级前提、完播率口径与时长档；未做时长修正时写明
- [ ] B3 结论指到环节：诊断结论落在具体环节（开头 / 价值感 / 人设 / 传播 / 分发），不是"内容不够好"

**计分项：**

- [ ] 1 派生指标齐全：有输入的派生指标全部算完并写了分子分母；缺输入的标 N/A，不硬算
- [ ] 2 问题只有一个主因：按决策树命中第一个即停，没有把所有环节都列成问题
- [ ] 3 改进动作可执行：每步是能当天做的事，不是"提升内容质量"
- [ ] 4 保留优势：列出仍有效的指标与对应策略
- [ ] 5 样本校验：播放量 <1000、完播率 >80% 或时长 <15 秒时，明确说明数据不代表内容质量；播放量 <1000 时比例指标给 Wilson 95% 区间，区间重叠不下优劣结论
- [ ] 6 环比同窗口：两期对比时窗口一致；不一致就说明不可直接比（无对比数据标 N/A）

判定：阻塞任一为 0 = 重做；阻塞全过 + 计分 ≥⌈0.8×N⌉（N 为计分项数，N/A 不计入分母；满项 N=6，阈值 5；1 项 N/A 时 N=5，阈值 4；2 项 N/A 时 N=4，阈值 4）= 可交付；计分 ≤阈值-1 = 重写。
