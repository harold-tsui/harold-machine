# Video Analysis · 短视频数据诊断

> 一句话：先用数据定位到第一个出问题的环节，再谈改什么。

## 核心定位

- 适用：单条视频表现诊断、多条视频横向对比、周与周环比、账号阶段性复盘。
- 平台口径：微信视频号为主；抖音、小红书等指标口径接近，但基准值要重设。
- 不适用：内容创作（用 `harold-production-copy`）、投放预算决策、账号定位规划。
- 默认交付：结论在前，改进项按影响力排序，不写泛泛的"要多互动"。

## 触发场景

- "帮我分析一下这条视频的数据"
- "我的完播率很低，帮我找原因"
- "这几条视频哪条表现最好"
- "这周和上周对比一下"

## 工作流

### Step 0 确认口径

四件事：平台与账号粉丝量级（决定用哪套基准）、时间窗口（单条 / 周 / 月）、是否为同一窗口对比、完播率取的是哪个口径。缺项标"假设"，一次只问一个。

完播率四选一，选定后写进输出：平台后台"完播率"字段（各平台定义不同，如抖音为最后一帧观看完成次数 / 播放次数）｜3 秒完播（停留率）｜5 秒完播率｜用平均播放时长 ÷ 视频时长 反算。同一份分析里所有评级必须用同一口径；换平台就重设基准，不沿用旧表。

### Step 1 提取字段

逐项识别，截图中没有的写"无"，看不清的写"识别失败"，不猜。

| 字段 | 单位 | 说明 |
|---|---|---|
| 播放量 | 次 | 视频总播放次数；注意平台是否含重播 |
| 完播率 | % | 必须写明来源：后台字段 / 3 秒 / 5 秒 / 平均时长反算 |
| 3 秒完播（停留率） | % | 平台有就记；没有写"无"，不硬算 |
| 5 秒完播率 | % | 同上 |
| 平均播放时长 | 秒 | 反推实际完播情况 |
| 视频时长 | 秒 | 决定完播率落在哪个时长档 |
| 点赞 / 评论 / 分享 / 收藏 | 个 | 四项分开记 |
| 涨粉数 | 人 | 该视频带来的新关注 |
| 主页访问量 | 次 | 从视频进入主页的次数 |

多条视频逐条建档，列成表格再算。

### Step 2 算派生指标

有原始数据就必须算，并写明分子分母；缺输入的指标标 N/A，不硬算：

- 互动率 =（点赞 + 评论 + 分享 + 收藏）/ 播放量
- 粉丝转化率 = 涨粉数 / 播放量
- 评论率 = 评论数 / 播放量
- 分享率 = 分享数 / 播放量
- 主页转化率 = 主页访问量 / 播放量

### Step 3 对标基准

先按粉丝量级选基准表，再做时长档修正，最后看指标落档。

完播率是时长的函数：15 秒以内天然偏高、60 秒以上天然偏低，跨时长直接套同一张表会误判。

**基准 A：粉丝 <1 万**

| 指标 | 及格 | 良好 | 优秀 |
|---|---|---|---|
| 完播率 | >15% | >25% | >35% |
| 互动率 | >1% | >3% | >5% |
| 粉丝转化率 | >0.1% | >0.5% | >1% |
| 评论率 | >0.1% | >0.3% | >0.5% |
| 分享率 | >0.1% | >0.5% | >1% |
| 主页转化率 | >0.5% | >1.5% | >3% |

**基准 B：粉丝 ≥1 万**

| 指标 | 及格 | 良好 | 优秀 |
|---|---|---|---|
| 完播率 | >10% | >20% | >30% |
| 互动率 | >0.7% | >2% | >4% |
| 粉丝转化率 | >0.05% | >0.2% | >0.5% |
| 评论率 | >0.05% | >0.2% | >0.4% |
| 分享率 | >0.05% | >0.3% | >0.7% |
| 主页转化率 | >0.3% | >1% | >2% |

四条口径必须同时说明，否则评级会误导：

1. 两套都是**经验基准，不是平台官方口径**；粉丝越多各指标基准通常越低，量级处于两档之间时取更接近的一档，并在输出里写明所用档位。
2. 垂直行业（教育、财经、医疗）互动天然偏低，互动率 0.5%–1.5% 属正常，需按行业下调。
3. 播放量 <1000 的样本波动大：比例指标给 Wilson 95% 区间，区间重叠即判"不可区分"，不做排序或优劣结论；评级仅供参考。
4. 完播率要做时长档修正，按 ≤15 秒 / 16–30 秒 / 31–60 秒 / >60 秒 分开比。优先用账号自身历史同档中位数作参照；没有历史就只做同档内视频之间的比较，并在输出里写明"未做时长修正"。

**多条视频排序**：先对三项指标做 min-max 归一化（在**同一批视频内**把每项拉到 0–1），再加权：`综合得分 = 归一化完播率 × 40% + 归一化互动率 × 40% + 归一化粉丝转化率 × 20%`。直接拿原始百分比相加会量纲失衡（完播 12 与转粉 0.06 不同量级），排序会退化成按完播率。归一化结果只在本批内有效，不跨批比较。标出 Top 1–2 与 Bottom 1–2，并对比两端的差异特征（选题、开头、时长、发布时间）。

### Step 4 诊断：命中第一个就停

按顺序判断，命中即停，不要把所有问题都列一遍——同一份数据里，后面的问题往往是前一个的结果。

判断前先做时长换算：完播率只与同档（≤15 / 16–30 / 31–60 / >60 秒）的视频比，长视频的 15% 可能已是良好，不能直接套下面前两条。

1. 完播率低于本时长档及格线（≤30 秒的视频即 <15%）→ **开头钩子**。有 3 秒 / 5 秒完播就用来分归因：3 秒掉得最狠是钩子问题，3 秒稳、之后才掉是节奏问题。查第一帧有没有视觉吸引。改法：问题式开头，或结果前置。
2. 完播率在及格与良好之间（≤30 秒时即 15%–25%）且互动率 <1% → **价值感或行动号召**。查结尾有没有明确的点赞 / 评论引导，内容有没有留下"想说点什么"的入口。改法：结尾给具体问题，中段放一个有立场的观点。
3. 互动率 >3% 但粉丝转化率 <0.1% → **人设不清**。观众喜欢这条，但不知道关注你能持续得到什么。改法：视频内说清"关注我看什么"，同步修主页简介。
4. 分享率 <0.1% → **传播属性弱**。查内容有没有"值得转给朋友"的实用性或情绪共鸣。改法：做工具型内容（模板 / 清单 / 公式），加"转给需要的人"话术。
5. 播放量 <1000 且其余指标正常 → **分发问题，不是内容问题**。查发布时间（高峰 7–9 点 / 12–13 点 / 20–22 点）、封面文字大小与主题辨识度。改法：换时段、A/B 封面。
6. 以上五条都不命中（各指标均在及格线上、无明显单点失效）→ **无明显短板**。不出改进项，只在「保持不变的优势」里写明哪几项达标，避免为了改而改。

### Step 5 出建议

每条建议三件套：具体问题（带数据）、根本原因（诊断结论）、可立即执行的动作（1–2 步）。同时单列"保持不变的优势"，避免把有效做法一起改掉。

时长档：≤15 / 16–30 / 31–60 / >60 秒｜数据来源：截图 / 粘贴｜缺失或识别失败字段：……

## 数据概览

| 指标 | 数值 | 公式（分子 / 分母） | 基准 | 评级 |

## 验收标准

**阻塞项：任一为 0，不得交付。**

- [ ] B1 不猜数：截图中缺失或模糊的字段标"无 / 识别失败"并告知用户，不把 1K 与 1W 这类数字按猜测填进表里
- [ ] B2 每个评级有基准：所有评级都对照基准表给出，并注明"经验基准、非平台官方口径"、账号量级前提、完播率口径与时长档；未做时长修正时写明
- [ ] B3 结论指到环节：诊断结论落在具体环节（开头 / 价值感 / 人设 / 传播 / 分发），不是"内容不够好"

**计分项：**

- [ ] 1 派生指标齐全：有输入的派生指标全部算完并写了分子分母；缺输入的标 N/A，不硬算
- [ ] 2 问题只有一个主因：按决策树命中第一个即停，没有把所有环节都列成问题
- [ ] 3 改进动作可执行：每步是能当天做的事，不是"提升内容质量"
- [ ] 4 保留优势：列出仍有效的指标与对应策略
- [ ] 5 样本校验：播放量 <1000、完播率 >80% 或时长 <15 秒时，明确说明数据不代表内容质量；播放量 <1000 时比例指标给 Wilson 95% 区间，区间重叠不下优劣结论
- [ ] 6 环比同窗口：两期对比时窗口一致；不一致就说明不可直接比（无对比数据标 N/A）

判定：阻塞任一为 0 = 重做；阻塞全过 + 计分 ≥⌈0.8×N⌉（N 为计分项数，N/A 不计入分母；满项 N=6，阈值 5；1 项 N/A 时 N=5，阈值 4；2 项 N/A 时 N=4，阈值 4）= 可交付；计分 ≤阈值-1 = 重写。

## Gotchas

1. **截图数字靠猜**
   1K 与 1W 猜错，整份分析的结论都会反过来。看不清就问，不硬填。

2. **完播率高就夸内容好**
   15 秒以内的视频完播率天然高，这不代表内容质量。先看时长再看完播率。

3. **把所有问题都列一遍**
   五个环节全写成问题，用户不知道先改哪个。命中第一个就停，改完再看下一个。

4. **拿经验基准当平台标准**
   这些数字来自实操沉淀，不同类目、不同时期差别很大。必须写明口径，并允许用户用自己历史数据替换。

5. **小样本硬做结论**
   播放量 <1000 时指标波动极大，只做方向性提示，不给确定性结论。

6. **跨窗口直接比**
   一条视频是发布 3 天数据、另一条是 30 天数据，横向对比没有意义。先对齐窗口。

7. **不同平台或不同口径混着比**
   视频号的"完播率"和抖音的"最后一帧完成率"分母不同，3 秒完播和整体完播更不是一回事。换平台先重设基准，换口径先重算，不能把两个数放进同一张对比表。
