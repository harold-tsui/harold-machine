# Finance Ops · 知识付费财务核算

> 一句话：先把口径对齐（净收入不是流水），再算指标，最后拿行业基准做诊断。

## 核心定位

- 适用：知识付费、在线教育、内容付费业务的月度 / 季度核算；CAC、LTV、毛利率、渠道 ROI 与简易 P&L；投不投、扩不扩的量级判断。
- 前置：有本期收入与成本数据，至少能拆到"毛收款 / 退款 / 投放费用 / 新增付费用户数"。
- 不适用：投资组合与资产配置、审计与税务申报、上市公司财报分析、股权与估值。
- 基准是经验值，不是会计准则；对外使用（投资人、合伙人）前，口径需由财务确认。

## 触发场景

- "帮我看下这个月账"
- "我的获客成本合理吗"
- "这几个投放渠道哪个划算"
- "LTV 怎么算，现在能不能加大投放"
- "给合伙人 / 投资人出一份经营财务"

## 工作流

### Step 0 口径确认（先做这一步）

三组，一次问清；缺项按"假设"标注继续，不静默跳过。

1. **业务形态**：录播为主 / 直播为主 / 1v1 辅导 / 混合。决定毛利率基准取哪一档。
2. **核算周期**：自然月 / 季度 / 自定义；是否与平台账期一致。
3. **口径四项确认**：毛收款是否包含退款中的订单；是否含未授课预收（默认只取本期已履约部分，未授课部分记合同负债）；分销佣金记在收入端还是成本端（默认成本端，计入 CAC）；一次性内容制作费是否摊销（默认 12–24 个月）。

### Step 1 数据收集

按三张表要数，缺必填项就停，给出缺项清单与影响。

| 表 | 必填 | 选填 |
|---|---|---|
| 收入端 | 毛收款、退款、平台手续费（按实际签约费率：微信支付 0.38%–0.6%，教育类常见 0.6%，小微有 9 折；不得默认 0.6%） | 分销佣金支出、预收款余额 |
| 成本端 | 广告投放（按渠道分列）、讲师课酬 / 内容制作、运营人力 | 工具订阅、管理费用（用于完整 P&L） |
| 用户端 | 本期新增付费用户数（首次完成正价付费，已扣退款；不含 1 元体验课 / 0 元引流课）、平均客单价 | 复购用户数、历史购买次数、退款率 |

不做的事（三件）：不得假设退款率；不得用行业均值反推新增用户数或 CAC；不得用行业均值补内容成本。缺就是缺，写进缺口清单，并标注影响哪个指标。

### Step 2 口径清洗六检

计算前逐条过，有问题先修口径再算。

1. **毛收款含退款**：净收入 = 毛收款 − 退款 − 平台手续费。
2. **毛收款只算已履约**：毛收款取本期已授课 / 已交付部分；一次性收多期的预收款不进本期收入，按月确认，未确认部分记合同负债。
3. **佣金两头扣**：分销佣金计入 CAC 后，收入端不再扣，否则双重计算。
4. **制作费是否可复用**：录播等可复用内容按 12–24 个月摊销；直播、活动性内容当期全额。
5. **人力跨业务线**：多产品线共用团队，按收入占比分摊。
6. **投放与转化跨期**：费用按付款时间对齐，明显跨期要在报告里说明。

### Step 3 指标计算

```text
净收入 = 毛收款 − 退款 − 平台手续费        净收入率 = 净收入 / 毛收款
毛利润 = 净收入 − 内容 / 交付成本          毛利率   = 毛利润 / 净收入

总获客费用 = 广告投放 + KOL 合作费 + 分销佣金
CAC = 总获客费用 / 本期新增付费用户数       渠道 CAC = 渠道费用 / 渠道新增付费用户数

LTV（历史）  = 客单价 × 平均购买次数 × 毛利率
LTV（复购率）= 客单价 × 1/(1 − 复购率) × 毛利率   （复购率须来自本期或历史数据）
LTV（简化）  = 客单价 × 毛利率                     （下限；无复购数据时只能用这个）
LTV:CAC = LTV / CAC                        回收期（月）= CAC / (客单价 × 毛利率)
渠道 ROI  = (渠道净收入 − 渠道内容成本 − 渠道费用) / 渠道费用
渠道 ROAS = 渠道毛收款 / 渠道广告费               （只看投放效率，不用于扩张 / 缩减判断）
```

LTV（复购率）里的期望购买次数 = 1/(1 − 复购率)；复购率没有数据就不得估算，改用简化法并标"下限"。

CAC 分母只算本期新增正价付费用户：已扣退款，不含 1 元体验课 / 0 元引流课；若分母含体验课，须单列并标"口径不同，不可与正价 CAC 比较"。

渠道费用含该渠道的广告、KOL 合作费与分销佣金；ROAS 分母只含广告费。渠道净收入 = 渠道毛收款 − 渠道退款 − 渠道平台手续费；渠道内容成本按该渠道直接归属，共用内容按收入占比分摊（见 Step 2 第 5 条）。

基准（经验值，仅适用于月收入 > 50 万的成熟期业务；早期业务数据量小，只作参考不作评级）：

| 指标 | 基准 |
|---|---|
| 毛利率 | 录播 60–80% / 直播 40–65% / 1v1 20–45%（成本口径含讲师课酬与内容制作，不含推广与运营；公开样本常报 70–90%，多因未计讲师成本，对比前先对齐口径） |
| LTV:CAC | ≥5 良好可加投；≥3 合格；<2 警戒；<1 危险 |
| CAC 回收期 | ≤3 个月优秀；4–6 个月监控；>6 个月不扩张（按单次课程毛利回收，非订阅摊销；SaaS 的 12 个月口径不适用） |
| 复购率 | 私域强 30–50%；纯广告流量 10–20% |

### Step 4 P&L 与对比

P&L 固定十一行：毛收款 → 退款 → 手续费 → 净收入 → 内容成本 → 毛利 → 推广费 → 运营费 → 经营利润 → 管理费 → 净利润。

出表前过勾稽五检：净收入 = 毛收款 − 退款 − 手续费；毛利 = 净收入 − 内容成本；经营利润 = 毛利 − 推广 − 运营；净利润 = 经营利润 − 管理费；各渠道拆解合计与总盘一致，不一致要写出差异项与金额。

有上期就给环比（净收入、毛利率、CAC、LTV:CAC、各渠道 ROI），重点标毛利率下降、CAC 上升、单渠道 ROI 突变。有目标就给达成率，>110% 与 <90% 单独标。

### Step 5 渠道建议与自检

| 建议 | 条件 |
|---|---|
| 扩张 | 渠道 ROI > 3，且该渠道用户复购率不低于整体均值 |
| 缩减 | 渠道 ROI < 1.5，或 CAC 回收期 > 6 个月 |
| 持观察 | 该渠道本期新增用户 < 50 人，先不判 |

阈值作用于「渠道 ROI」（利润口径）；ROAS 只作投放侧参考，不单独用于扩张或缩减判断。

交付前自检：口径写了吗；缺失与估算标了吗；每个评级引了基准吗；样本不足的地方写了"不足以判断"吗。

## 验收标准

**阻塞项：任一为 0，不得交付。**

- [ ] B1 口径先行：净收入已扣退款与平台手续费（手续费按实际签约费率，未默认 0.6%）；分销佣金只计一次（计入 CAC 后收入端不再扣）；未授课的预收款未计为收入
- [ ] B2 不编数：缺失项写"未提供"；估算值标"估算"并写明假设；无历史数据时不套用历史复购率
- [ ] B3 评级有条件：每个评级都引用基准并注明适用条件（成熟期、样本量）；样本不足处写"不足以判断"

**计分项：**

- [ ] 1 毛利率取对基准：按录播 60–80% / 直播 40–65% / 1v1 20–45% 对应业务形态，未混用；基准按「含讲师课酬与内容制作」口径取，公开样本未计讲师时已说明不可直接对比
- [ ] 2 CAC 无漏项：含分销佣金与 KOL 费用，且能按渠道分列；分母只含本期新增正价付费用户（已扣退款、不含体验课 / 引流课），含体验课时已单列并标注口径
- [ ] 3 LTV 有方法：注明所用方法（历史 / 复购率 / 简化）与假设；复购率无数据时未估算
- [ ] 4 P&L 十一行完整：毛收款 → 退款 → 手续费 → 净收入 → 内容成本 → 毛利 → 推广 → 运营 → 经营利润 → 管理 → 净利润；表内勾稽通过（净收入 = 毛收款 − 退款 − 手续费；毛利 = 净收入 − 内容成本；经营利润 = 毛利 − 推广 − 运营；净利润 = 经营利润 − 管理费），渠道合计与总盘不一致时已写出差异项与金额
- [ ] 5 渠道有阈值：扩张 ROI > 3 且质量达标；缩减 ROI < 1.5 或回收期 > 6 个月；新增 < 50 人持观察
- [ ] 6 缺口单列：缺什么、影响哪个指标、补什么可复算

判定：阻塞任一为 0 = 重做；阻塞全过 + 计分 ≥⌈0.8×N⌉（N 为计分项数，N/A 不计入分母；满项 N=6，阈值 5；1 项 N/A 时 N=5，阈值 4；2 项 N/A 时 N=4，阈值 4）= 可交付；计分 ≤阈值-1 = 重写。

## Gotchas

1. **拿平台流水当收入**
   后台显示的"销售额"通常是毛收款，含退款与手续费前金额。直接当净收入算，利润会被系统性高估。

2. **分销佣金扣两次**
   收入端扣一次、CAC 里再算一次，CAC 虚高、净收入虚低。默认记在成本端，并在口径里写明。

3. **一次性录制费全进当月**
   录一套课花 10 万记成当月费用，当月必然巨亏、次月虚高。可复用内容按 12–24 个月摊销。

4. **预收款当收入**
   报名费收进来但课没讲完，会计上是预收账款。按月确认收入，否则月份之间不可比。

5. **新业务套历史复购率**
   成立不足一年，复购数据不足。只用简化 LTV，并说明这是下限估算。

6. **多产品线合并算 LTV 与 CAC**
   私域用户 LTV 常是广告流量的 2–3 倍，合并后互相掩盖。至少按主要产品线分开。

7. **早期业务硬套成熟期基准**
   月收入不到 50 万时，CAC 月度波动很大。可以对照，但不据此下"危险"结论。

8. **1 元体验课混进客单价**
   引流课的 0–1 元订单不进正常客单价，否则 LTV 严重偏低。

9. **1 元体验课混进 CAC 分母**
   把体验课用户计入新增付费人数，分母虚大、CAC 虚低，渠道会被误判为"可以加投"。分母只算正价付费用户。

10. **表加总对不上**
   十一行各写各的，净收入减不出毛利、渠道合计不等于总盘。财务表先过勾稽五检，再谈评级。
