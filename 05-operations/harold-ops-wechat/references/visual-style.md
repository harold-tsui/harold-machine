# 配图规格与风格模板

## 1. 规格

| 用途 | 比例 | 像素 | 数量 |
|---|---|---|---|
| 长文头图 | 2.35:1 | 1504×640 | 1 张 |
| 长文正文图 | 16:9 | 1344×756 | 3–4 张 |
| 贴图单页 | 3:4 | 1080×1440 | 按内容深度 |
| 贴图封面 | 3:4 | 1080×1440 | 1 张，必须叫 `01-cover.png` |

贴图比例必须是 3:4：朋友圈按 3:4 完整呈现，用 16:9 会被裁掉上下两条，封面信息直接丢。

头图虽然是 2.35:1，但在历史消息列表和分享预览里会按中间约 1:1 裁剪，左右两侧被切掉。标题、人脸、主体一律放中间安全区，两侧只放可裁背景；不要把关键信息贴在边缘。

## 2. 使用规则

1. 先选风格，再出图；进入配图阶段先给 2–4 个模板让用户定，不默认直接生成。
2. 一篇只用一套主风格，封面与正文图同一视觉系统。
3. 模板可微调主体与关键词，但色彩、质感、字体、构图语言保持一致。
4. 生成结果必须落地本地，不依赖临时链接（多数接口的 URL 24 小时失效）。
5. 用户认可某次效果后，把命名与骨架回写到本文件，形成可复用模板。

## 3. 封面规则

- 背景只生成无文字图，标题、副标、页码、署名用 HTML/CSS 叠字。
- 生图模型写中文常出错字；中文一律不用模型生成。
- 叠字后先出 `design-sources/cover-for-review.png` 给用户审核，通过后再放进 `assets/01-cover.png`。
- 封面是朋友圈缩略图，当海报做：大标题 + 强对比 + 单一视觉支点。
- 生图通道不可用时，改用纯 HTML/CSS 渲染封面再截图，中文零错字、成本为零。

## 4. 提示词骨架

```text
[风格模板的统一描述]，
3:4 竖图 / 2.35:1 横图，
公众号配图，
主体居中且占画面 60%，
无文字、无 Logo、无水印，
[封面主体描述]，
统一视觉系统，
不要拥挤，不要模板感。
```

可调项只有「比例」和「主体描述」；风格描述整段照抄，避免每张图跑偏。

## 5. 模板 01：黑金数据流

**状态**：已验证
**适用**：商业、经济、科技、AI、宏观趋势、产业分析、深度洞察
**不适用**：温情故事、生活方式、轻松教程、家庭主题

- **色彩**：石墨黑、深海军蓝、暗灰打底；暖金 / 琥珀金做强调；深红只用于风险提示。禁廉价大红大紫、浅色软萌、花哨渐变。
- **构图**：封面 2.35:1 强中心；正文图 16:9 主体清晰，留中文标题区。可用数据曲线、发光节点、金融网格、城市剪影、人物背影、芯片、账本。
- **字体**：现代中文黑体，硬朗；不用手写体、毛笔字、卡通字体。
- **骨架**：黑金数据流风格，高冲击力中文深度文章配图，深色高级财经杂志感，石墨黑与深海军蓝背景，暖金色数据流与抽象信息网络，电影级光影，克制、锋利、可信，现代中文黑体标题，中文清晰可读，少量信息图元素，画面主体明确，统一视觉系统，不要卡通，不要廉价商业海报，不要花哨渐变。

## 6. 模板 02：胡桃木黄昏

**状态**：草稿
**适用**：家庭关系、代际、婚姻、生育与家务分工、原生家庭
**不适用**：商业财经、AI 科技、人物特稿、励志鸡汤、母婴软萌

- **色彩**：深胡桃木棕、暖灰、米白、奶油杏为主；低饱和墨绿或暗砖红二选一；极少量铁锈红做冲突隐喻。禁粉色系、马卡龙、亮黄、卡通高饱和。
- **构图**：封面 2.35:1 弱中心，主体偏一侧，留 40% 以上负空间给标题；用静物或局部（手、背影、桌上筷子、未叠的衣服、空椅子）避开正面人脸。正文图单一场景、浅景深、焦点落在一个物件（碗、账单、相框、儿童画）。
- **光线**：单一方向黄昏侧光或单灯，暗部保留。
- **字体**：现代衬线中文或克制细黑体，最多 1 主标题 + 1 副标题。
- **骨架**：胡桃木黄昏风格，中文家庭情感深度文章配图，克制的人间烟火与冷静的家庭观察，室内特辑质感与暖调侧光，深胡桃木棕、暖灰、米白与奶油杏为主，低饱和墨绿或暗砖红点缀，单一光源，景深浅，焦点在具体家庭物件或人物局部，避免正面人脸，画面安静但有张力，现代中文衬线标题，中文清晰可读，留大块负空间给标题，不要粉色系，不要马卡龙，不要卡通，不要团圆笑脸，不要红双喜。

## 7. 模板 03：档案馆铅灰

**状态**：草稿
**适用**：人物特稿、企业家史诗、历史复盘、商业败局、思想家解读
**不适用**：家庭情感、AI 教程、生活方式、轻量资讯

- **色彩**：铅灰、墨黑、档案纸米白、烟褐；单一暗酒红或深普鲁士蓝点睛，一篇定一色。禁金色、彩虹渐变、霓虹。
- **构图**：封面 2.35:1 强中心人物半身 / 侧脸 / 剪影，硬侧光切一半，背景极简或叠旧纸纹理。正文图 4:5 或 3:4 竖构图，单人或单物；不出现现代 logo、不出现可识别真人脸。
- **字体**：粗衬线主标题（4–10 字最佳），细等线做副标；可加年份或「档案 No.07」小字。
- **骨架**：档案馆铅灰风格，中文人物特稿与历史哲思配图，杂志封面硬调摄影质感，铅灰、墨黑、档案纸米白与烟褐为主，单一暗酒红或深普鲁士蓝点睛，单光源伦勃朗布光，半身 / 侧脸 / 剪影或关键档案物件，背景极简或叠加轻微旧纸、网点、印刷纤维质感，庄重、克制、有时间厚度，现代中文粗衬线主标题搭配细等线副标题，中文清晰可读，可加档案编号或年份小字，不要金色，不要彩虹渐变，不要霓虹，不要卡通，不要现代 logo，不要清晰可识别的真人脸。

## 8. 选型提示

- 三个模板之间犹豫时，优先档案馆铅灰：黑白 + 单色，在朋友圈缩略图里最抢眼。
- 贴图的传播力更依赖封面，选模板时偏向对比度高、单色点睛、字大的方向。
- 正文卡片用 HTML/CSS 渲染，中文字体可控、改一处全组同步，不消耗生图额度。

## 9. 新增模板的最低要求

新增模板至少写清：模板名、适用与不适用、色彩、构图、字体、提示词骨架、已验证样例目录。没经过一次真实发布检验的，标「草稿」，不要标「已验证」。
