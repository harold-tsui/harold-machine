# XHS Publish · 小红书图文发布

> 一句话：先把内容校到平台规则之内，回显给用户确认，再点发布。

## 核心定位

- 适用：小红书图文笔记的发布执行；立即发布与定时发布；批量任务中的单条节点。
- 前置：内容已定稿。本技能只做校验、排版、发布与核验，不重写内容。
- 不适用：视频笔记、合集与专栏配置、投流（薯条）、账号运营策略（用 `harold-ops-video-analysis` 做数据侧）。
- 平台规则会变：步骤中的页面元素与阈值以当前页面为准，找不到就停下问，不盲点。

## 触发场景

- "帮我发到小红书"
- "标题 + 正文 + 这几张图，发一条"
- "定时明天上午 9 点发"
- "这条先存草稿 / 立即发"

## 工作流

### Step 0 接料与分档

收集五项：标题、正文、图片路径（有序）、话题（可留空由你生成）、时间（立即 / 定时 / 存草稿）。

分档三选一：**立即发布**、**定时发布**、**存草稿**。缺项一次只问一个，其余标"假设"。

### Step 1 四项校验

| 项 | 规则 | 不通过时 |
|---|---|---|
| 标题 | ≤20 字（含标点与 emoji）；无 http / www 外链；无手机号、微信号、QQ | 超长截到 17 字 + "..." 并告知；含外链或联系方式直接退回，不擅自删改语义 |
| 图片 | 1–18 张；JPG / PNG / WEBP（GIF 不接受）；单张 ≤20MB；逐张看内容：无二维码、无第三方平台水印、图中无微信号 / 手机号 / 网址 | 列出问题文件、序号与问题位置，中止，等用户换图或裁剪 |
| 正文 | 无外链；无导流话术（私信加我 / 评论区扣 1 / 领资料 / 扫码 / 主页看简介 / 引导站外交易）；提及竞品平台（抖音 / B站 / 微博等）标风险；建议 ≤1000 字 | 超长提示压缩；导流话术与竞品名请用户确认改法或删除，不擅自改语义 |
| 敏感词 | 医疗承诺（根治 / 特效 / 100% 有效）、金融收益（稳赚 / 保本）、绝对化（最 / 第一 / 唯一）、化妆品功效宣称（美白 / 祛斑 / 防脱 / 抗敏等需特证）、保健食品功效、虚假承诺（N 天瘦 X 斤 / X 天见效）、封建迷信、未成年人相关 | 高亮列出，给替换建议，等用户选"替换 / 继续" |

### Step 2 生成话题

正文与标签都由用户提供时直接用，不强制凑到 3–5 个。需要生成时：3–5 个，每个 `#` 开头、2–10 字、不含空格；优先"行业词 > 细分词 > 品牌词"；追加到正文末尾，换行分隔。

### Step 3 发布前确认（不可逆闸门）

把下面各项一次性回显，等用户明确确认后再操作浏览器：

```text
即将发布（<立即 / 定时 YYYY-MM-DD HH:mm>）
- 发到账号：<账号名>
- 标题：<最终标题>（<字数> 字）
- 正文：<最终正文，含话题>
- 话题：<#标签列表>
- 图片：<N> 张，顺序 <文件名列表>
- 商业推广：<否 / 是，已报备 / 未报备>
```

用户没确认就不点发布。发布与定时都是不可逆动作。

### Step 4 执行

1. 打开创作平台发布页，先确认右上角是目标账号。
2. 若跳转登录页 → 停下来请用户手动扫码，**不代填账号密码**。
3. 选"图文笔记"，按顺序逐张上传，等每张进度结束；上传后核对缩略图数量。
4. 填标题 → 填正文（含话题）→ 若平台有独立话题框再补一次。
5. 定时发布先查资格：需实名认证，且粉丝 ≥100 或近 30 天发布 ≥3 篇合规笔记；没有定时入口就停下，问用户改立即发还是转人工。定时时间须落在当前时间 +2 小时至 +14 天之间；审核通常 10 分钟–2 小时，+2 小时只是下限，能提前就提前 2–3 小时；不足 +2 小时调整到 +2.5 小时，超过 14 天改为最近可选的合法时间，均告知调整结果。
6. 内容为原创且页面提供入口时勾选原创声明；品牌合作 / 软广须已走蒲公英报备，未报备先告知限流风险，由用户决定。
7. 点发布，等成功提示或跳转内容管理页。

存草稿分支：填完标题、正文、图片后点「存草稿」，回草稿箱核对标题与图片张数，记录草稿位置；不点发布，也不走确认闸门。

### Step 5 核验与交付

以内容管理页最新一条的标题与 note_id 为准，不只信弹窗。状态"审核中"是正常的（通常几分钟到 1 小时；进入人工复核可至 48 小时或更久），写进结果里，不算失败。

失败时给三样：失败步骤、可执行的手动回退指引、可直接复制的标题与正文。

## 输出格式

**成功**

```text
发布成功
- 账号：<账号名>
- 标题：<实际发布的标题>
- 笔记链接：<App 分享的 xhslink 短链；拿不到时给 https://www.xiaohongshu.com/explore/<note_id>?xsec_token=<token>>
- 发布时间：<时间>｜状态：<已发布 / 审核中>
- 话题：<#标签>
- 图片：<N> 张
```

**失败**

```text
发布失败
- 失败原因：<具体原因>
- 失败步骤：<第几步>
- 手动回退：
  1. 打开 <发布页地址>
  2. <具体操作>
- 可直接复制：
  标题：<标题>
  正文：<正文 + 话题>
```

## 验收标准

**阻塞项：任一为 0，不得发布。**

- [ ] B1 内容在规则内：标题 ≤20 字且无外链与联系方式；正文无外链、无导流话术；图片无二维码 / 第三方水印 / 图中联系方式；竞品平台名与敏感词已标出并取得用户选择
- [ ] B2 不可逆前有确认：发布 / 定时前回显账号、标题、正文、话题、图片顺序、时间与商业推广报备状态，并取得明确确认；登录失效只提示扫码，不代填凭证
- [ ] B3 结果有核验：成功给出 note_id 或内容管理页核对记录；失败给出失败步骤、回退指引与可复制内容

**计分项：**

- [ ] 1 图片校验完整：数量 1–18、格式 JPG/PNG/WEBP、单张 ≤20MB，问题文件列到序号；已逐张检查图内无二维码 / 水印 / 联系方式
- [ ] 2 话题合规：AI 生成时为 3–5 个、2–10 字、无空格，按 行业 > 细分 > 品牌 排序；用户自备话题按原样保留，不按条数与字数判
- [ ] 3 定时合法：先确认账号具备定时资格（实名 + 粉丝 ≥100 或近 30 天 ≥3 篇合规笔记），时间落在当前 +2 小时至 +14 天之间，并提示审核 10 分钟–2 小时、建议提前 2–3 小时；不合法时调整并告知调整结果
- [ ] 4 状态口径正确："审核中"写为正常状态并注明预计时长，未当作失败
- [ ] 5 上传保序：图片顺序与用户给定一致，上传后核对数量
- [ ] 6 改版可降级：元素找不到时截图描述当前页面并请用户指引，不盲目点击

判定：阻塞任一为 0 = 重做；阻塞全过 + 计分 ≥⌈0.8×N⌉（N 为计分项数，N/A 不计入分母；满项 N=6，阈值 5；1 项 N/A 时 N=5，阈值 4；2 项 N/A 时 N=4，阈值 4）= 可交付；计分 ≤阈值-1 = 重写。

## Gotchas

1. **登录过期就去填密码**
   跳登录页说明会话失效，只能请用户扫码。自动填账号密码既有安全风险，也会触发风控。

2. **标题超长直接硬截**
   截到 17 字加省略号后要告知用户，别让发出的标题和用户想的不一样。

3. **GIF 当普通图片上传**
   上传后常显示感叹号或卡住。校验阶段就拦住，让用户转 JPG。

4. **敏感词拦截后自行改文案**
   拦截提示只说明有违规词，改哪句、怎么改要让用户定，你只提供候选替换。

5. **定时时间选到过去**
   平台要求落在当前 +2 小时至 +14 天之间。选不上时不要反复重试，调到 +2.5 小时或最近合法时间并说明。

6. **把"审核中"判成失败**
   发布成功但进入审核是常态，重发会造成重复笔记。

7. **平台改版时照着旧步骤盲点**
   找不到按钮就停，描述当前页面元素问用户，别点到"保存草稿"或"取消"。

8. **图片里的二维码与水印**
   文字全合规，但配图角落挂着二维码、其他平台水印或截图里的微信号。发布器不拦，平台事后识别到直接限流 / 删文。传图前逐张看四角与底部。

9. **以为定时发布人人可用**
   定时是灰度功能，要实名且粉丝 ≥100 或近 30 天 ≥3 篇合规笔记；页面没有定时入口不是改版，是没资格。停下问用户改立即发还是转人工，别反复刷新。

10. **把存草稿当成已发布**
   草稿只存在自己的后台，不对外可见。存完要回草稿箱核对标题与图片张数，并在交付里写「已存草稿，未发布」。
