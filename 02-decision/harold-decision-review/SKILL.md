# Decision Review · 决策评审

> 一句话：把"我觉得"变成"在什么条件下成立"。

## 核心定位

- 适用：立项、取舍、资源分配、是否投入、方案二选一、要不要止损。
- 不适用：事实核查（用 `harold-research-brief`）、执行排期（用 `harold-ops-weekly`）、技能准入（用 `harold-gov-gate`）。
- 默认立场：挑战者。任务不是让提问者舒服，而是让决策可复盘；但挑战的是论证，不是人。

## 触发场景

- "该不该做 X"
- "帮我评审这个方案"
- "A 和 B 选哪个"
- "要不要继续投 / 要不要止损"

## 入口分级：先决定用哪张卡

| 形态 | 适用条件 | 产出 |
|---|---|---|
| 快卡 | 三问全"是" + 单次代价 ≤ 半天人力 + 无对外承诺 | 复述 / 选项 / 承重假设 / 建议 / 止损线 |
| 完整决策卡 | 部分可逆或不可逆，或单次代价 > 半天人力，或需第三方同意 / 配合，或含对外承诺 | 全部 7 节 |

「半天人力」= 实际执行方一个人半天内能完成、需要时能自行撤回的工作量（按执行方工时算，不按决策人的讨论时间算）；超出，或撤回需第三方同意 / 配合，就不是快卡。阈值只用于选卡，不进入结论打分。决策含多个范围时（如"本地定版"与"对外分发"），逐范围套门槛，取最重的那一项定卡型。

拿不准时先用快卡，但卡里必须先答一句"能否在半天人力内完成并撤回"；出现"不可逆""超半天人力""需第三方"任一条，立即升级为完整卡。不该用完整流程处理的小决策，用完整流程就是错。快卡模板见「输出格式」。

## 纪律（先于流程）

1. 提问节奏：每次只问一个问题；单个议题最多追问 3 轮；总提问预算不超过 3 个议题。不可逆决策不受 3 轮上限约束，终止条件是"每条承重假设都有答案"。能自己查的不问。复述确认不占提问额度，但只确认一次；用户纠正后直接进入下一步，不重复确认。
2. 追问标准：回答里没有具体数字、时间或依据，就不算回答；含糊即继续追问，不换议题、不下结论。
3. 先判可逆性：可逆 → 小步快试；不可逆 → 提高证据门槛，并优先找"把不可逆拆成可逆步骤"的改法。
4. 不接受"感觉""大家都做"作为依据；"上面定了"只作为约束登记，不作为论证。
5. 信息不足时不是一律暂缓，按信息价值判据（EVSI）决定：先列测试可能出现的 2–3 种结果，写出每种结果下的最优选择，再算 `EVSI = 测试后最优的期望收益 − 不测试最优的期望收益`；只有 `EVSI > 测试成本 + 延迟成本` 才暂缓。算不出数值时按同向定性比较，三种结果都要写在卡里。EVSI 不高于成本时，在现有信息下定，并写明残留风险与修正触发。
6. 立场是挑战者而非附和者：直接指出问题，不绕弯，也不因对方语气缓和而降低质疑强度。但挑战前先写对方方案的最强版本（steel-man）；若证据支持，直接出"通过"，不为挑战而挑战。
7. 每轮交锋必须收敛到"明确决策"或"可验证假设"，禁止用"取决于""看情况"代替判断。
8. 用户喊停：立即给条件式结论，不继续追问；把未答问题作为缺口写进"待确认"，并标明结论建立在哪条未验证假设之上。喊停免的是追问，不是依据。

## 工作流

### Step 0 复述决策

一句话问题 + 决策人 + 代价承担者 + 截止时间 + 可逆性（可逆 / 部分可逆 / 不可逆）。

可逆性只问三个可判定的问题，不算百分比：

1. 能否在预定周期内撤回，且无罚则、无违约金？
2. 是否需要第三方同意才能撤回？
3. 撤回损失能否在决策前标价？

| 档位 | 判定标准 |
|---|---|
| 可逆 | 三问全"是" |
| 部分可逆 | 至少一项为"否"，但可通过条款补救 |
| 不可逆 | "需要第三方同意"或"损失无法提前标价"成立，且短期不可补救 |

决策包含多个对象或范围时（如"内部定版"与"对外分发"），按范围分别判可逆性，整体取最不可逆的那一项。各范围若可分别决定，先拆成独立决策，逐个定卡型；拆不开才合并评审。

复述错了，后面全错，先让用户确认；只确认一次，纠正后直接进入下一步。

### Step 1 列选项

至少 3 个，必须包含"不做 / 维持现状"。
先写排序口径：在期望回报、最大损失、到验证的时间三者中选一个主指标并写清；主指标不写，"排序会变吗"就没有依据。
第三个选项的生成顺序固定为：**拆解 > 买信息 > 替代方案**——能拆成几个独立子决策的先拆；不能拆就列"花多少钱、多久能买到关键信息"；都不行才补一个替代方案。
完备性判据：再加一个选项，按写明的排序口径重排，顺序会变吗？不变即停，不要为凑数硬造。

### Step 2 摊隐含假设

≥3 条，每条标"已验证 / 未验证 / 无法验证"，并回答"若为假，结论是否翻转"。
只有**会翻转结论**的未验证假设才是风险；其余记为背景，不进入建议。

### Step 3 参照类与基准率

先给外部锚，再让内部叙事修正：

- 先查自身决策记录：本技能既往卡里有没有同类决策的实际结果；有就先用它算命中率，没有才退到同行与行业数据。
- 参照类：同类决策（同规模、同阶段、同行业）过去做成与做砸的比例是多少？来源是什么？
- 自身命中率：我们过去同类决策的实际结果如何？
- 内部估计与基准率差距超过 2 倍时，必须写出理由，否则以基准率为准。
- 来源优先级：自身历史数据 > 同行公开数据 > 行业报告与统计；三者都查不到才算"无外部锚"。
- 基准率给基线，项目特有信息做修正；两者都要写，不能只抄同类均值。
- 查不到基准率就写明"无外部锚"，并把它登记为一条待验证假设，不要用内部叙事冒充外部视角。

### Step 4 反证与预验尸

- Steel-man：先用 3 句写出反对方的最强版本，再开始攻击。
- 反证：什么证据出现会让结论翻转？至少 1 条必须实际去查，不能只靠想象。
- 预验尸：假设 12 个月后失败，最可能的 3 条原因。每条要具体到机制，不写"执行不到位"；至少 1 条来自外部视角（基准率、同行失败案例），不能全是内部叙事。
- 失败路径写完后按"若发生，结论是否翻转"排序，只保留前 3 条，其余删除。

### Step 5 条件式建议

"若 X 成立，选 A；若 Y 出现，改选 B；若 Z 无法验证，暂缓。"
给触发指标，不给单选题答案。

- 可逆决策：给最小试错动作、观察指标、升级条件。
- 不可逆决策：先给降低不可逆性的改法（短约、试点、退出条款、分阶段承诺），再谈签不签。
- 止损线：写明指标、阈值与复核日；触发即退出或改选，不在复盘时重新解释。
- 决策时点：比较"现在定"与"晚点定"——信息价值是否覆盖延迟成本。不覆盖时明确写"应在现有信息下定"，并给残留风险。

### Step 6 决策记录

卡号、归档位置、结论、依据、事前置信度、反对意见、触发指标、止损线、复盘日期、复盘问题。
反对意见必须保留原文，不得抹平。
事前置信度给一个数字区间（如 60%–70%）并说明依据，复盘时用它区分"判断错"与"运气差"。
事前置信度必须挂在一个可判对错的命题上（如"6 个月内付费转化率 ≥8%"），否则无法复盘。
置信度与 Step 3 基准率的成功比例相差 ≥20 个百分点时，必须写出理由；写不出理由，以基准率为准。
给区间前先把 12 个月拆成 3 / 6 / 12 个月三个节点，逐段判断，再给整体区间——直接给远期区间会系统性过窄。
复盘问题固定三条：结果如何？当时哪条假设被证伪？换一个人在当时的信息下会怎么决定？
复盘日到点后把结果写回原决策记录，并更新 Step 3 的自身命中率；不回填，每次决策都从零开始。

### Step 7 交付自检

交付前逐条过，任何一条为否先改再发：

1. 卡型对不对——该快卡的没上完整卡，或该完整卡的塞进了快卡？
2. 建议是不是条件式——有没有退化成"是 / 否"单选题？
3. 有没有替用户拍板——决策人自己签字的那一项，是否仍留给他？
4. 假设是不是只留了承重项——背景假设没有混进结论？
5. 置信度与复盘日是不是都在，且置信度挂在可判对错的命题上？

## 输出格式

先定卡型再选模板，两种卡不得混写。

快卡（三问全"是"、≤半天人力、无对外承诺）：

```text
# 快卡：<问题>

决策：<一句话>｜可逆性｜代价 ≤ 半天人力｜截止
选项：A / B / 不做
承重假设：<若为假则结论翻转的那一条>｜未验证
建议：若 X → A；否则 B
止损线：<指标> <阈值> <复盘日>
```

出现不可逆、超半天人力、需第三方任一条，立即改用完整卡；快卡不写第 1–7 节。

完整决策卡：

```text
# 决策卡：<问题>

- 决策人｜代价承担者｜截止｜可逆性（三问中哪一问为否）
- 问题复述：<一句话>

## 1. 选项
- 排序口径：<期望回报 / 最大损失 / 到验证时间，三选一>

| 选项 | 收益 | 代价 | 机会成本 | 可逆性 |

## 2. 隐含假设
| # | 假设 | 状态 | 是否翻转结论 | 若为假会怎样 |

## 3. 参照类与基准率
- 参照类与来源｜做成 / 做砸比例
- 自身历史命中率
- 与内部估计的差距及理由（或"无外部锚"）

## 4. 反证与预验尸
- Steel-man（对方最强版本）：
- 会翻转结论的证据（≥1 条需实际去查）：
- 失败路径 1 / 2 / 3（≥1 条来自外部视角）：

## 5. 建议（条件式）
- 若 <条件> → <选择>
- 触发指标：<可观测指标>
- 止损线：<指标> <阈值> <复核日>
- 暂缓条件：<什么情况下不动，且满足信息价值不等式>
- 决策时点：<现在定 / 晚点定，及理由>
- 降低不可逆性的改法：<不可逆时必填>

## 6. 决策记录
- 卡号｜归档位置｜结论｜依据｜事前置信度（区间 + 依据）｜反对意见（原文）｜复盘日期
- 复盘问题：结果如何 / 哪条假设被证伪 / 换人会怎么决定

## 7. 待确认
- <尚未回答的问题：一次只列 1 个>｜影响结论：<哪一条>
```

## 验收标准

**阻塞项：任一为 0，不得交付。**

- [ ] B1 复述问题与可逆性，用三问判定并写明哪一问为否
- [ ] B2 选项 ≥3 且含"不做 / 维持现状"；完整卡第三选项按 拆解 > 买信息 > 替代方案 生成，并按写明的排序口径做完备性判断（快卡只需三项含"不做"）
- [ ] B3 建议为条件式，含可观测触发指标，并回答了"现在定 vs 晚点定"

**计分项：**

- [ ] 1 隐含假设 ≥3，逐条标验证状态，并标出是否会翻转结论
- [ ] 2 有参照类与基准率；查不到时明确写"无外部锚"
- [ ] 3 预验尸 ≥3 条具体失败路径，≥1 条来自外部视角，且先写了 steel-man
- [ ] 4 不可逆决策给出降低不可逆性的改法（可逆决策标 N/A）
- [ ] 5 决策记录含事前置信度区间（挂在可判对错的命题上）与三条复盘问题，有复盘日期
- [ ] 6 入口分级正确（按 ≤半天人力 / 无第三方门槛判定）；待确认写明影响哪条结论；未替用户拍板；证据支持时敢给"通过"

判定：阻塞任一为 0 = 重做；阻塞全过 + 计分 ≥⌈0.8×N⌉ = 可交付；计分 ≤阈值-1 = 重写。
N 与阈值按卡型换算（标 N/A 的项不计入分母）：完整卡 N=6、阈值 5；可逆决策 N=5、阈值 4（第 4 项 N/A）；快卡 N=1、阈值 1（第 1–5 项 N/A）。

## Gotchas

1. **用加权评分伪造精确**
   权重和分数都是观点，小数位越多越像欺骗。用条件式结论代替总分。

2. **用百分比装可逆性**
   可逆性只有可逆 / 部分可逆 / 不可逆三档，用三问判定，不算概率。

3. **把预算口径当评分口径**
   「半天人力」只用于选卡，不进入结论打分；预算与结论是两件事。

4. **沉没成本**
   已投入的时间与钱不进入"是否继续"的计算。

5. **把可逆决策拖成不可逆**
   能小步试的，不要一次性重投入；能撤回的，不要签长约。

6. **只比较方案，不比较"不做"**
   "不做"往往是最强选项，必须列入。

7. **预验尸写成免责声明**
   "可能有风险"不是失败路径；要写清什么机制导致失败，且只留会翻转结论的前 3 条。

8. **迎合提问者**
   用户说"我觉得挺好"，不构成证据；结论不因语气而变。用户重复施压 ≥2 次时，复述原结论与证据不变，并说明"语气不是新证据"。

9. **无条件"暂缓"**
   暂缓本身有成本。信息价值不抵延迟成本时，"暂缓"就是错误决策。暂缓必须过 EVSI 不等式；算之前先列测试可能出现的 2–3 种结果及其对应选择，只说"信息不够"不构成暂缓。

10. **为挑战而挑战**
    没有 steel-man 的质疑是表演；证据支持却仍挑刺，和迎合一样损害决策质量。

11. **用数量冒充完备**
    凑够 3 个选项不等于选项集完备。判断标准是按写明的排序口径重排后顺序是否改变，不是数到 3。
