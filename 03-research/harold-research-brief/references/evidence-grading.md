# 证据分级细则

## 1. 判定顺序（30 秒版）

0. 这句话是事实、观点还是预测？→ 观点 / 展望 / 预测 / 目标值在事实等级上**降一级**；利益相关方（公司评自身行业、卖方评覆盖板块）的观点直接定 P3；并在「类型」列标注
1. 是不是原始发布方？→ P0
2. 是不是权威机构对原始数据的整理，且披露方法？→ P1（咨询机构报告不适用，按 P2）
3. 是不是专业媒体 / 数据库的报道？→ P2
4. 其余（观点、转述、AI 生成、匿名）→ P3

拿不准时往下取，不往上取。

## 2. 边界案例

| 材料 | 等级 | 说明 |
|---|---|---|
| 政府 / 监管原文、统计公报 | P0 | 注意征求意见稿与正式稿、有效期与废止 |
| 公司年报、招股书、公告 | P0 | 对其自身事实；涉及其对行业判断时降为 P3 |
| 公司官网新闻稿 | P0（自身事实）/ P3（行业判断） | 宣传口径需交叉 |
| 财报电话会记录 | P1 | 管理层表述，非审计数据 |
| 券商研报（披露模型与口径） | P1 | 其预测值固定标"预测"，不进 P0 |
| 券商研报（只给结论） | P2 | 需回溯原始数据 |
| 行业协会统计 | P1 | 注意会员覆盖与统计范围偏差 |
| 咨询机构报告（有方法说明） | P2 | 等级定义以 SKILL.md「证据分级」为准：有方法说明的咨询报告算 P2 |
| 主流财经媒体报道 | P2 | 只作线索；关键结论找原始 |
| 百科、知识库、问答 | P2 以下 | 只用于建立检索关键词 |
| 翻译稿 | 原级降一档 | 核对原文后再恢复 |
| 自媒体、公众号、短视频 | P3 | 不得作唯一依据 |
| AI 生成内容 | P3 | 必须回溯到其引用源，否则不入表 |

## 3. 独立性判定

满足任一条件即视为**同源**：

- 同一发布主体
- 同一份原始数据或同一篇稿件
- 同一套模板的转载 / 摘编
- 后发文章明确引用前一篇

三源要求的是三条独立的采集—发布链条，不是三个网址。

立场也要独立：

- 多源都引自同一利益方（同一家公司、同一支基金、同一个推广方），按 1 个立场计
- 多源全属同一阵营（全卖方研报、全行业推广机构），即使链条不同，也按 1 个立场计
- 出现立场单一，必须在结论里写明"来源立场单一"，且不得据此上调确定性档位

## 4. 常见误判

1. **把"权威媒体"当 P0。** 媒体是传播方，不是数据生产方。
2. **把"公司自述"当行业事实。** 公司对自己有利的行业数字要交叉。
3. **把预印本当已发表论文。** arXiv 等未经同行评审，按 P1 或 P2。
4. **把数据库导出当原始数据。** 看它采自哪里、如何清洗。
5. **把"引用量高"当可靠。** 传播广不等于方法对。

## 5. 等级如何影响结论

- 结论等级 = 该结论所依赖证据的最低等级。
- 核心结论（进结论摘要）默认需 ≥3 个独立来源；1 份可点开的 P0 原文直证可替代，标「P0 直证」。
- P0 且只有一个来源、也不构成直证 → 写"P0 单源"，档位最多到 3。
- 证据的地域、人群、时段或指标口径与本问题不一致 → 按间接证据在现有等级上降一级，并在证据表「口径与时间」列写明差异；写不出差异的不得进结论摘要。
- 仅由 P2/P3 支撑的判断 → 只能进"待验证假设"，不得进结论摘要。
- 措辞随等级走：P0/P1 直述；P2 只能"据 X 报道"；P3 只能写成假设。
- 观点 / 预测 / 目标值固定标类型并已降一级，不与实绩同列比较。
- 同一指标多源数值不同 → 给区间并注明取自哪几个源，不硬凑单值。
- 证据等级与确定性档位不能因为"用户希望确定"而上调。
- 已做反证检索的结论，可在结论句后注明"已检索反证，未见 X"，但不因此加分升级。

## 6. 三类降级与无源判定

| 情形 | 处理 |
|---|---|
| 来源本身有问题（本议题上修订过同一指标 / 被公开更正过 / 未披露利益关系） | 该源证据在 P 级基础下降一级 |
| 调研类证据未写样本量与抽样方式 | 按间接证据降一级，且不进结论摘要 |
| 数值超出 §0 数据保质期 | 不得进结论摘要，只能进证据表并标年份与时点 |
| 数值来自训练记忆、本次未打开原文 | 视同无来源：不写进「值」列，行标「未获取」、等级「—」 |

三类降级可以叠加，但最多降到 P3；降到 P3 后仍只能进「待验证假设」。
