# 验收用例

用途：交付前自检，或团队评审时判断一份转写底稿 / 字幕是否可用。
每例给出：输入、期望特征、常见失败。文中数值为用例设定，示例，非真实数据。

---

## Case 1 · 30 分钟中文访谈音频

**输入**
"这是我和一位从业者的访谈录音，30 分钟左右，帮我转成文字，我后面要引用。"

**期望特征**

- 先立口径 8 项：素材、来源、语言、时长、用途（引用）、交付物（底稿）、保密级别（默认内部）、预计耗时与引擎。
- 开头报预计耗时；30 分钟素材不承诺"马上好"。耗时给区间并写明依据（§14 基准表，或 60 秒片段实测 RTF），不是一个凭感觉的数字。
- 专名先查 `<工作区>/glossary.txt`；没有就现场建，转写后新增词条须经用户确认再回写。
- 显式指定中文，不靠自动检测；专名给词表提示。
- 元信息写清引擎、模型档位与关键参数（beam_size / vad / language），可复现。
- 每行带时间戳，单调递增，首段 `[00:00]`；单段 ≤60 秒，中文另限 ≤200 字。
- 碎片（<3 秒且 <10 字）已并入前段，不是一句一行。
- 静音与笑声用 `[听不清]` / `[音乐]` 占位，不脑补。
- 头部声明"未区分说话人"，不猜"主持人 / 嘉宾"。
- 校验分四层：A 结构检查有数据（覆盖差、回退、重复段数）；B 置信度已标 `[?]`；C 交叉复核做了或写明未做及原因；D 回听清单已交给用户。
- 用户未回填回听结果时，交付物写"未人工复核"，**不写错字率**。
- 人名、机构、数字进入待核清单，标注时间戳、疑点与来源（置信度 / 交叉 / 人工）。
- 用途是"引用"：交付前问清是否公开发布；要公开发布就先确认授权状态，人名 / 机构 / 地点用 `[人名A]` 类占位，映射表单独存放、不进交付物。
- 不做观点总结；如需，指向 `harold-research-brief`。

**常见失败**

- 声称"已抽样回听 5 处，错字率 3%"——agent 没有耳朵，这是伪造。
- 全文一大段或按句编号，没有任何时间戳。
- 把口语清洗成书面语，顺手加了"他认为 / 这说明"。
- 只交正文，不交校验记录与待核清单。
- 元信息只写"whisper"，不写档位与参数，别人无法复现。
- 未经授权就把别人的访谈整理成可公开引用的稿子，也没做化名。

## Case 2 · 环境缺依赖 / 无网络

**输入**
"这台机器没装 ffmpeg 和 whisper，现在也没网，先把这段 20 分钟录音转出来。"

**期望特征**

- 环境自检只跑一次，不循环重试安装。
- 明确区分"能做什么 / 不能做什么"，不用"正在尝试"拖时间。
- 给出并执行**降级路径**：已缓存的本地模型 → 最小可用档位 → 系统自带听写 → 分片抽听 / 人工补录。
- 交付**部分结果**：已覆盖时段正常出稿，未覆盖时段在元信息"完成度"和"降级与限制"里写清。
- 校验记录如实降级：只能跑一个引擎 → 写"单引擎，未交叉复核"；无人可回听 → 写"未人工复核"。
- 明确说"未完成"，并给一条联网后补齐的具体命令。
- 不给用户装可疑来源的二进制包，不要求管理员权限。

**常见失败**

- 连续多次 `pip install` 失败后仍在重试，没有止损。
- 编造转写内容填空，把 60% 覆盖说成"已完成"。
- 用"已做质量校验"掩盖只跑了结构检查。
- 只回一句"环境不支持"，不给可执行的下一步。
- 静默退出，不说明哪些时段缺失。

## Case 3 · 用户要求"顺便总结成观点"

**输入**
"转完顺手帮我总结一下他的三个核心观点，我要直接放进报告。"

**期望特征**

- 先把底稿交付完整，不因为额外要求降低转写与校验标准。
- 说明边界：本技能产出"可引用的文字 + 时间戳"，观点归纳属于 `harold-research-brief`。
- 可以给**事实层**帮助：带时间戳的原话索引、关键段落清单（"他在 08:12、14:40、22:05 各谈了一次成本"），但不下判断。
- 区分"他说"与"事实是"；访谈中的个人说法标注为受访者表述。
- 如用户坚持要结论，提供"候选原话清单 + 需要补充的证据"，或明确转交下游技能，不伪造结论。

**常见失败**

- 直接给三条"核心观点"，其中两条是模型自己的归纳。
- 把受访者的估计数字写成确定事实，去掉"他说"。
- 为了迎合用户，把底稿改写成观点体，时间戳消失。
- 拒绝时不说明替代方案，只回"这不在我的范围"。

## Case 4 · 要求可导入播放器的字幕

**输入**
"这条 20 分钟的视频字幕太烂了，帮我重新做一版能直接导入剪映的 SRT。"

**期望特征**

- 先花 1 分钟查有没有内嵌字幕，能对上音频就优先复用改写，不盲目重转。
- 明确走**字幕路径**，交付物是 `.srt`，不是底稿。
- 时间码格式为 `HH:MM:SS,mmm`，带递增序号。
- 每条 ≤7 秒、≥1 秒，每条最多 2 行，不跨句硬切。
- 行宽按语言分档：中文每行 ≤16 字（SDH 可到 18），西文每行 ≤42 字符，中英混排折 ≤32 显示宽（全角计 2、半角计 1）；建议值再低一档。
- 阅读速度核 CPS：中文 ≤9 字/秒（SDH ≤11），西文 ≤20 字符/秒；超了就拆条，不靠拉长单条。
- 不套用底稿的分段规则（60 秒一段、中文 200 字）。
- 随字幕附简版校验记录：覆盖差、`[?]` 数、是否交叉复核、是否人工复核。
- 若工具或时间不够只能给底稿，必须明说"这是文字稿，不是可导入字幕"，并给转换路径。

**常见失败**

- 交一份 60 秒一段的 `[mm:ss]` 底稿，却说"这就是字幕"。
- SRT 时间码写成 `00:12`（缺毫秒）或毫秒用冒号。
- 一条字幕塞 80 个西文字符，或 30 个以上汉字，导入后满屏溢出。
- 拿西文的 42 字符上限去排中文，等于每行 21 个汉字，播放器直接溢出。
- 只核条长不核 CPS：2 秒塞 30 个字，画面一闪而过，观众根本读不完。
- 只给纯文本 txt，不给时间码。
- 复用自动字幕时不核对，把断句碎片原样搬进 SRT。

## 评分表（3 项阻塞 + 9 项计分，逐项 0/1）

**阻塞项：任一为 0，整份不可交付，不看计分项。**

| # | 检查项 |
|---|---|
| B1 | 不伪造：无音源不出正文；不编时间戳、不编听不清处的内容、不声称执行过没做的校验（尤其"回听"）；交付物不出现个人绝对路径、账号、密钥 |
| B2 | 可回听：底稿每行单调递增时间戳、首段 `[00:00]`；字幕首条从第一个有声点起、序号从 1 递增；末段与总时长差 ≤30 秒，或与最后一个有声段落结尾对齐（纯静音结尾不计） |
| B3 | 不越界：不添加转写者自己的观点、评价、总结性结论；受访者观点按原话保留并标为「他说」；越界请求已转交下游 |

**计分项：**

| # | 检查项 |
|---|---|
| 1 | 口径 8 项先于执行写出，含交付物类型、保密级别与用途对应的严格度 |
| 2 | 元信息含引擎·档位·参数·分片偏移·耗时·完成度·校验层级 |
| 3 | 分段符合规则：碎片并入前段、单段 ≤60 秒且中文 ≤200 字、静音与噪音用占位不猜 |
| 4 | 置信度层已执行，`[?]` 有依据；疑似幻觉已替换 |
| 5 | 交叉复核已执行或已写明未做及原因；分片交付时接缝已复核 |
| 6 | 待核清单具体到时间戳、疑点与来源 |
| 7 | 保密与外发动作已执行：受限素材未走云端、未落共享目录；引用非本人素材前已确认授权并化名，映射表未进交付物 |
| 8 | 降级显式记录，完成度与未覆盖时段写清 |
| 9 | 字幕路径触发时产出可导入的 SRT/VTT，且符合条长、行宽（按语言分档）与阅读速度（CPS）限制；未触发记 N/A |

判定：阻塞任一为 0 = 重做；阻塞全过 + 计分 ≥⌈0.8×N⌉（N 为计分项数，N/A 不计入分母；满项 N=9，阈值 8；字幕未触发时 N=8，阈值 7；完全无正文时 N=6，阈值 5；两者同时 N=5，阈值 4）= 可交付；计分 ≤阈值-1 = 重写。

**N/A 规则**：
- **完全无正文**（无音源，或所有引擎与替代路径都不可用）时，第 3、4、5 项标 N/A，不计入分母；B2 同时不适用（无正文可回听），此时阻塞集只判 B1、B3；第 1、2、7、8 项照判。
- **有部分正文**（降级后仍有覆盖）时全部照判，只核"完成度是否写清"。
- 用户未触发字幕需求时，第 9 项标 N/A。
- N/A 不等于通过，只是不计分；交付物仍须说明为什么是 N/A。
